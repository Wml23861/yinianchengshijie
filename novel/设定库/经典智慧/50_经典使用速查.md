# 50_经典使用速查（写一章前看 30 秒）

> 用途：AI 写经文最容易犯两类错：硬塞 + 凭记忆编。
> 本文件是写经文前的快速对照表。

---

## 一、6 大原则

1. **不确定原文就不用引号**（凭记忆编出来 = P0 致命）
2. **不要每章都引经**（一章不引也活得很好；引则服务于人物当时具体处境）
3. **不要让人物突然说出大段经文**（普通人不念经；和尚/学者/老人在合适场景才引）
4. **不要让经文承担"主题解释"功能**（写的是"经文教我们……"，= 讲义）
5. **不要把所有经文塞进同一章**（一章最多 1 处引用，0-1 句）
6. **出处要查 14_儒释道经典索引.md**，查不到就写成"角色自己的理解"

---

## 二、5 种合法的经文出场方式

### 1. 人物真的在念经 / 抄经 / 听到别人念

> 例：老和尚在扫地的间隙念《心经》最后一句，明心走过听到了。
> 这种最自然。**出处要准**。

### 2. 人物记起一句

> 例：明心坐在医院走廊，忽然想起母亲以前说过"既来之则安之"（俗语，不是经文）。
> 经文也可以这样，但必须**当时处境正好对上**。**出处要准**。

### 3. 经典被**用错**（人物自己理解偏了）

> 例：明心安慰朋友说"放下屠刀立地成佛"——朋友反问"那被屠的人呢"。
> 这是**最有用**的一种。经文被错用 = 人物局限 + 经典本身被看见。
> **不需要原文**（反正角色自己讲错了），但读者得懂经典原本不是这意思。

### 4. 经典不出场，但人物活出了它

> 例：明心某个章节完全没有引用《道德经》，但他做了"无为"的事——读者自己读出来。
> **最高级**。但作者不能跳出来说"看，这就是无为"。

### 5. 经典被反派利用

> 例：赤炎念"杀身成仁"去杀人。
> 例：无厌侯用"知足常乐"反向劝人别反抗。
> 这种是给反派立体感。**不否定经典**（经典是中性的，看人怎么用）。

---

## 三、绝对禁止

- ❌ **凭记忆编一句"原文"**（AI 最爱这么干。P0 致命。）
- ❌ **把不同经典的句子拼成一句**（"色即是空，空即是色，受想行识……"——拼接错误，P0）
- ❌ **编造作者/出处**（"《庄子·逍遥游》记载"——原文查不到，P0）
- ❌ **借人物讲经**（"明心心想：'所谓放下，就是……'"——P1）
- ❌ **一段经文 + 一段白话翻译**（讲义结构，P1）
- ❌ **每章必引**（30 章引了 28 处 = 注水，P2）
- ❌ **金句腔的伪经文**（"人生就像一条河"——这种不是经文，是 AI 自创鸡汤）

---

## 四、写经文前的 3 步

```
1. 查 14_儒释道经典索引.md（出处/原文/上下文）
2. 找到原文 → 复制原文 → 写出处 → 写到正文
3. 找不到原文 → 不要用引号 → 写成"角色自己的理解"或"他模模糊糊记得一句"
```

## 五、6 大经典最易错的原文（速记）

| 经典 | 易错点 | 实际原文（速记） |
|---|---|---|
| 《心经》 | "色不异空，空不异色" 不能串改 | "色不异空，空不异色；色即是空，空即是色；受想行识，亦复如是" |
| 《金刚经》 | "凡所有相皆是虚妄" 经常被倒装 | "凡所有相，皆是虚妄。若见诸相非相，则见如来" |
| 《道德经》 | "道可道非常道" 的"常"经常被写成"非" | "道可道，非常道；名可名，非常名" |
| 《庄子》 | 出处经常张冠李戴（"逍遥游" vs "齐物论"） | 引用前必须查具体篇名 |
| 《论语》 | "学而时习之" 经常被改成"学而时之" | "学而时习之，不亦说乎" |
| 《六祖坛经》 | "本来无一物" 的来源经常被错配 | 出自《六祖坛经·行由品》 |

> **以上只是提醒，真要用必须查 14_儒释道经典索引.md。**

## 六、AI 自检（一章完成后跑）

```
[ ] 本章经文引用 ≤ 1 处
[ ] 每处引用都有出处（书名 + 篇名 / 章）
[ ] 原文与出处一致（不准凭记忆）
[ ] 没有"作者借人物讲经文含义"
[ ] 没有"一段经文 + 一段白话翻译"
[ ] 找不到原文的，没有用引号
[ ] 经典被错用 / 反派用 / 人物活出 = 算高级用，不在此限
```
