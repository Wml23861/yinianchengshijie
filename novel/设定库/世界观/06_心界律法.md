# 06_心界律法

> 心界存在二十条深层规律。这些规律**不能一次性全部告诉读者**，要在剧情中逐步显现。
> 每一条都对应真实的人心规律，是全书哲学骨架。

| 编号 | 律法 | 心界表现 | 对应剧情/人物 |
|------|------|----------|---------------|
| 一 | 念起必有因 | 每个念头众生都有来历 | 五蕴大臣各有前史 |
| 二 | 念头不等于事实 | 妄城的谎花不是真话 | 疑川 |
| 三 | 念头不等于我 | 识海大臣的「你是谁」 | 明心见性 |
| 四 | 被压抑的东西不会因压抑而消失 | 嗔怒的火越压越旺 | 赤炎 |
| 五 | 越抗拒某种念头，越容易被它牵引 | 明心越反抗四相魔君越强 | 四相魔劫 |
| 六 | 注意力在哪里，哪里就越强 | 排名的塔因被盯着而越盖越高 | 高台侯 |
| 七 | 执着于得到，就害怕失去 | 无厌侯攥着金砂不敢松手 | 无厌侯 |
| 八 | 执着于控制，就不断恐惧失控 | 明心强行镇压心界越乱 | 道境无为 |
| 九 | 逃避痛苦，有时让痛苦活得更长 | 雾先生制造迷雾逃避 | 雾先生 |
| 十 | 理解一个人，不等于赞同他的行为 | 明心理解反派仍阻止其伤人 | 全书原则 |
| 十一 | 慈悲不等于纵容 | 明心不让恶继续 | 全书原则 |
| 十二 | 放下不等于放弃责任 | 空门之悟 | 知行合一 |
| 十三 | 无为不等于什么都不做 | 无为的点化 | 道境 |
| 十四 | 空不等于什么都没有 | 明心误解「空」后纠偏 | 空门 |
| 十五 | 自由不是拥有一切，而是不被某样东西强迫 | 明心放下「必须赢」 | 全书 |
| 十六 | 真正的智慧不急于证明自己正确 | 明心不再争辩 | 名城 |
| 十七 | 知道自己不知道，是智慧的一部分 | 明心说「我不知道」 | 全书 |
| 十八 | 见念而不随念 | 坐在岸边看念头流走 | 识海 |
| 十九 | 见情而不困于情 | 情天放手 | 情天 |
| 二十 | 最终甚至要放下「我要觉醒」的执着 | 明心对无明天魔的回答 | 无界 |

## 二、九种核心运行规律（与二十条律法互补）

| 编号 | 核心规律 | 含义 |
|------|----------|------|
| 1 | 念起则境生 | 强烈念头持续存在，会影响周围环境 |
| 2 | 执着越深，世界越窄 | 执着不是增加力量，而是缩小选择 |
| 3 | 恐惧会制造未来 | 越害怕什么，越不断寻找相关证据 |
| 4 | 逃避会形成迷宫 | 不面对的问题不会消失，只会改变入口 |
| 5 | 欲望会产生债 | 得到之后，会产生新的维护成本 |
| 6 | 情绪不能被消灭 | 只能被看见、理解、承受、转化 |
| 7 | 看见本身就是力量 | 不是超能力，而是选择空间增加 |
| 8 | 真正的自由不是想做什么就做什么 | 而是能看见自己为什么想做 |
| 9 | 越接近本心，越少「证明自己」 | 全书最重要的隐性规律之一 |

## 使用规则

1. 律法**不得**以「本章讲第X条律法」的方式机械使用。
2. 律法通过人物经历、冲突、选择自然显现，读者自己领悟。
3. 二十条律法对应的剧情，在后文保持因果一致（见 16_世界时间线）。
4. 每完成一部，检查是否有多条律法被重复使用或遗忘（见 23_长篇连续性检查规则）。
