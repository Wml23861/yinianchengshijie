# 27_意象库

> 意象是反复出现的象征物、场景、动作，用于承载情绪与主题。建立本表控制频率（CLAUDE.md 第八十条：建立「意象使用表」；第六十二条：同一意象同一章不超过一次）。
> 觉悟/静默场景不得总是「风吹过、湖面荡漾、树叶落下、明心闭眼、深吸一口气」。

## 二、意象使用规则

1. 同一意象同一章不超过 1 次（CLAUDE.md 第六十二条）。
2. 觉悟/静默场景的「标配动作」必须打破：不能每次都是风吹过、湖面荡漾、树叶落下、闭眼、深吸气。
3. 终极意象（镜子、空殿、珠子、锁链盒子、无门）只在关键转折使用，保持稀缺。
4. 每个意象必须有「此刻」的具体性，不能只剩象征（CLAUDE.md 第一百零九条：一片树叶可以只是树叶）。
5. 新增意象前查本表，避免与已有意象重复。

## 三、意象与主题的对应（仅供作者管理，正文不解释）

- 镜子 / 空殿 / 无门 → 「我是谁」「自性不统治」
- 火 / 金砂 / 城墙 → 执着、欲望、边界
- 水 / 风 / 雨 → 情绪、无常、流动
- 锁链盒子 / 珠子 → 压抑的记忆与初心（返本）
