# 20_AI高风险表达库

> AI文感的根本来源不是几个词，而是：过度工整、过度正确、过度总结、过度解释、人物无真实欲望、每句都有意义、每章都闭环、每个人都恰好知道该知道的（CLAUDE.md 第五十七条）。
> 本库列出的句式/词汇**不是绝对禁止**，而是**禁止高频、禁止连续、禁止成模板**（第四十一条）。

---

## 一、高风险句式（出现即检查）

| 句式 | 问题 | 处理 |
|------|------|------|
| 不是……而是…… | 高频AI模板 | 保留最重要的一个，其余改简单句 |
| 不是……是…… | 同上 | 同上 |
| 并不是……而是…… | 同上 | 改 |
| 从某种意义上来说 | 空洞过渡 | 删除 |
| 从某种程度上来说 | 空洞过渡 | 删除 |
| 这一刻，他终于明白…… | 过度总结 | 每章不超过一句 |
| 此时此刻 | 煽情模板 | 删或改具体时间 |
| 他忽然意识到…… | 顿悟模板 | 改成具体动作因果 |
| 原来…… | 总结感 | 每章不超过一句 |
| 真正的…… | 金句工厂 | 稀缺使用 |
| 所谓…… | 说教感 | 删 |
| 人生…… | 金句工厂 | 稀缺使用 |
| 这一刻，他释然了 | 廉价顿悟 | 用动作替代 |
| 他深吸了一口气 | 万能动作 | 改具体动作 |
| 他的眼神复杂 | 偷懒描写 | 改具体细节 |
| 沉默良久 | 偷懒描写 | 改具体沉默内容 |
| 嘴角露出一丝笑容 | 模板表情 | 改具体 |
| 缓缓地/轻轻地/静静地 | 副词堆砌 | 删或改动词 |
| 仿佛…… | 滥用比喻 | 控制频率 |
| 不由得…… | 被动感 | 改主动 |
| 不仅仅是……更是…… | 机械递进 | 改简单句 |
| 值得注意/不可否认/显而易见 | 书面腔 | 删 |

## 二、禁止的机械结构（CLAUDE.md 第四十二、四十三条）

1. **连续同构句**：「他看着天空。他看着远方。他看着明心。」——「他看着」连续超过两次必须改。
2. **机械三段式**：「过去……现在……未来……」「第一……第二……第三……」「不是……不是……而是……」「他没有……没有……只是……」——除非剧情确实需要。
3. **连续「的」字短语**：连续三个以上必须断句重组。
4. **连续「当……的时候」**：连续两个以上删改。

## 三、禁止过度总结（CLAUDE.md 第四十四条）

不要每章结尾告诉读者「这一刻明心终于明白了人生的意义」。应该让动作结束。例如：明心没有回答，只是把手里的石头放回河边，然后继续往前走。

## 四、AI文感的深层来源（CLAUDE.md 第五十七条）

以下任何一条，都可能是AI感的来源，写作时必须警惕：

- 过度工整、过度正确、过度总结、过度解释
- 人物没有真实欲望
- 人物说话全部有意义
- 每个冲突都服务主题
- 每章都有完整闭环
- 每个角色都恰好知道该知道的事
- 每段都在推进剧情
- 每句话都很漂亮
- 每个人都很聪明
- 每个反派都像哲学家
- 每次冲突都为了主角悟道

## 五、制造真实感（CLAUDE.md 第五十八条）

必须允许：偶然、误会、无效对话、生活细节、无意义的小动作、人物的迟疑、错误判断、说完后悔、情绪失控、无关紧要的小事、不完美的表达。但这些不能大量注水，必须服务人物真实感。

## 七、补充AI规避规则（引自创作宪法_1/_2）

### 更全的高风险模板句
- 他从未想过…… / 不知何时…… / 一时间…… / 良久…… / 沉默了很久……
- 眼神中闪过一丝…… / 嘴角微微上扬…… / 缓缓闭上眼睛……
- 命运的齿轮开始转动 / 一个惊人的真相浮出水面 / 所有人都震惊了 / 在场众人无不……
- 空气仿佛凝固 / 时间仿佛停止

### 句式层面（二级禁区）
连续排比、连续金句、连续总结、连续抽象概念、连续哲学句；「不是A，而是B」「既A，又B」「越A，越B」「当A时，B」「他没有……只是……」「他知道……却……」

### 情绪直接命名
少写「他很悲伤」，多写「他把手机扣在桌上，过了一会儿，又翻回来」。让动作承担情绪。

### 重复意象
不能每次觉悟都用：风吹过、湖面荡漾、树叶落下、明心闭眼、深吸一口气。建立「意象使用表」控制频率。

### 过度完美
允许句子略微不对称、人物表达不完整、生活细节偶尔粗糙、情绪存在矛盾、人物说出自己后来会后悔的话。

### 机械「人类化」禁止
不故意加错别字、病句、低级错误、无意义重复、刻意口语。「不像AI」不等于「像人」，真正目标是「像一个长期活在这个世界里的人写出来的故事」。
