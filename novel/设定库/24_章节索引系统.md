# 24_章节索引系统

> 章节索引记录每章的元数据（CLAUDE.md 第十条、第三十三~三十四卷）。
> 元数据**不得混入正文**，单独登记在本文件；正文文件只含标题 + 正文。

---

## 一、章节元数据格式

每章登记：

| 字段 | 说明 |
|------|------|
| 章节号 | 全局递增（已写至25章） |
| 标题 | 章节标题 |
| 所属 | 时代/卷/部（按九大时代归档） |
| 时间 | 现实时间 + 心界时间 |
| 地点 | 主要场景 |
| 人物 | 出场人物 |
| 事件 | 核心事件 |
| 主题 | 修行课题/移石 |
| 经典 | 使用的经典（佛/道/儒） |
| 伏笔 | 本章埋设/回收的伏笔编号 |
| 对境 | 现实对境编号 |
| 心力 | 清明度变化 |

## 二、章节登记

| 章 | 标题 | 时代 | 核心课题 |
|----|------|------|----------|
| 1 | 深夜两点 | 尘中少年 | 现实崩溃，强撑到极限 |
| 2 | 天空裂了 | 尘中少年 | 天空裂开，坠入心界，撑不住 |
| 3 | 城门外 | 尘中少年 | 城外茫然，迈入城门 |

> 每章详细档案（创作信息 / 伏笔对境 / 审查结果 / 问题修改 / 下一章衔接）见 42_章节创作记录。

> 详细逐章元数据（对境、经典、伏笔编号）随创作逐步补齐，已有对境追踪见 ../生活对境库.md。

## 三、章节文件命名（CLAUDE.md 第三十二卷）

- 统一 `NN_第N章_标题.md`（如 `26_第二十六章_高台侯的榜单.md`）。
- 禁止 `final/new/new2` 等后缀。

## 四、章节内部格式（CLAUDE.md 第三十三卷）

- 第一行：章节标题。
- 空一行，开始正文。
- 正文禁止出现作者说明、剧情总结、「本章主题」「作者的话」「下一章」「读者」等。

## 五、更新时机

每章完成后，在本文件登记本章元数据（见 23_长篇连续性检查规则 的核对维度）。
