# 23_长篇连续性检查规则

> 长篇创作最大的风险是遗忘前文、前后矛盾、重复注水。以下为分层检查规则（CLAUDE.md 第九十七~一百条）。

---

## 一、二十章重复检查（每写新章前）

写新章前，检查最近至少20章，比较：
- 人物、地点、事件、冲突、情绪、动作、金句、经典、现实对境、结尾形式
- 目标：避免短期重复。

## 二、一百章结构检查（每完成约百章）

检查：
- 主线是否推进
- 人物是否成长
- 世界是否扩大
- 伏笔是否增加过多
- 旧伏笔是否回收
- 是否出现大量重复
- 是否出现注水
- 是否出现人物失控

## 三、十万字检查（每完成约十万字）

阶段审查，包括：
- 世界观、人物、主线、支线
- 哲学方向、读者体验、语言风格
- AI痕迹、重复、伏笔、经典

## 四、百万字检查（每完成约一百万字）

大型结构审查，检查：
- 明心是否仍是核心
- 故事是否变成普通玄幻
- 哲理是否压过故事
- 人物是否工具化
- 反派是否套路化
- 是否为了千万字而注水
- 是否出现大量重复
- 是否偏离最终愿景

必要时允许重构后续路线，但**不得随意修改已确立的历史事实**。

---

## 五、连续性核对维度（每章写后必查）

| 维度 | 检查点 | 数据来源 |
|------|--------|----------|
| 人物 | 年龄、身份、关系、状态、成长阶段 | 03/08/09 人物库 |
| 时间 | 现实/心界时间、事件顺序 | 16_世界时间线 |
| 地点 | 场景一致性 | 19_场景库 |
| 伏笔 | 埋设/回收、编号 | 13_长期伏笔库 |
| 经典 | 原文/出处准确 | 14_经典索引 |
| 心力 | 清明度（非战斗力） | 03_明心弧线 |
| 对境 | 近五章不重复 | 18_生活对境库 |
| 表达 | 高频词/句式 | 21_高频词追踪 |
| 世界观 | 九重世界/律法/百官 | 05/06/07 |
| 主线 | 是否推进 | 11_主线剧情树 |

## 六、出现不确定时的处理（CLAUDE.md 第一百零三条）

1. 优先查已有文件。
2. 仍无法确定 → 建立待确认记录。
3. 非核心细节 → 选最符合已有设定的方案。
4. 核心设定 → 不允许偷偷改变。

## 七、数字准确性（CLAUDE.md 第五十六条）

所有年龄、时间、日期、距离、数量、章节编号、人物关系、钱、事件顺序必须准确。不能前面写二十岁后面突然二十二岁；不能一个人有两个年龄；不能人物已死亡后面又正常出现。
