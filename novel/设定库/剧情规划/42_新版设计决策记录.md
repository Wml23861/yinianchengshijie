## 三、一句话定位

《心上众生》第一部，讲一个 **28岁都市打工人在「工作、家庭、关系」三线同时崩盘的绝境里，
通过「心界」看见自己、看破心结、一点点把自己捡起来** 的故事。

- **深度与法喜并重**：每章让读者心头一亮（看破式智爽）或心里一暖（治愈式暖爽）。
- 经典如钥匙般点破心结，但绝不点破象征、不说教。
- 世界观、人物、双线结构全部照旧，只改写法。

## 四、设计方案提案（待用户确认）

### （一）现实线：三线危机具体设计

**工作线（先爆，生存层主引擎）**
明心在互联网公司做产品，28岁做了三年不上不下。新空降的年轻领导张总看他不顺眼，逐步架空、边缘他。
他倾注心血的一个项目被否、被抢、被砍，最后还要替一个数据事故背锅，面临被裁。
> 痛点：我怕输、我证明不了自己、我努力了却没用。

**家庭线（次爆，情感引擎）**
明心报喜不报忧：他在外面的难处（工作、钱、感情）一个字都不跟父母说，报喜不报忧。
父母每句关心都让他更不敢说真话。压力不是父母给的，是明心自己扛着不肯放。
> 痛点：我不敢让父母知道，我快撑不住了。父母是好人、是暖色，不是危机的来源。

**关系线（后爆，情感＋身份引擎）**
前女友周薇在这个节骨眼重新出现（她要结婚了／有事求明心／旧情复燃又无疾而终）。
明心状态差，一段刚萌芽的新关系（同事或相亲）也黄了。
> 痛点：我怕被抛弃、我不知道怎么爱、我放不下。

**三线交错节奏**：工作先爆 → 家庭再爆 → 关系爆 → 三线交汇把明心逼进最低谷 → 爬起来。

### （二）心界线：世界之谜

保留旧版核心：**心界为何崩乱（明心十年未归／遗忘了自己）＋ 皇帝（自性）真相 ＋ 明心十年前为何离开**。

新版改法：谜不是「设定科普」，而是「有戏的悬念」——
明心第一次进心界，看到崩乱的王城和一个小孩子（问天童）；
越被现实逼到墙角，心界越乱；每看破一个心结，心界就修复一块。
**现实危机与心界之谜互为镜子。**

### （三）写法核心：智爽＋暖爽＋经典怎么落地

- **智爽（看破）**：心界里一个具象的场景／人物，让明心（和读者）「原来如此」——原来我不是怕这个，是怕那个。由剧情带出，绝不点破。
- **暖爽（治愈）**：一个念头众生或一个普通人被看见、被理解、被放过。明心放过自己，或明心看见别人的苦。
- **经典三线**：关键处一句原文做钥匙（点题）；走到哪一步哪部经典自然浮出（随人生）；《心经》「照见五蕴皆空」做贯穿悬念（线索）。

### （四）章节卡格式（每章一张）

| 字段 | 内容 |
|------|------|
| 章号／标题 | 唯一 |
| 现实线 | 哪条线、推进什么 |
| 心界线 | 谜团推进什么 |
| 本章爽点 | 智爽 or 暖爽，具体打什么 |
| 本章经典 | 引什么、怎么带出 |
| 明心状态 | 开头A → 结尾B |
| 钩子 | 结尾留什么 |
| 配比 | 现实% vs 心界% |

### （五）前100章节奏骨架（四幕）

1. **第1-20章**：明心日常，工作线爆，心界初入（王城崩乱＋问天童），世界观用故事建立，读者第一次尝到智爽＋暖爽。
2. **第21-45章**：家庭线爆，双线危机叠加，心界谜团展开，明心第一次真正看破＋放下一个心结。
3. **第46-70章**：关系线爆，三线交汇，明心最低谷，心界大事件（王城危机），第一次重大反转。
4. **第71-100章**：明心爬起，三线各有阶段性解决，心界之谜阶段性揭示，为第二时代埋钩。

## 六、写法铁律（随设计补充，写入章节卡时严格执行）

- 人物活、不点破象征（金算盘不等于贪婪，他爱吃糖葫芦、怕冷、记得母亲缝的鞋）。
- 明心父母是好人、是暖色：不写父母的不是、不写家人生病／欠债，不让他们成为危机的来源；家庭压力来自明心自己（报喜不报忧、亏欠、期待）。
- 智爽＝看破、心头一亮；暖爽＝被看见、心里一暖。不写打脸、无敌、秒杀。
- 经典：关键处点题、随人物人生自然带出、可做悬念线索；原文不得编造。
- 每章 3000-3300 字（目标 3000+，最低 2800 兜底；字数＝汉字＋标点）。
- 禁止破折号、连续句号、AI 高频句式（不是……而是、忽然、这一刻、原来……等）。
- 幽默、烟火气必须有；明心也要出丑。
