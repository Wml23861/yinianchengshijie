# 41_千万字卷章规划

> 全书的「卷 → 时代 → 篇章 → 小篇 → 章节」完整结构与字数规划。
> 总目标：**千万字以上，约 4000 章，每章 2800-3300 字（最低 2800 字）**。
> 结构层级：三大卷（长周期大分段）→ 九大时代（叙事骨架，CLAUDE.md 权威）→ 篇章 → 小篇 → 章节。
> 注意：本章节/字数是**规划**，实际创作中随故事浮动（宪法：故事完整性优先于字数；宁可少写不注水）。方向和顺序（九大时代由浅入深）不可变，具体章数可浮动 ±20%。
> 每章拆短（2800-3300 字，最低 2800 字）是番茄发布需求：一章太长读者厌烦，拆成多章节更新更友好。

## 六、字数原则（CLAUDE.md 第七十四条 + 番茄发布需求）

1. 每章 **2800-3300 字**（最低 2800 字），目标 3000 字左右。
2. **故事完整性优先于字数**：一个场景 3300 字写不完，可以加；故事只需 2800 字，不为凑 3300 字注水。
3. 一章一个「事件单元」，一章太长读者厌烦，拆成多章更新。
4. 严禁为了凑字数：重复解释、重复心理、重复环境、重复对话。
5. 千万字靠「主线 + 时代 + 人物 + 支线 + 众生 + 心性成长 + 世界变化 + 经典 + 伏笔 + 因果」共同组成，不是机械重复。

## 七、与 38/39 的关系

- **38_第一卷大纲**、**39_前100章章节卡**：是第一卷**开头部分**的精编细纲。
- 本规划给出 4000 章全景；38/39 按本规划扩展——第一时代共 360 章，39 目前细化开头的若干章，其余待创作推进时逐步细化。

## 八、浮动与调整规则

1. 章数、字数可浮动 ±20%，但**九大时代的顺序与方向（由浅入深、由执着到清明）不可变**。
2. 每完成一个时代，重新校准该时代剩余章节与下一时代的规划（见 23_长篇连续性检查规则）。
3. 发现某时代内容确实不足时，宁可缩短，也不注水（宁可少写）。
