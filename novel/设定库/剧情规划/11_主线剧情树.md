# 11_主线剧情树

> 明心觉醒之路的主线脉络。主线 = 从「被念头控制」到「无所住而生其心」。
> 每个节点标注：时代、关键事件、明心变化、对应迷失。

---

## 主树干

```
【起点】现实崩塌 → 坠入心界（第一时代·尘中少年）
        │
        ├─ 看见崩乱的心国王城（我是谁？这是哪儿？）
        │
        ├─ 逐一对峙念头众生（生存层：贪/嗔/痴/慢/疑）
        │        └─ 关键节点①：说出「我看见你了」→ 第一缕清明
        │
【第二时代·欲海初渡】
        ├─ 四相魔君现世（我相/人相/众生相/寿者相）
        ├─ 越反抗越强 → 关键节点②：不认同而非战胜（破执）
        │
【第三时代·情天风暴】
        ├─ 现实分手 + 心界情天
        ├─ 关键节点③：理解一个人 ≠ 占有他（放手）
        │
【第四时代·名城之困】
        ├─ 排名 + 现实身份焦虑
        ├─ 关键节点④：身份之外有一个在看的人（事上磨练初启）
        │
【第五时代·念国之乱】
        ├─ 念头纷飞，越分析越乱
        ├─ 关键节点⑤：见性第一瞥——「找心的那个就是心」
        │
【第六时代·识海迷宫】
        ├─ 内在大分裂（五蕴/念头众生内乱）
        ├─ 关键节点⑥：各归其位，不令而从（万法归一）
        │
【第七时代·空门无门】
        ├─ 现实 vs 修行的双重考验
        ├─ 关键节点⑦：知行合一——知道并且做到
        │
【第八时代·道境无为】
        ├─ 越控越乱 → 顺势而为
        ├─ 关键节点⑧：返本归真——放下所有身份
        │
【第九时代·无界明心】
        ├─ 无明天魔：「所有修行都是你的欲望」
        ├─ 关键节点⑨：连觉醒的执着也放下（无所住）
        │
【终点】回归现实，普通场景，明心没有像过去那样反应
```

## 主线的三大悬念（CLAUDE.md 第二十九、三十卷）

1. 心界究竟从哪里开始？为什么明心能进入？
2. 自性为什么从不出现？
3. 明心究竟是在进入心界，还是在认识自己？

**终极悬念**：不是「谁是最终反派」，而是「『我』到底是谁？」贯穿全书，直到最后读者不是得到概念答案，而是经历一次自我观察。

---

## 主线推进规则

1. 主线不靠「升级」推进，靠「看见/放下/承担」推进。
2. 每完成一百章检查主线是否推进（见 23_长篇连续性检查规则）。
3. 主线节点之间允许大量生活、支线、众生故事填充，但方向不可偏离（由执着到清明）。

## 节点② 破执 详细设计（51-150 章，2026-09-04 立约）

> **核心命题**：「我相/法相/人相/众生相/寿者相」= 佛教"诸相非相"的"相"，是 5 个"我"的执着面相，不是 5 个反派。
> **节点② 不是"战胜"四相**——是「不认同也不战胜，看见他们也苦」。
> **5 阶段对应 5 魔君**：
> - 我相（91-100）= "我"的执着（最直接）
> - 法相（101-110）= "法"的执着（"我应该这样"）
> - 人相（111-120）= "我应该如何被人看"的执着
> - 众生相（126-135）= "我是与众不同的我"的执着
> - 寿者相（141-150）= "我要活成某种样子"的执着
> **2 阶段结构**：
> - **51-100 初级版** = 看见"我相"是执着（91-100 我相首现）+ 100 章王城门口转身走（看见自性不需"进"）
> - **101-150 完整版** = 看见"诸相"都是执着 + 看见他们也苦 + 不"战胜"也放下
> **关键对照**：
> - 51-100 段一/段二/段三/段四 = 家庭/工作/周薇/自性 4 线汇合
> - 101-150 段一/段二/段三/段四 = 工作深入/家庭深入/身份焦虑/三线汇合
> - 51-150 整体 = 节点② "从看见我相 → 看见诸相 → 不战胜"
