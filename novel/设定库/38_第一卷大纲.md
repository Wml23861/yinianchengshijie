# 38_第一卷大纲（入道）

> 第一卷·入道 = 从「被念头控制」到「看见念头」。对应九大时代的第一至四时代，第 1-1200 章。

## 三、各时代核心

### 时代1 尘中少年（第1-300章 · 生存）

- 核心：让读者喜欢明心、好奇世界、产生悬念；明心从「强撑」到「承认撑不住」，再学会「看见」。
- 关键场景：崩塌之夜（现实崩溃+坠入）→ 心国王城（崩乱）→ 五蕴大臣 → 情绪即天气 → 国库空虚 → 问天童之问 → 城墙黑雾 → 面对赤炎（嗔）→ 第一缕清明 → 深入五蕴 → 遍历念头众生。
- 明心变化：从「我要镇压这座城」到「第一次没有打，而是看见」；说出第一句「我看见你了」。
- 经典：《心经》照见五蕴皆空、《道德经》自胜者强。
- 红线：开头不解释世界观，只让明心「经历」；明心嘴硬、想变强、逃避。

### 时代2 欲海初渡（第301-600章 · 欲望）

- 核心：四相魔君（我相/人相/众生相/寿者相）逐一现世，明心越反抗越深陷，学会「不认同」而非「战胜」。
- 秘密：四相不是外敌，是「我」的四种执着，且曾保护过童年明心。
- 明心变化：从「我要变强」到「我先看清」；第一次真正「破执」。
- 经典：《金刚经》无我相人相众生相寿者相、应无所住而生其心。

### 时代3 情天风暴（第601-900章 · 关系）

- 核心：明心在现实（分手、亲子、友情）与心界双重关系困境中，学习「放手」与「真链接」。
- 明心变化：从「要别人理解我」到「我先理解别人」；学会「理解一个人，不等于占有他」。
- 经典：佛家离欲、儒家发乎情止乎礼、道家相忘于江湖。

### 时代4 名城之困（第901-1200章 · 身份）

- 核心：明心在身份、排名、角色之间，发现所有身份都无法定义「我」。
- 明心变化：从「用身份证明自己」到「身份之外有一个在看的人」。
- 经典：阳明心学致良知、知行合一、《道德经》自见者不明。

## 四、第一卷写作红线（第一卷不能急）

1. **不急着讲大道理**：开头只做「让读者喜欢明心、好奇世界」。
2. **明心前期嘴硬、逃避、想变强**，不能一开始就通透、慈悲。
3. **每章只移一块石头**（CLAUDE.md 第四十三条）。
4. **现实线贯穿**：工作、周薇、母亲，不脱离现实（映照法则）。
5. **明心不突然顿悟**：允许困惑、失败、倒退。
6. **众生不被「打败」**：被「看见」，转化是反复的。
7. **先渡己、不居高临下**：明心是「同样在路上的人」，不是「即将开悟的人」（见最高创作愿）。

## 五、第一卷结束时的状态

- 明心：不再「变强」，学会「看见」；第一次真正「破执」。
- 世界：心国王城从崩乱边缘到裂缝停止扩大。
- 现实：明心第一次没有为掌声做选择。
- 悬念：第二重·欲海翻涌，四相魔君转护法的伏笔埋下。
