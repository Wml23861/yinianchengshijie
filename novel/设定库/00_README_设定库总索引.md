# 《心上众生》设定库总索引

> 本目录是《心上众生》千万字长篇的**唯一权威资料库**。CLAUDE.md 是创作总宪法，本目录是宪法的落地实现。
> 创作任何章节前，先读 CLAUDE.md，再按需读取本目录对应文件。

## 权威关系

- **唯一宪法**：CLAUDE.md（自动加载，唯一权威宪法）。原心界_创作宪法_1/2 的独特内容（六部/七情/烦恼、念头众生二十类、九种运行规律、皇帝=镜子、成长九阶段、角色设计铁律、读者可实践原则、禁止事项三十条、终极文学原则、工作模式）已全部并入 CLAUDE.md。
- **设定权威**：本目录（设定库），是 CLAUDE.md 核心设定的落地实现（详细人物、世界、剧情、伏笔数据）。
- **旧版设定文件已清理**：世界观、修炼体系、人物、势力、大纲、时间线、章节创作规则等旧文件已删除，不再保留。

## 核心整合决策（已确认）

1. **结构**：以 CLAUDE.md（唯一宪法）为唯一权威。人物体系采用宪法「念头众生二十类 + 政治体系」，弃用旧「九大势力」。正文已作废，从头按此体系创作。
2. **心力**：「心力光粒」重定义为**清明度**的可见象征，不是战斗力。明心的成长 = 执着减少 + 看见增加 + 清明增加，不是力量变大。
3. **数量原则**：宁可减少数量，也要保证人物、故事、世界观具有差异性。禁止为了凑数制造重复。

## 使用规则

1. **写前必读**：CLAUDE.md + 43_人类化写作规则 + 当前时代总纲 + 主要人物档案 + 伏笔库 + 时间线 + 对境库 + 高频词。
2. **写后必更**：章节索引、人物状态、时间线、伏笔、对境追踪、高频词。
3. **冲突裁决**：故事真实 > 人物真实 > 世界连续 > 读者体验 > 思想深度 > 语言美感 > 字数。
4. **核心设定不得擅改**：不确定时查本目录；仍无法确定，建立待确认记录，不得偷偷改核心设定。
