# 《心界》设定库总索引

> 本目录是《心界》千万字长篇的**唯一权威资料库**。CLAUDE.md 是创作总宪法，本目录是宪法的落地实现。
> 创作任何章节前，先读 CLAUDE.md，再按需读取本目录对应文件。

## 权威关系

- **三部宪法并存**：CLAUDE.md（自动加载，第一版）、心界_创作宪法_1.md（版本1.0，含政治体系/六部）、心界_创作宪法_2.md（总纲版，含皇帝-镜子设计）。三者是同一部《心界》宪法的不同版本，内容互补，本设定库已全部整合。
- **设定权威**：本目录（设定库），是三部宪法核心设定的落地实现。
- **旧版设定文件已清理**：世界观、修炼体系、人物、势力、大纲、时间线、章节创作规则等旧文件已删除，不再保留。

## 核心整合决策（已确认）

1. **结构**：以 CLAUDE.md「九大时代 + 九重世界」为唯一权威，现有「三卷九部 + 九重天」内容映射并入，已写 25 章正文保留为「第一时代·尘中少年」的开篇。
2. **心力**：「心力光粒」重定义为**清明度**的可见象征，不是战斗力。明心的成长 = 执着减少 + 看见增加 + 清明增加，不是力量变大。
3. **数量原则**：宁可减少数量，也要保证人物、故事、世界观具有差异性。禁止为了凑数制造重复。

## 使用规则

1. **写前必读**：CLAUDE.md + 当前时代总纲 + 主要人物档案 + 伏笔库 + 时间线 + 对境库 + 高频词。
2. **写后必更**：章节索引、人物状态、时间线、伏笔、对境追踪、高频词。
3. **冲突裁决**：故事真实 > 人物真实 > 世界连续 > 读者体验 > 思想深度 > 语言美感 > 字数。
4. **核心设定不得擅改**：不确定时查本目录；仍无法确定，建立待确认记录，不得偷偷改核心设定。
