# 12_支线剧情树

> 支线 = 各人物独立于明心的成长线 + 众生故事 + 现实对境 + 势力内部线。
> 支线服务于主线，但每条支线的人物都有自己的欲望、痛苦、成长，不是工具人。

---

## 一、核心人物支线（贯穿多时代）

### 赤炎将军：从愤怒到守护之火
- 第一阶段：愤怒保护自己（易怒的将军）
- 第二阶段：开始怀疑力量（明心问「疼吗」）
- 第三阶段：发现自己害怕失去
- 第四阶段：第一次承认恐惧（正文第10章收火）
- 第五阶段：从控制火焰到转化火焰（火不再是武器，是光）
- 终点：焚城从「愤怒之城」变「守护之城」

### 无厌侯：从囤积到创造
- 松手 → 又攥紧 → 再松手 → 反复
- 明心什么都没做，只是「坐着」，触动了他
- 从囤积金砂到让金砂流动（创造价值）
- 终点：金砂不再是执念，是资源

### 天骄侯：从排名到放下
- 永远站最高 → 排名波动（明心威胁了排名体系）
- 从「排第一」到「帮别人排得更好」
- 终点：放下排名，找到比排名更重要的东西

### 梦痴：从逃避到面对
- 制造美梦 → 被明心看见孤独
- 从逃避到面对：第一次不做梦，醒着
- 终点：成为梦想导师（帮人用梦照亮现实，而非逃进梦）

### 狐疑先生：从怀疑到洞察
- 看透一切疑点，看不到答案
- 开始怀疑自己的怀疑
- 终点：怀疑用得好就是洞察

### 红绫夫人：从占有到放手
- 以情丝缚人 → 自己的情丝开始松动
- 终点：从执着占有到慈悲放手

### 少年侍读：从引导到合一
- 引导者 → 追问者 → 陪伴者 → 渐隐 → 合一
- 终点：明心不再需要外在的「初心」

### 四相魔君：从敌人到护法
- 我相/人相/众生相/寿者相 → 转化为四面护法

## 四、支线使用规则

1. 支线人物有独立成长线，不是工具人（CLAUDE.md 第一百一十三条）。
2. 支线不能喧宾夺主——明心仍是核心（见 23_长篇连续性检查规则·百万字检查）。
3. 支线之间可有交集，但每个势力只有一条主线（防止重复）。
4. 支线的收束要回馈主线（例如赤炎的转化，让明心第一次真正「看见」一个人）。
