## 一、章节元数据格式

每章登记：

| 字段 | 说明 |
|------|------|
| 章节号 | 全局递增（已写至6章） |
| 标题 | 章节标题 |
| 所属 | 时代/卷/部（按九大时代归档） |
| 时间 | 现实时间 + 心界时间 |
| 地点 | 主要场景 |
| 人物 | 出场人物 |
| 事件 | 核心事件 |
| 主题 | 修行课题/移石 |
| 经典 | 使用的经典（佛/道/儒） |
| 伏笔 | 本章埋设/回收的伏笔编号 |
| 对境 | 现实对境编号 |
| 心力 | 清明度变化 |

## 三、章节文件命名（CLAUDE.md 第三十二卷）

- 统一 `NN_第N章_标题.md`（如 `01_第一章_深夜两点.md`）。
- 禁止 `final/new/new2` 等后缀。

## 四、章节内部格式（CLAUDE.md 第三十三卷）

- 第一行：章节标题。
- 空一行，开始正文。
- 正文禁止出现作者说明、剧情总结、「本章主题」「作者的话」「下一章」「读者」等。
