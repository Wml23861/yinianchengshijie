## 三、写作铁律（不可违反）

- **连续句号铁律（最高优先级，硬门槛）**：正文叙述中不得出现「短句。+ 后句」的碎片化断句、不得出现句号后紧跟几个字短句再句号；一个自然段句末符（。？！…）≤3。`硬规则自检.py` 已内置检测，此项 [X] 即整章不通过，其它项不评分。
- 结论由 B 定；你写完先自查，发现 AI 痕迹、破折号、字数不足等，自己先改。
- 每章 **3000-3300 字**，目标 **3000 字以上**，最低 **2800 兜底**，第一遍就写足，不精炼到不足。
- 零破折号、零英文、零「忽然/这一刻/仿佛/真正的/原来」、金句稀缺（0-1 句）、禁止连续同构句、禁止每章顿悟。
- **写心界人物前必查登场记录（第 21 章教训，P0 级防再犯）**：动笔写任何一个心界人物（尤其五大臣、念头众生）之前，先 `grep` 前文 + 查 `36_心界众生谱.md` 的「登场记录」行，确认这个人是不是已经登场过、当时用什么称谓、说过什么关键话、和明心的关系到了哪一步。**已经登场过的人物一律按重逢写，称谓沿用既定（五大臣自称「臣」、称明心「王/您」），不得当新人写、不得崩称谓、不得重复他早先说过的话。** 明心没有失忆设定，认得的都记得。
- 不奉承、不替读者/人物/作者悟，先渡己、不居高临下。

## 三·附：一遍过写作自检清单（效率铁律）

> 目标：正文**第一遍**就过 `硬规则自检.py`，不写一遍审一遍改一遍。**边写边查，不靠脚本事后报错。** 第 18 章教训：写短了再补、写完再改标点，是最耗时的返工。

### 0. 动笔时即时打断（AI 味在生成时掐掉，不是写完靠检测器抓）

> 脚本能查的（字数、标点、禁词）可以写完再兜底；**AI 味这种软质感，脚本查不到，只能靠外部检测器事后标疑似，这就是「被人追着兜底」的根源。** 所以 AI 味必须在写每一句的当下打断，不能留到写完。

AI 味的本质是「平滑」：句句工整、句句有意义、前后呼应、零杂质，而 AI 生成时默认滑向平滑。写每一句之前，问三句：

1. **这句是不是顺到没有毛边？** 太顺就是太平滑。真人说话、动作、念头都有毛边，把恰到好处的句子写破一点。
2. **我是不是在替别人总结？** 替人物点破、替读者解释、演完还补一句定义的，当场删掉那句，停在动作上。
3. **这段是不是太干净？** 一整段都干净，就放一句不干净的进去：说一半、说错、重复、一句没结论的话。

平滑有七张脸，生成时认出哪张，当场打断：

1. 点破脸：演完还补总结（「话说得硬，眼睛却不再往水面落」）。
2. 对称脸：两半对仗、否定对称（「没回那个回字，也没打那行真话」）。
3. 量化脸：给情绪上刻度（「松了那么一点点」）。
4. 模板转场脸：幻境和现实用固定套路（「睁开眼，还坐在」「水声远，换成别的声音」）。
5. 金句收尾脸：三短句递进漂亮升华（「它待在那儿，天也没塌」）。
6. 执行设定脸：象征物机械地随情绪变（衣裳灰变亮）。
7. 叠词脸：白晃晃、灰蒙蒙、凉飕飕、咕嘟咕嘟扎堆。

> 写的时候觉得「这句写得太好了」，停下来，多半是平滑脸，写破它。

### 1. 字数（动笔就写够，别写短了再补）
- 目标 **2900-3000 字**（汉字+标点，脚本口径），留余量，别贴 2800 兜底。
- 估算：约 45-55 段，叙述段每段 60-90 字（2-3 句）。对话短行是天然占行不占字，字数靠叙述段撑。

### 2. 标点三铁律（逐句边写边数，别等脚本报错）
- **单句逗号≤3**：一句话（到。？！…为止，**含对话引号内**）逗号最多 3 个，超了就拆句。
- **段落句末符≤3**：一个自然段里。？！… 加起来最多 3 个，超了就拆段。
- **禁碎片短句**：叙述里「≤10 字、且无逗号/顿号/冒号」的短句后接句号、且后面还跟句子 → 违规。改法：短句后改逗号并并到下一句。
  - 例：坏 `明心没应声。他想起从前` → 好 `明心没应声，想起从前`。
  - 高频陷阱词：`X问` `X说` `X没应声` `X应着` `X没再劝` 后面若还接句子，一律改逗号合并。

### 3. 对话归因格式（专治逗号超3）
- 用「完整句。」X说，「新句。」：前引号内先结句（。？！），再归因，再开新引号。
- **不用**「“半句，”X说，“半句”」中缀式：引号内逗号 + 归因后逗号 + 后引号内逗号会累加超 3。
  - 例：坏 `“对了，”母亲说，“你爸养了几只鸡，这两天下蛋了”`（对了，+说，+鸡，=3 已到顶，再加就超）
  - 好 `“对了。”母亲说，“你爸养了几只鸡，这两天下蛋了。”`

### 4. 零禁用词（边写边避）
忽然 / 这一刻 / 仿佛 / 真正的 / 原来 / 缓缓 / 轻轻 / 静静 / 慢慢 / 越X越（含「越来越」）/ 破折号 / 英文 / 半角标点 / 半角引号。

### 5. 写完只跑一次脚本，一次过
- `python novel/工具/硬规则自检.py <文件>` 应一次过。
- 没过 = 没按上面清单写，回到**对应句**改，不要整段推倒重写。
- 每写完 10 章，把新踩的坑追加进本清单（持续学习）。

### 6. Write 前自检（第 20 章教训，防整体作废）
- 提交的正文必须**纯正文**：不含思考批注、不含「（让我改）」「等等，这里…」等自言自语、不含草稿痕迹。
- 引号一律**全角**「“”」，半角英文引号 `"` 会触发硬失败。
- 写完先扫一眼：有没有把上一版草稿、改动备注一起粘进正文。

## 四、写作流程

1. **读资料**：CLAUDE.md、43、章节卡、人物、伏笔、时间线、前两章。
2. **设计章节**：本章目的/人物/冲突/欲望/障碍/情绪变化/关键场景/智慧触点/结尾状态（CLAUDE.md 第七十二条）。
3. **写正文**：第一遍就写足 3000 字，一章一个事件单元。
4. **自查自审**：跑 CLAUDE.md 第十五卷八轮审查 + 43 维度，发现问题先改。
5. **更新记录**：写进 创作记录/（字数、状态、问题、修复）；并把 47_中间人转发话术.md 顶部改成「正等 B 审第 N 章」。
6. **交 B 审核（可选）**：写完可交 B 审，但不等 B 结论也可继续写下一章；B 给了「不通过」提示词，再按 N 处改。
