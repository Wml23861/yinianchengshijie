# 48_章节设计模板（写一章前可填参考；**2026-09-02 二次修订：去掉"必填"硬定**）

> 用途：每章动笔前 5 分钟参考这份设计模板，让作者**先想清楚再写**。
> 这是 **建议前置参考**：不填也可以写，但**填了会减少返工**。
> **2026-09-02 二次修订**：填空数**不固定 4 个**——按章节类型灵活（冲击章可填 4 填空；纯日常章/纯对话章/纯心界章可只填关键的 1-2 个）。每空字数**不硬限 50 字**——按"那一段到底是什么"决定长短。

## 一、4 填空（**2026-09-02 二次修订：参考结构，不硬性必填**）

> **4 填空是设计辅助工具，不是 P0 硬关**。下面是 4 个常见的"本章在做什么"的提问，**作者按本章类型选取回答**。

### 1. 本章认知翻转

读者对什么**老东西**的看法会被推翻？

> 不是反转剧情。是翻转读者对某个人物、某件事、某句话的旧看法。
> 例：明心一直以为父亲冷漠 → 这章发现父亲那天被公司辞退 → 父亲也在保护他。
> 例：明心以为赤炎只是愤怒 → 这章发现赤炎小时候也是个爱笑的孩子。
> 例：明心以为张三恨他 → 这章发现张三在替他挡了一件事。

**适用**：冲击章 / 揭示章 / 部分日常章（揭露某个人的新面）。
**不适用**：纯过渡章 / 纯对话章 / 纯心界章——本章无（"本章无"即可，不必硬想一个）。

### 2. 本章主角代价

主角付出一个**具体的、不可逆的、或很难挽回**的东西。

> 不是"心里难过"。是错过电话、退掉票、丢了东西、说错话收不回、关系破裂。
> 例：明心挂掉母亲的电话 → 第二天母亲住院。
> 例：明心没有去接女儿 → 女儿发烧三天。
> 例：明心在朋友圈屏蔽了老同事 → 对方后来查出癌症晚期。

**适用**：大多数章节（小到一只杯子的代价也算）。
**不适用**：极少数"主角纯观察"章——本章无（不必硬找代价）。

### 3. 本章错误正确

主角**做对了什么，反而坏了**？

> 这是最反 AI 的一条。AI 默认"做对→有奖励"，但人生不是游戏。
> 例：明心劝朋友离婚 → 朋友第二年复婚并怪他 → 朋友丈夫后来出事。
> 例：明心给老板提了正确建议 → 老板升职了 → 新领导上任把明心边缘化。
> 例：明心坚持要给陌生人让座 → 那人是个骗子 → 老人在站台站了 20 分钟。

**适用**：冲击章 / 战斗章 / 揭示章。
**不适用**：纯日常章 / 纯对话章 / 纯心界章——本章无。
**注意**："本章无"完全允许——**不必硬卡"接下来 3 章内必须有 1 次"**，按创作节奏自然出现。

### 4. 本章结尾事实

章节结束时，**一个客观的、和开头不同的事实**是什么？

> 不是心情。是事实。
> 例：开头明心手上有钥匙 → 结尾钥匙在桌上。
> 例：开头明心和母亲通话 → 结尾明心查母亲的通话记录（事实）。
> 例：开头张三在办公室 → 结尾张三在天台抽烟（位置变了）。
> 例：开头明心没吃饭 → 结尾明心吃了一碗面（事实在变）。

**适用**：所有章节——结尾是章节的"落点"，事实变化是基本要求。
**不适用**：极少数"主角在睡前闭眼"章——本章无（"明心睡了"即可）。

### 5. 本章能量点（**2026-09-02 新加 + 二次修订**，铁律四；**至少记 1 条即可**）

本章让读者**重新打开哪一处感知**？（不是事件、不是道理，是**一寸一寸的感知**）

```
[ ] 呼吸 / 身体  ━━━━━━━━━━━━━━━━━━
[ ] 时间  ━━━━━━━━━━━━━━━━━━
[ ] 天地（风/雨/光/树）  ━━━━━━━━━━━━━━━━━━
[ ] 他人  ━━━━━━━━━━━━━━━━━━
[ ] 自己  ━━━━━━━━━━━━━━━━━━
```

**至少记 1 条具体到"这一刻、这一段"**（极致 1 条即过，不必 5 项都填）。

**示例（正）**：
```
本章能量点（至少 1 条）：
- 呼吸/身体：明心走在路上，脚底板感到一颗小石子硌了一下（第 3 段）
- 或者——时间：母亲在厨房的背影，一勺一勺地舀，明心数了三下，没数清（第 8 段）
- 或者——天地：风从江上吹过来，带着柴油味（第 12 段）
- 或者——他人：老人抬手的瞬间，明心看见他袖口破了一个三角形的口（第 20 段）
```

**示例（反 / 必须打回）**：
```
本章能量点：
- "明心感受到了温暖"
- "明心看见了生活的真谛"
- "明心被感动了"
- "用了'风吹过来'骨架"
- "用了'半句话'对话"
```

（**正例是写"那一段发生了什么"，反例除了"点破情绪"，也包括"用了哪种骨架"——骨架是死的，那一寸是真的**。）

**详细规则**：`novel/设定库/写作流程/53_能量传递创作原则.md`。

## 二、删哲理自检（写完正文后必跑）

把这一章**所有以下段落**整段删掉：

- 直接说"人生就是这样""原来……""真正的……""其实……"
- 总结性心理活动（"这一刻他终于明白……"）
- 金句/排比/三个"不是 X 是 Y"
- 经典原文引用（除非是角色真的在念经）
- 任何"作者借人物讲哲理"的段落

然后问自己：

```
[ ] 删完之后，剩下 ≥60% 的内容仍然：
    - 有人物欲望在驱动
    - 有具体动作在推进
    - 有至少一个事实变化
    
[ ] 删完之后，主角还"在做事"，不是在"想事"
    
[ ] 删完之后，至少一个配角有自己的私事，不是只服务明心
```

**剩不到 60% → 本章 P0，必须重写。**

### 删哲理自检扩展（**2026-09-02 新加，铁律四；2026-09-02 修订：去限制性清单**）

> **2026-09-02 修订**：5 项自检**不限定形态**——是"可观察的感知特征"，不是"必选哪种骨架"。括号里只是举例，不是清单。

```
[ ] 删完哲理后，剩下的内容里，**至少 2 处让读者"重新打开一寸感知"**？
    （不是金句，不是大词，是具体的：风怎么吹、光怎么动、人怎么动、手怎么放——具体形态自由）
    
[ ] 本章有没有"人物的身体反应"？
    （眼皮跳 / 肩膀酸 / 喉咙紧 / 手指凉 / 后背热 / 胃里一动 / 喉咙发紧——具体形态自由）
    
[ ] 本章有没有"具体到一寸的风 / 光 / 声音 / 触感"？
    （不是"微风拂面"——是"风从左边来，吹动了她头发末梢那几根白的"——这一刻这一寸）
    
[ ] 本章有没有"陌生人的一个小动作，跟主题无关"？
    （蹲下倒石子 / 抬手挡风 / 把筷子放下又拿起来 / 蹲在路边数硬币——具体形态自由）
    
[ ] 本章有没有"沉默的、有距离的、没解决的"段落？
    （不是"我终于明白"——是"老人没说完。明心没问。桥下水声很大"——形态自由）
```

**5 项里至少 3 项 = 通过**。少于 3 项 = 本章 P1，必须改。

## 三、4 填空 + 自检的填法示例

### 反例（AI 喜欢这么写，必打回）

```
认知翻转：明心意识到自己一直活在别人的期待里
代价：明心心里很难过
错误正确：明心学到了一个道理
结尾事实：明心决定改变
```

这种填空 = 没填。等于让 AI 自由发挥 = 流水账。

### 正例（按这个水准填）

```
认知翻转：明心一直以为母亲打电话是"例行关心"，
          这章发现母亲打来的那天，刚被小区里的老太太当面骂"养废物"
代价：明心挂掉电话后，那个电话再也没回拨过去；
      母亲三个月没再打来
错误正确：明心这周主动多打了三个电话（他以为自己在弥补），
          母亲接了以后说"你是不是闯祸了要钱"
结尾事实：明心的手机通话记录里，删除的号码从 0 个变成 1 个
```

4 个空都有具体人物、具体动作、具体事实。AI 拿到这个，没法只讲道理。

## 四、章节类型（**2026-09-02 二次修订：参考分类，不是封闭的 6 种**）

> **章节类型是参考分类，不是封闭的 6 种**。下面列出 6 种常见类型，**作者可按本章实际内容自由命名新类型**（如"和解章""重逢章""失物章""等待章""散步章"等任何新形态都允许）。

| 类型 | 认知翻转 | 代价 | 错误正确 | 结尾事实 |
|---|---|---|---|---|
| 冲击章 | 推荐填 | 推荐填 | 推荐填 | 推荐填 |
| 过渡章 | 可不填 | 小代价 | 本章无 | 1 个事实 |
| 战斗章 | 必有（对人不对事） | 必有（伤/死/失去） | 必有（赢反而失去） | 战局有变 |
| 悟道章 | **本章无（克制）** | 必有 | 必有 | 必有 |
| 日常章 | 小翻转 | 小代价 | 本章无 | 1 个事实 |
| 揭示章 | 推荐填（最大翻转） | 推荐填（有人付出） | 可无 | 必有 |
| **新类型** | 作者按实际决定 | 作者按实际决定 | 作者按实际决定 | 作者按实际决定 |

**悟道章的克制**（保留为参考原则）：明心不能这章突然想通一切。想通必须来自前几章的积累，这一章只是"最后一片叶子落下"。

**所有"必有""必填"都是"推荐"——作者可按本章实际调整**。

## 六、对话形式 + 上下文一致性自检（**2026-09-01 加**，写前 2 分钟 / 写后 1 分钟）

> **2026-09-01 第 51 章事故后扩写**：本节是格式硬关的入口。详细规则见 `52_对话与标点格式手册.md`（**必读**）。

### A. 对话格式写前规划（**2026-09-01 硬关化**）

本章预计对话超过 4 句的，必须先想清楚：

```
[ ] 对话每句独立成段（前后空行隔开）—— P0
[ ] 对话全部用全角""包裹 —— P0
[ ] 段首不能是句号 —— P0
[ ] 段中不要"。"+主语"碎片化（用，；：承接）—— P0

[ ] 至少 1 处用动作打断对话（低头刻字/手里的铁丝没停/把袜子脱了扔在床脚）
[ ] 至少 1 处用停顿打断（"老人嗯了一声没接下去"）
```
