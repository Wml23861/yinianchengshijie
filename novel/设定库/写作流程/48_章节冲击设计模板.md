# 48_章节冲击设计模板（写一章前必填，没填完不准开正文）

> 用途：每章动笔前 5 分钟填这 4 填空 + 1 自检。填不出来，这一章就先不写，去想清楚再写。
> 这是 **强制前置关卡**：不填 = 不写 = 不算"动笔"。

---

## 一、4 填空（每章必填，每空不超过 50 字）

### 1. 本章认知翻转

读者对什么**老东西**的看法会被推翻？

> 不是反转剧情。是翻转读者对某个人物、某件事、某句话的旧看法。
> 例：明心一直以为父亲冷漠 → 这章发现父亲那天被公司辞退 → 父亲也在保护他。
> 例：明心以为赤炎只是愤怒 → 这章发现赤炎小时候也是个爱笑的孩子。
> 例：明心以为张三恨他 → 这章发现张三在替他挡了一件事。

如果本章是**纯过渡章**（搬家/赶路/吃饭/没大事发生），可以不翻。
但必须把过渡章**和冲击章**混着来，不能连续 3 章都"不翻"。

### 2. 本章主角代价

主角付出一个**具体的、不可逆的、或很难挽回**的东西。

> 不是"心里难过"。是错过电话、退掉票、丢了东西、说错话收不回、关系破裂。
> 例：明心挂掉母亲的电话 → 第二天母亲住院。
> 例：明心没有去接女儿 → 女儿发烧三天。
> 例：明心在朋友圈屏蔽了老同事 → 对方后来查出癌症晚期。

**没有代价的章节 = 流水账。**
本章至少 1 个代价。可以小（小到一只杯子），但必须**具体 + 不可逆**。

### 3. 本章错误正确

主角**做对了什么，反而坏了**？

> 这是最反 AI 的一条。AI 默认"做对→有奖励"，但人生不是游戏。
> 例：明心劝朋友离婚 → 朋友第二年复婚并怪他 → 朋友丈夫后来出事。
> 例：明心给老板提了正确建议 → 老板升职了 → 新领导上任把明心边缘化。
> 例：明心坚持要给陌生人让座 → 那人是个骗子 → 老人在站台站了 20 分钟。

**没"错误正确"也要写**："本章无"——但接下来 3 章内必须有 1 次。

### 4. 本章结尾事实

章节结束时，**一个客观的、和开头不同的事实**是什么？

> 不是心情。是事实。
> 例：开头明心手上有钥匙 → 结尾钥匙在桌上。
> 例：开头明心和母亲通话 → 结尾明心查母亲的通话记录（事实）。
> 例：开头张三在办公室 → 结尾张三在天台抽烟（位置变了）。
> 例：开头明心没吃饭 → 结尾明心吃了一碗面（事实在变）。

**没事实变化 = 流水账。**
一章哪怕主角想通了，但外界什么都没变，那他想通也是空的。

## 二、删哲理自检（写完正文后必跑）

把这一章**所有以下段落**整段删掉：

- 直接说"人生就是这样""原来……""真正的……""其实……"
- 总结性心理活动（"这一刻他终于明白……"）
- 金句/排比/三个"不是 X 是 Y"
- 经典原文引用（除非是角色真的在念经）
- 任何"作者借人物讲哲理"的段落

然后问自己：

```
[ ] 删完之后，剩下 ≥60% 的内容仍然：
    - 有人物欲望在驱动
    - 有具体动作在推进
    - 有至少一个事实变化
    
[ ] 删完之后，主角还"在做事"，不是在"想事"
    
[ ] 删完之后，至少一个配角有自己的私事，不是只服务明心
```

**剩不到 60% → 本章 P0，必须重写。**

## 三、4 填空 + 自检的填法示例

### 反例（AI 喜欢这么写，必打回）

```
认知翻转：明心意识到自己一直活在别人的期待里
代价：明心心里很难过
错误正确：明心学到了一个道理
结尾事实：明心决定改变
```

这种填空 = 没填。等于让 AI 自由发挥 = 流水账。

### 正例（按这个水准填）

```
认知翻转：明心一直以为母亲打电话是"例行关心"，
          这章发现母亲打来的那天，刚被小区里的老太太当面骂"养废物"
代价：明心挂掉电话后，那个电话再也没回拨过去；
      母亲三个月没再打来
错误正确：明心这周主动多打了三个电话（他以为自己在弥补），
          母亲接了以后说"你是不是闯祸了要钱"
结尾事实：明心的手机通话记录里，删除的号码从 0 个变成 1 个
```

4 个空都有具体人物、具体动作、具体事实。AI 拿到这个，没法只讲道理。

## 四、6 种常见章节类型（参考）

| 类型 | 认知翻转 | 代价 | 错误正确 | 结尾事实 |
|---|---|---|---|---|
| 冲击章 | 必填 | 必填 | 必填 | 必填 |
| 过渡章 | 可不填 | 小代价 | 本章无 | 1 个事实 |
| 战斗章 | 必有（对人不对事） | 必有（伤/死/失去） | 必有（赢反而失去） | 战局有变 |
| 悟道章 | **本章无（克制）** | 必有 | 必有 | 必有 |
| 日常章 | 小翻转 | 小代价 | 本章无 | 1 个事实 |
| 揭示章 | 必填（最大翻转） | 必填（有人付出） | 可无 | 必有 |

**悟道章的克制**：明心不能这章突然想通一切。想通必须来自前几章的积累，这一章只是"最后一片叶子落下"。

## 五、流程位置

```
/设计一章  →  填这 4 填空（200-400 字）  →  落档
/写一章    →  按 4 填空写正文
/审一章    →  用「删哲理自检」+ 4 填空对照正文
```

4 填空稿**永久存档**，放在章节卡 39 之后，正文之前。
