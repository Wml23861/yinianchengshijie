## 一、对话格式（**最核心，事故高发**）

### 1.1 对话每句独立成段（**硬关**）

**规则**：每一行人物直接对话，必须独立成一段，前后空行隔开。

**正例**（你的格式，第 51 章最终版）：

```
"您刻什么？"

"给我儿子。"

"他在哪儿？"

"北京。"
```

**反例**（必须改）：

```
❌ "您刻什么？""给我儿子。""他在哪儿？""北京。"  # 4 句挤一行
❌ 您刻什么？给我儿子。他在北京。  # 删引号
❌ "您刻什么？"老人说"给我儿子。"  # 老人说堆在一段
```

### 1.2 对话必须用全角 `""` 包裹（**硬关**）

**规则**：

- 外层用 `""`（U+201C 左 / U+201D 右）
- 不用 `""`（U+0022 半角）
- 不用 `「」`（方头括号）
- 不用 `''`（除非内层嵌）
- 成对，不残缺

### 1.3 对话标点（**硬关**）

| 类型 | 标点 | 位置 |
|---|---|---|
| 问话 | `？` | 引号内 |
| 陈述 | `。` | 引号内 |
| 感叹 | `！` | 引号内 |
| 话没说完 | `……` | 引号内（用 `……`，不用破折号） |

**示例**：

```
"您刻什么？"
"给我儿子。"
"这可了不得了！"
"我……我也不知道。"
```

### 1.4 段中不要 `。+主语` 碎片化（**硬关**）

**规则**：段落中间的句子，不要用 `。` 后紧跟主语开头（`X说X。X说Y。X说Z。` 这种）。

**正例**（用分号 / 顿号 / 换段）：

```
✅ 老人说三十六了，跟你们年轻人一样整天忙得很；停了一下又说一年回来两趟，回来了也不爱说话，坐一晚上就走了。
✅ 老人又说刻了半拉钟头了也刻不出几个字，这种石栏杆几十年没人管过；他每天这个时候出来走一圈，回去也是坐着。
```

**反例**（必须改）：

```
❌ 老人说三十六了，跟你们年轻人一样整天忙得很。老人停了一下说一年回来两趟。老人又说回来了也不爱说话，坐一晚上就走了。
```

### 1.5 "X 说"动词不连用 3+ 次（**2026-09-02 修订**：参考阈值，不是死锁）

**规则**：

- 同一段内"明心说 / 老人说"连用 3+ 次 → P1 警告（**参考阈值**——对话密集章可酌情，作者按情况判断）
- 改法（4 选 1 或组合）：
  1. **换动词**：`问 / 答 / 嗯了一声 / 停了一下 / 重复 / 补一句 / 抬头 / 低头 / 笑 / 摇头 / 喊 / 催 / 嘀咕 / 插嘴 / 岔开 / 追问`
  2. **拆段**：每句对话独立成段后，`说` 自然分散
  3. **动作打断**：说话时伴随动作（低头、停手、转头、看一眼、手里的铁丝没停）
  4. **省略主语**：连续同主体时，省略"老人说"只用动作

### 1.6 对话与动作的间隔（**格式建议**）

- 短对话 + 短动作 → 各成一段（如"老人抬了下头。"独立成段）
- 长对话 / 长动作 → 同一段内可含多个短句
- 关键规则：**对话独立成段** 比 **动作独立成段** 更重要

## 二、段落规则（**硬关**）

### 2.1 段首不能是 `。`

- ❌ `。明心说X` （段首是句号）
- ✅ `明心说X` （段首是主语）
- ✅ `"X"` （段首是对话）

### 2.2 一个自然段可以有多个句子（**描写段落**）

- 场景描写、环境描写、动作描写，可以一段 2-3 句
- 段落句号 ≤ 3（**2026-09-02 修订**：硬规则脚本检测 + 参考阈值；动作密集章可酌情，作者按情况判断）

### 2.3 段中连接用 `，` `；` `：` 而不是 `。+主语`

- ✅ 用 `，` 连接后续动作
- ✅ 用 `；` 连接并列叙述
- ✅ 用 `：` 引出对话
- ❌ 用 `。` 然后另起主语

## 三、标点总表（**硬关**）

| 标点 | 用法 | 示例 |
|---|---|---|
| `。` | 句末 / 段末 | `明心停下。` |
| `？` | 问句末 | `您刻什么？` |
| `！` | 感叹末 | `这可了不得了！` |
| `，` | 句中停顿 | `凌晨两点，他到了。` |
| `；` | 句中并列 | `他停了一下；又说了一句话。` |
| `：` | 引出 / 解释 | `他说："X。"` |
| `……` | 省略 / 犹豫 / 戛然而止 | `我……我也不知道。` |
| `""` | 对话外层 | `"您刻什么？"` |
| `''` | 对话内层 | `"他说'X'。"` |
| `「」` | **禁用**做引号 | — |
| `——` | **禁用**（破折号） | — |
| `,.;:?!` | **禁用**（半角） | — |

## 四、动作与场景的格式

### 4.1 动作可以独立成段

```
"这栏杆上刻字罚款不罚款？"

老人抬了下头。

"大约不罚。"
```

### 4.2 长动作可成一段

```
老人抬手招呼了一下，明心走到老人身边停下。老人刻字的手在发抖，铁丝划在石栏杆上划一道；老人退后一步眯着眼看，看完又上前再划一道。
```

### 4.3 场景描写独立成段

```
桥上没什么车，桥栏杆上的灯一盏没亮，桥面是灰的。桥下边的水声很轻，桥那头的柳树在风里摆了几下。桥中间站着个老人。
```

## 五、消息/手机/微信格式

手机消息用 `""` 包裹 + 结尾加 `。`（不是 `~` 不是 emoji）：

```
"你做啥我吃啥。"
"妈你明天还做糖醋排骨吗。"
```

不用：
- ❌ "你做啥我吃啥~"
- ❌ 你做啥我吃啥
- ❌ 「你做啥我吃啥」

## 六、违反示例（**常见错误，必查**）

| 错误 | 反例 | 改法 |
|---|---|---|
| 段首句号 | 。明心说X | 删 `。` 或合并段 |
| 4 句对话挤一行 | "X""Y""Z""W" | 拆段 |
| 老人说 4 连 | X说X。X说Y。X说Z。X说W。 | 换动词 / 拆段 |
| 半角引号 | "X" | 改全角 `"X"` |
| 方头括号 | 「X」 | 改全角 `"X"` |
| 段中 `。+主语` | X说X。Y说Y。Z说Z。 | 用 `；` 或拆段 |
| 段末 `~~` | X~~ | 改 `。` 或 `……` |
| 英文缩写 | 明心说OK | 改中文 |
| 引号不配对 | "X。 | 补 `"` |
| 句号堆叠 | X。。 | 删一个 |

## 七、硬规则脚本扩展（**新加**）

`novel/工具/硬规则自检.py` 新增以下检查（**写后必跑**）：

1. **对话未独立成段**：一行内出现 3+ 对 `""`（如 `"X""Y""Z"`）→ P0
2. **段首句号**：段落第一个非空字符是 `。` → P0
3. **段中 `。+主语`**：连续两段都以 `明心 / 老人 / 母亲 / 父亲 / 他 / 她 / 老人` 开头且段尾是 `。` → P1 警告
4. **"X 说"连用**：一段内 4+ 次"X说" → P1 警告
5. **消息未加引号**：直接命名"明心说+无引号内容" + 行尾无标点 → P0
