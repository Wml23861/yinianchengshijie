# 53_能量传递创作原则（写每章必查，写每段必想）

> **新加核心创作要求（2026-09-02 立；2026-09-02 修订：去限制性清单）**。
> 这是《心上众生》区别于所有普通长篇的**第四铁律**。
> 与卷一三铁律并列：环环相扣 / 写出现象底层规律 / 震撼来自看见真相 = 第一铁律群。
> 第四铁律：**让文字完成"能量传递"——读者通过文字，重新打开他原本就拥有的感知能力**。

---

## 一、什么是"能量传递"（定义）

读者读到某一处普通场景、某一段对话时，突然产生一种**无法准确说明的感觉**。

这种"说不清"恰恰是最有力的——它不是逻辑被说服，而是**感知被重新打开**。

文字能完成这种传递时，读者会：
- 突然意识到自己的呼吸
- 突然听见窗外的风
- 突然感受到肩膀的酸
- 突然想起某个亲人的脸
- 突然意识到自己一直低着头
- 突然发现自己已经很久没抬头看天

**这种"被打开"不是被教导出来的，是被唤起的**。读者自己原本就有这种感知能力，只是被生活困住了——忙、焦虑、麻木、攀比、自我怀疑、失眠、手机刷屏、工作压力、人际疲惫、关系消耗——这些东西像一层一层的灰，厚到他们忘了自己原本是能感受天地的人。

**作者要做的不是"教"读者感受，是用一段文字、一个动作、一句对话、一个停顿，把那层灰悄悄吹开一点。**

读者合上书，如果能感到**自己内心比读之前更辽阔、更安静、更能感受天地**——这就是这本书真正在做的事。

## 二、核心原则（**2026-09-02 修订**：方向指引，不做清单）

> **天地是广阔的，生活是丰富的，作者的笔触不应被任何"骨架清单"框住。**
>
> 本铁律只保留**方向**，不规定**具体形态**。下面 5 个维度是创作时可以参考的方向，**不限定章法**——
> 真正的能量场景，永远是作者在那一刻的人物、那一刻的城市、那一刻的天气、那一刻的光线里，**自己长出来的**。

### 维度 1：呼吸 / 身体

让读者重新感到自己是一具活的身体，不是思维。

可以写的方向（仅举例，不是清单）：
- 肋骨、肩膀、喉结的微小变化
- 脚踩在地上、屁股贴着椅面、背靠墙
- 手心是热的、指尖是凉的、脖子后面被风吹
- 纸的毛边、铁丝的反光、布料的褶皱

**禁用**：
- ❌ "他深吸了一口气"（套路化）
- ❌ "他感到前所未有的平静"（直接命名情绪）
- ❌ "空气仿佛凝固了"（空洞大词）
- ❌ "那一刻他明白了"（点破）

### 维度 2：时间

让读者感受到"这一刻"——不是日历上的时间，是有质感的、不可逆的、正在流逝的此刻。

可以写的方向：
- 一个动作写 3 段，让读者跟着慢下来
- 一个瞬间反复看
- 一件重复的事里出现的微小变化

**禁用**：
- ❌ "时间仿佛静止了"
- ❌ "那一瞬间他意识到……"
- ❌ "一切都像慢动作回放"

### 维度 3：天地（风 / 雨 / 树 / 光 / 影 / 温度）

让读者抬头看天——他们已经很久没抬头了。

可以写的方向：
- 不是"天空很蓝"，是"风从左边吹过来，吹动了她头发末梢那几根白的"
- 不是"阳光很温暖"，是"对面楼顶的反光，白得让人眯眼"
- 不是"土地很软"，是"脚底板陷进去一点，又弹回来"

**禁用**：
- ❌ "微风拂面"（成语堆砌）
- ❌ "天空湛蓝如洗"（空洞大词）
- ❌ 任何形容词 + "仿佛"结构

### 维度 4：他人（亲人 / 陌生人 / 路人 / 邻居）

让读者从人物的眼睛，重新"看见"一个原本被忽略的人。

可以写的方向：
- 身上的小细节（袖口磨白、指甲缝里的土、头发末梢分叉、手背的疤）
- 处境（不是他说的，是明心**看见**的）
- 一两个与主题无关的习惯（嚼口香糖、爱摸耳垂、口袋里揣着糖）
- 小动作（筷子放回桌面又拿起来、坐下时手撑一下膝盖、说话时眼睛往左下角瞟）

**核心原则**：人物是**完整的人**，不是工具人，不是道德符号，不是作者的嘴。

**禁用**：
- ❌ 让人物突然说金句
- ❌ 让人物所有动作都"刚好"配合主题
- ❌ 让人物被明心三言两语感动

### 维度 5：自己（孤独 / 疲惫 / 真实 / 完整）

让读者看见**自己**——明心就是读者的"我"。

可以写的方向：
- 小自私（帮别人之前先想自己）
- 小疲惫（不是"身心俱疲"——是"眼睛有点干"）
- 小逃避（答应了不去、想回的消息没回、买了票又退）
- 小愚蠢（一句话能说清的事绕了 5 句）
- 小确幸（路边捡到一片好看的叶子、吃到一口烫嘴的豆腐、远处有人叫他名字）
- 小清醒（某个瞬间他突然发现自己在干什么，但没说出口）

**核心原则**：明心不必每章"悟道"，但他**常常看见自己**——看见就够了，不必立刻变成什么。

**禁用**：
- ❌ "他终于明白" / "原来" / "真正的" / "其实"
- ❌ 任何"作者借人物讲哲理"的段落
- ❌ 把"看见"立刻变成"开悟"（看见 → 命名 → 放下，三拍滑坡）

## 三、5 个可观察特征（**2026-09-02 二次修订**：方向不限，但可观察的"感知被打开"特征必须出现——**极致 1 维比浅尝 5 维强 100 倍**）

> **5 个维度是开放的方向。下面 5 个特征是"感知是否被打开"的可观察信号——不必全过，不必按固定数；写到了就是写到了，没写到不必凑。**

每章**至少触及 1 项**（**极致 1 项即可，不必 5 项都过**）：

1. **"重新打开一寸感知"的具体描写**
   - 不是金句、不是总结、不是大词、不是点破
   - 是具体的：风怎么吹、光怎么动、人怎么动、手怎么放
   - **数量按章节需要**——1 处极致，2 处充足，3 处饱满，不必硬凑

2. **"人物的身体反应"**
   - 眼皮跳 / 肩膀酸 / 喉咙紧 / 手指凉 / 后背热 / 胃里一动 / 手心出汗等真实反应
   - 不是"心理活动的身体版"——是真的身体在反应
   - **出现了即写到，不必每章必有**

3. **"具体到一寸的天气/光线/声音"**
   - 不是"微风拂面"——是"风从左边来，吹动了她头发末梢那几根白的"
   - 是这一刻、这个城市、这个人物眼睛里看到的那一寸
   - **按人物所在的环境决定有没有**——室内章不必硬塞风吹

4. **"陌生人的小动作，与主题无关"**
   - 蹲下倒石子 / 抬手挡风 / 把筷子放下又拿起来 / 蹲在路边数硬币
   - 让生活感回归，让读者想起自己走过的那条街
   - **这一项是"是否做了"的开关，不是"必须做 N 次"的清单**

5. **"沉默/停顿/没解决"**
   - 不是每件事都有结论
   - 老人没说完、明心没问、桥下水声很大
   - 一件事悬着，比"圆满"更接近人生
   - **悟道章 / 揭示章等需要"完整闭合"的章节可以少用；日常章 / 过渡章多写**

**自检方式**：写完本章，回头看——这一章里有没有任何一处，读者读到这里会突然意识到自己的呼吸？如果有，就过了。如果没有，再加。**不要按"5 项打勾"的方式检查**——那会反向机械。

## 四、5 个维度是方向（**2026-09-02 二次修订**：不是清单，不是硬指标）

5 维度（呼吸/身体 / 时间 / 天地 / 他人 / 自己）是给作者一个**回到"自己写到了什么"的对照表**——**不是必填清单**。

维度怎么用：
- 写到一段风吹过来，那是"天地"维度——记下"那一刻我触碰到了什么"
- 写到母亲手指的皱纹，那是"他人"维度——记下"那一刻是谁的眼睛在看"
- 写到明心没问，那是"自己"维度——记下"那一刻沉默里有什么"
- 写到肩膀一沉，那是"身体"维度——记下"那一刻身体在说什么"
- 写到那一刻很慢很长，那是"时间"维度——记下"那一刻时间是怎么过去的"

**维度永远不必凑数**。如果一章写到了极致的"他人"——人物的眼睛在那一刻被写得那么细、那么真——那"天地"和"自己"维度不出现也完全没问题。**一章有一个维度被写到极致，比 5 个维度都浅尝辄止强 100 倍。**

**所以"至少触及 1 维"是参考性引导，不强求；不强求 5 维都写；不强求"最近 N 章 5 维都出现过"——作者自己心里有数即可。**

## 五、6 类反向边界（**2026-09-02 二次修订**：是"破坏者清单"，不是"创作清单"——保留，但作者心里清楚：这是底线不是模板）

> 这些是"破坏能量传递"的反面教材——**砍掉这些东西的清单**。**禁用的清单可以存在，因为它限定的是"不要写什么"，不限定"要写什么"——所以不限制创作方向**。

1. **❌ 直接命名情绪**："他很悲伤" / "他感到孤独" / "他非常痛苦" / "他心里一阵温暖"
2. **❌ 空洞大词**："深邃" / "古老" / "不可名状" / "震撼" / "灵魂" / "宿命" / "永恒" / "一切" / "仿佛" / "缓缓" / "静静"
3. **❌ 点破感受**："他突然明白" / "原来" / "这一刻他终于" / "其实"
4. **❌ 身体 + 情绪绑定**："他感到心头一暖" / "心里一紧" / "心里一松"（"心里"= AI 味）
5. **❌ 总结式环境**："阳光很温暖，照在身上" / "微风拂面，带来春天的气息"
6. **❌ 工具化他人**："老人笑了笑，仿佛在诉说一个古老的秘密"（老人=工具人）

**重要**：禁用清单的条数（6 条）可以按"出现的新破坏模式"动态扩展——比如未来发现"金句腔"是一种新的破坏模式，可以加第 7 条。**禁用的本质是"破坏者识别"，不是封闭数字**。

## 六、删哲理自检扩展（写完正文后跑，加在原 48 自检后）

> **2026-09-02 二次修订**：本节不是"5 项打勾"——5 项里**心里过去 1 项即可**。下面 5 项只是**可观察的提问**，不是"必须满足 N 条"的清单。

```
[ ] 删完哲理后，剩下的内容里，**有没有任何一处让读者"重新打开一寸感知"**？

    （眼皮跳 / 肩膀酸 / 喉咙紧 / 手指凉 / 后背热 / 胃里一动 / 喉咙发紧）
    → **按章节类型决定**：纯对话章可以没有；内心章可以多写
    
[ ] 本章有没有"具体到一寸的风 / 光 / 声音 / 触感"？
    （不是"微风拂面"——是"风从左边来，吹动了她头发末梢那几根白的"）
    → **按人物环境决定**：室内场景不必硬塞天气
    
[ ] 本章有没有"陌生人的一个小动作，跟主题无关"？
    （蹲下倒石子 / 抬手挡风 / 把筷子放下又拿起来 / 蹲在路边数硬币）

[ ] 本章有没有"沉默的、有距离的、没解决的"段落？
    （不是"我终于明白"——是"老人没说完。明心没问。桥下水声很大"）

```

**自检方式**：写完回头读一遍。如果读完觉得"读者读到这里可能突然意识到自己的呼吸"——**这一章就过了**。不必打勾。**作者自己的心，比任何清单都准**。

## 七、4 填空扩展（48 模板同步加第 5 空；**2026-09-02 二次修订**：填空不固定，可按章节类型灵活）

> **4 填空**是**参考结构**，不是**硬性必填**。本章如果是纯日常章/纯对话章/纯心界章，4 填空可按章节类型**只填关键的 1-2 个**。
> 第 5 填空（本章能量点）作为"那一刻这章触碰到了什么"的**记录**——记 1 条就够。

### 5. 本章能量点（**2026-09-02 修订**：写"那一刻这章做了什么"，不写"用了哪种骨架"）

本章让读者**重新打开哪一处感知**？（不是事件、不是道理，是**一寸一寸的感知**）

```
[ ] 呼吸 / 身体  ━━━━━━━━━━━━━━━━━━
[ ] 时间  ━━━━━━━━━━━━━━━━━━
[ ] 天地（风/雨/光/树）  ━━━━━━━━━━━━━━━━━━
[ ] 他人  ━━━━━━━━━━━━━━━━━━
[ ] 自己  ━━━━━━━━━━━━━━━━━━
```

**至少记 1 条具体到"这一刻、这一段"**（不必 5 项都填）。**有 1 条即过**。

**示例（正）**：
```
本章能量点（极致 1 条即过）：
- 呼吸/身体：明心走在路上，脚底板感到一颗小石子硌了一下（第 3 段）
- 或者——时间：母亲在厨房的背影，一勺一勺地舀，明心数了三下，没数清（第 8 段）
- 或者——天地：风从江上吹过来，带着柴油味（第 12 段）
- 或者——他人：老人抬手的瞬间，明心看见他袖口破了一个三角形的口（第 20 段）
```

**示例（反 / 必须打回）**：
```
本章能量点：
- "明心感受到了温暖"
- "明心看见了生活的真谛"
- "明心被感动了"
- "用了'风吹过来'骨架"
- "用了'半句话'对话"
```

（**正例是写"那一段发生了什么"，反例除了"点破情绪"，也包括"用了哪种骨架"——骨架是死的，那一寸是真的**。）

## 八、章节质量参考指标（22 评分同步加项；**2026-09-02 二次修订**：评分是参考，不是红线）

### 能量传递参考分（10 分）

> **本章传递了多少能量**——由作者/A/B 共同判断。**不是按条数算分**。

| 参考分 | 状态 |
|---|---|
| 9-10 | 这一章让读者合上书会**长出一口气**——3 处以上极致描写，能量饱满 |
| 7-8 | 这一章有几处让读者重新感受到天地/他人/自己——1-2 处极致 + 几处支撑 |
| 5-6 | 这一章有可感的描写，但抽象成分稍多——有一处极致即过 |
| 3-4 | 这一章偏金句/大词/点破——AI 味重，但偶有亮点 |
| 0-2 | 这一章全是道理/哲理/情绪命名——没有任何"重新打开感知"的描写 |

**低于 5 = 提示修改**（不强制）。
**8+ = 本章可作标杆**（不强制）。

**评分不查"用了哪个骨架"——只查"那一寸是否被读者感受到"。**

**重要**：分数是参考工具，不写"低于 X 必须改"这种 P0 红线——**让作者/A/B 按章实际判定**。有些章节就是抽象的（哲思章、心界对辩章），硬扣 6 分门槛反而伤害创作。
