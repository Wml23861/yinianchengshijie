## 一、中枢与朝堂（皇城）

### 皇帝（自性）—— 空位，非人格

> 特殊：不按 19 字段写，因为自性不可对象化（见 35_世界观底层规则 公理八）。它「坐在」太初殿，却从未以「一个能被看见的对象」出现。皇城有皇位、有朝会、有百官，唯独皇帝不在——这是全书最大的悬念。正文中只能以「空殿、无字诏书、无人王座、镜子」出现。

### 观微 · 宰相（觉知）

- 外貌：面容总像隔着一层水，看不清五官；无年龄感，不老不幼。
- 语言：极少开口，开口只有半句，且从不评判；说「起风了」就只是说「起风了」。
- 生活/爱好：常站在皇城最高的飞檐上，只看，不记事、不记事本。
- 欲望：无；不争、不抢、不评判。
- 恐惧：无——「没有恐惧」正是它的位置。
- 秘密：它知道皇帝从未离开，只是从不解释。
- 过去：它比所有众生都早，是「看见」本身。
- 错误认知：无（它不判断，所以不犯错）。
- 核心执着：无——它没有「位置」可以执着。
- 关系：不干涉任何人，但人人隐约知道它；文臣想拉它站队，它只摇头。
- 与明心：后期明心发现「一直在看的那一个」就是它。
- 首现 / 中期 / 归宿：第一时代隐现 / 始终只是看 / 明心成为「看见」本身。

### 明鉴 · 谏官 / 良知

- 外貌：清瘦，一袭旧青衫，眼睛很静；年龄感：中年，像教过很多年书的先生。
- 语言：不大声，关键时刻一句，直指人心；不绕弯，但点到即止。
- 生活/爱好：夜读、抄书；抄的是经，写的却是自己。
- 欲望：问心无愧。
- 恐惧：良心不安——怕自己辜负了那个「知道」。
- 秘密：他知道皇位是空的，但从不说破，怕说破了反而害人。
- 过去：曾是明心童年最纯的那一点（初心的一部分）。
- 错误认知：一度以为「把真相说破」才是尽责。
- 核心执着：让人「知」——有时太急于让人醒。
- 关系：与问天童相熟，常被问天童一句「为什么」问住；与文臣不同路。
- 与明心：关键时刻点醒明心，却从不替他做决定。
- 首现 / 中期 / 归宿：第一时代隐现 / 学会「等明心自己来」 / 明心自己就是明鉴，无需外求。

### 理析 · 文臣（理性）

- 外貌：长须，衣冠一丝不苟，手里永远有卷册；年龄感：中年偏老。
- 语言：爱分析，条理清楚，爱说「其一、其二」；话多且密。
- 生活/爱好：案牍劳形，从不下朝；爱下棋，且是自己和自己下。
- 欲望：把一切都解释清楚。
- 恐惧：有解释不了的东西——尤其解释不了「皇帝为什么不在」。
- 秘密：他早算过无数次，答案都是「无解」，却不肯承认。
- 过去：曾以为理性能统领心界，如今越来越力不从心。
- 错误认知：用知识解释一切。
- 核心执着：确定性。
- 关系：常与武将争执；对宰相的「不评判」既敬畏又不耐。
- 与明心：明心早期最依赖的「智囊」，也是明心「想太多」的源头。
- 首现 / 中期 / 归宿：第一时代 / 承认「有些东西算不清」 / 理性退为工具，不再是主人。

### 武毅 · 武将（意志）

- 外貌：魁梧，披旧甲，沉默如一块铁；年龄感：中年。
- 语言：直接判断，短句，命令式；从不说「也许」。
- 生活/爱好：天不亮练兵、巡城；唯一的爱好是磨刀。
- 欲望：执行力——把事情办成。
- 恐惧：无力——怕自己有一天护不住这座城。
- 秘密：他并非不害怕，只是从不表露。
- 过去：一次次冲锋，一次次守住了「自我」的边界。
- 错误认知：努力能解决一切。
- 核心执着：行动、坚持、不退缩。
- 关系：与赤炎同属武将序列，有旧交；与文臣对立。
- 与明心：明心「硬撑」的来源，也是后期明心要放下的「蛮力」。
- 首现 / 中期 / 归宿：第一时代 / 学会「该停就停」 / 意志成为「选择后的担当」，不再是盲目的硬撑。

### 高台侯 · 吏部尚书 / 慢

- 外貌：衣饰华贵，永远挺直腰，下巴微抬；年龄感：中年，养尊处优。
- 语言：居高临下，爱说「你还不配」「放不下的是别人」。
- 生活/爱好：日日翻看「排名册」；私下收藏一封二十年前的信，谁也不让看。
- 欲望：排第一、被仰望。
- 恐惧：被看轻、被超越。
- 秘密：二十年前，他也曾是那个「被排到最后」的孩子。
- 过去：幼年被轻视，靠地位补偿自己。
- 错误认知：位置决定价值。
- 核心执着：站在顶端。
- 关系：轻视天衡子、缩影童子；与金算盘有「名与利」的微妙联盟。
- 与明心：明心「想证明自己」这一面的化身。
- 首现 / 中期 / 归宿：名城时代（早期隐现）/ 第一次帮别人 / 站在地上也能看见重要的东西。

### 无厌侯 · 户部尚书 / 贪·囤积

- 外貌：圆脸，指节粗大，总抱着一个算盘大小的金匣；年龄感：中年。
- 语言：把一切换算成得失，爱说「还不够」「再囤一点」。
- 生活/爱好：亲自守金库，数金砂数到天亮；爱吃甜的，越紧张越吃。
- 欲望：拥有更多。
- 恐惧：失去、匮乏——尤其怕「回到当年那种没饭吃的时候」。
- 秘密：金库最深处藏的不是金砂，是一小袋已经发霉的米。
- 过去：曾长期处于匮乏，被匮乏羞辱过。
- 错误认知：只有拥有足够多，才不会再失去。
- 核心执着：攥住金砂不敢松手。
- 关系：金算盘是他的下属兼对手；守城老兵曾替他挡过一刀。
- 与明心：被明心「坐着」触动，什么都没做，只是陪他坐着。
- 首现 / 中期 / 归宿：第一时代 / 第一次松手 / 松开手后，自己并没有消失。

### 金算盘 · 户部侍郎 / 贪·算计

- 外貌：瘦，眼珠转得快，常年穿一件洗得发白的袍子；年龄感：偏老。
- 语言：句句算账，爱说「这笔账……」「亏了」。
- 生活/爱好：爱吃糖葫芦、怕冷，一入冬就披三件衣；算盘从不离身。
- 欲望：算清一切利益。
- 恐惧：算不清就失控。
- 秘密：他算得清全城的账，唯独算不清「自己为什么还这么怕」。
- 过去：童年匮乏，靠精打细算活下来。
- 错误认知：一切都能算清。
- 核心执着：账本。
- 关系：无厌侯的下属兼对手；常被高台侯讥为「铜臭」。
- 与明心：明心「算计得失」这一面的化身。
- 首现 / 中期 / 归宿：第一时代 / 承认有算不清的 / 发现自己真正想守护的并不是财富。
- 登场记录：第 17 章《糖葫芦》首登场（王城街角糖葫芦铺子）。兑现设定：怕冷（天不冷也裹厚围巾）、爱吃糖葫芦、句句算账、算不清「心里那个数」；新增生活细节「母亲缝的布鞋（两朵梅花、血渗布上）+ 靴子补丁（同一个人缝的）」「停了就不知道自己在哪了」。明心为他留下一串糖葫芦，他应「等算清了这个数再说」。

### 赤炎 · 兵部尚书 / 嗔

- 外貌：三十出头，火红络腮，一道旧疤从眉梢划到颧骨；年龄感：青壮。
- 语言：直接、带火气，自称「末将」，急了会骂「放屁」。
- 生活/爱好：天不亮练兵；怕猫——见猫就绕道，却死不承认。
- 欲望：力量。
- 恐惧：再失去重要的人。
- 秘密：十年前那场愤怒之火，是他自己点的。
- 过去：曾因守护不力而痛失弟兄，愤怒成了他的铠甲。
- 错误认知：只有力量才能保护重要的人。
- 核心执着：用火护住一切。
- 关系：与武将同属武将序列；问天童唤他「赤叔叔」，他嘴硬心软。
- 与明心：从敌人到第一个转化的战友。
- 首现 / 中期 / 归宿：第一时代 / 第一次收火 / 明白「火不是他，他是他」。
- 登场记录：第 10 章首登场（王城）。第 11 章怕猫、旧伤（F018）落地。第 35 章《赤炎的旧伤》深夜城墙擦刀，明心近看左肩旧伤、得知「三十个弟兄剩三个」；第 36 章《那场火是他自己点的》坟前说出真相——十年前那场火是自己点的，二十七个弟兄被烧死，明心共鸣「我烧的是我自己」。

### 和事官 · 礼部尚书 / 讨好

- 外貌：圆脸和气，总陪着笑，腰微微弯；年龄感：中年。
- 语言：温和、含糊，先照顾别人，爱说「都行都行」「别伤了和气」。
- 生活/爱好：记住全城人的喜忌；爱养花，花比他自己金贵。
- 欲望：被喜欢、被需要。
- 恐惧：冲突——尤其怕被人生气。
- 秘密：他有个从没对任何人说「不」的账本，每一笔都是委屈。
- 过去：从小被教「要懂事」，懂事懂事，把自己活没了。
- 错误认知：只要不冲突，就会安全。
- 核心执着：维持表面的和气。
- 关系：借舟客是他最「照顾」也最「累」的人。
- 与明心：明心「讨好别人」这一面的化身。
- 首现 / 中期 / 归宿：情天时代 / 第一次说「不」 / 学会在不讨好里也能被爱。

### 镇国公 · 刑部尚书 / 控制欲

- 外貌：国字脸，法令纹很深，总握着一条马鞭；年龄感：中年偏老。
- 语言：命令式、计划式，爱说「必须按我说的」「出了岔子谁负责」。
- 生活/爱好：把每一件事排进「章程」；爱把地图折得方方正正。
- 欲望：掌控一切。
- 恐惧：失控。
- 秘密：他每晚都要确认三次门闩，才敢睡。
- 过去：曾因一次「意外」失去过最亲的人，从此信「万无一失」。
- 错误认知：失控=危险。
- 核心执着：让所有事按计划发生。
- 关系：与文臣一拍即合（都要确定性），与武将互相看不顺。
- 与明心：明心「想控制一切」这一面的化身。
- 首现 / 中期 / 归宿：道境时代 / 允许不确定 / 发现「顺」比「控」更有力。

### 疑川 · 都察院御史 / 疑

- 外貌：面色偏白，总是侧着身子看人，像在防暗箭；年龄感：中年。
- 语言：反问、试探，话总留一半，爱说「你凭什么让我信」。
- 生活/爱好：把每一份证据翻来覆去验三遍；爱养一缸从不说话的黑鱼。
- 欲望：看透一切疑点。
- 恐惧：被欺骗、被伤害。
- 秘密：他曾最信任的人，亲手把刀递给了别人。
- 过去：因信任而被背叛，从此不信任何人，包括自己。
- 错误认知：怀疑一切才安全。
- 核心执着：永远要一个「确定的答案」。
- 关系：与雾先生貌合神离；大理寺卿是他唯一勉强不查的人。
- 与明心：明心「自我怀疑」这一面的化身。
- 首现 / 中期 / 归宿：第一时代 / 第一次相信 / 想够了，该看了。

### 沈判 · 大理寺卿（因果）

- 外貌：黑袍，白手套，总在灯下誊写卷宗；年龄感：看不出，只觉很旧。
- 语言：一字一句，慢而准，爱说「有因，就有果」。
- 生活/爱好：把每桩案子的因果写得工工整整；爱对着一盏孤灯发呆。
- 欲望：因果分明，账目清楚。
- 恐惧：有些因果，他判不了。
- 秘密：他自己也欠着一笔「因果」，迟迟未还。
- 过去：曾是忘川边一个抄录生死的无名小吏。
- 错误认知：以为一切因果都能「判得清」。
- 核心执着：公平。
- 关系：与回首翁（史官）常常借阅旧卷；与疑川互相防着。
- 与明心：明心「算总账、求公平」这一面的化身。
- 首现 / 中期 / 归宿：中期 / 承认有判不了的因果 / 明白「承担」比「判清」更重要。

### 天衡子 · 翰林院学士 / 自负

- 外貌：文气，爱背着手，头昂得高；年龄感：偏老，自诩德高望重。
- 语言：断言式，好为人师，爱说「这你就不懂了」。
- 生活/爱好：著书立说，写的都是「论」；爱在自己写的字画上反复盖印。
- 欲望：被崇拜、被承认。
- 恐惧：被戳穿「其实没那么懂」。
- 秘密：他书房最深处，压着一本自己都读不懂的书。
- 过去：少年得志，一路被捧，忘了自己也有不会的。
- 错误认知：我已经懂了。
- 核心执着：学问上的「我」。
- 关系：与高台侯互相看不起；问天童的「为什么」常让他哑口。
- 与明心：明心「自以为是」这一面的化身。
- 首现 / 中期 / 归宿：名城时代 / 第一次承认不知道 / 懂得「知道自己不知道」。

### 沈一苇 · 国子监祭酒（学习）

- 外貌：温文，抱着一摞旧书；年龄感：中年。
- 语言：爱引经据典，但会耐心解释；口头禅「读书，是为了……」
- 生活/爱好：教书、抄书、把散页装订成册；爱看窗外的雨。
- 欲望：把学问传下去。
- 恐惧：教错了人，误人子弟。
- 秘密：他自己也一直在「学」，只是不好意思承认。
- 过去：寒门出身，靠读书走出来，所以更信读书。
- 错误认知：以为「懂了道理」就等于「做到了」。
- 核心执着：知识。
- 关系：与天衡子亦师亦敌；收过不少穷学生。
- 与明心：明心「求知欲」这一面的化身，也是「知行分裂」的镜子。
- 首现 / 中期 / 归宿：中期 / 明白「知行合一」 / 从「教」转为「陪人走」。

### 詹星 · 钦天监监正（直觉）

- 外貌：瘦小，总仰头看天，脖子后有晒痕；年龄感：偏老。
- 语言：话少，偶尔冒一句不着边际的「今晚有风」。
- 生活/爱好：夜观星象、记录天候；爱把不同的光都记下来。
- 欲望：读懂天意（读懂直觉）。
- 恐惧：直觉失灵——怕再也「感觉」不到什么。
- 秘密：他有时也分不清「直觉」和「胡思乱想」。
- 过去：曾因一次直觉救过全城，从此被奉为神算。
- 错误认知：把「直觉」当成绝对正确。
- 核心执着：预知。
- 关系：与宰相偶有交集（都「看」，但一个看外，一个看内）。
- 与明心：明心「说不清的预感」这一面的化身。
- 首现 / 中期 / 归宿：中期 / 学会「不确定」 / 直觉从「预言」回到「感受」。

### 尹影 · 内廷总管（潜意识）

- 外貌：总站在阴影里，看不太清；年龄感：无。
- 语言：几乎不说话，只在必要时低语一句。
- 生活/爱好：掌管皇城最深的、没有光的那些房间。
- 欲望：不被打扰。
- 恐惧：被「说破」。
- 秘密：皇城里所有被藏起来的东西，都堆在他那里。
- 过去：是明心「不愿意看见」的那些部分的看守者。
- 错误认知：以为「藏起来」就是「安全」。
- 核心执着：隐秘。
- 关系：与夜行客（恐惧）有暗中的往来。
- 与明心：明心「潜意识」的入口，梦境的守门人。
- 首现 / 中期 / 归宿：中期 / 打开一扇门 / 潜意识不再是被藏起来的部分。

### 梦眠 · 夜司（睡眠）

- 外貌：穿一身深蓝，眼皮总半阖着，走路没有声音；年龄感：无。
- 语言：慢，拖长音，像在梦呓。
- 生活/爱好：点起全城的灯，又一一吹灭。
- 欲望：让所有人都能睡去。
- 恐惧：有人睡不着——尤其是明心。
- 秘密：睡眠不只是休息，是「心界与现实之间的摆渡」。
- 过去：不知从何时起，就成了「夜」本身。
- 错误认知：以为睡过去，问题就暂时没了。
- 核心执着：安宁。
- 关系：与内廷总管（影）同管夜晚。
- 与明心：明心「失眠」这一面的对立面，也是明心进入心界的「摆渡人」。
- 首现 / 中期 / 归宿：第一时代 / 明心不再靠睡眠逃避 / 睡眠回归「休息」。

## 二、顾命五大臣（五蕴）

> **顾命五大臣**：皇帝（自性）从不上朝，心界明面上由这五位「顾命大臣」代行皇权、主理朝政。他们正是「色、受、想、行、识」五蕴的人格化，五蕴聚合成的那个「假我」，就是遮蔽自性的五样东西。他们从没见过皇帝，却自以为「替皇帝守着天下」；他们越尽忠职守，越把皇帝挡在身后。这是全书核心机锋之一：众生把五蕴当成「我」，正如心界把五大臣当成「主政者」。
> 命名铁律：姓即五蕴字（色／受／想／行／识），封侯，与「嫉贤侯」一类以烦恼字入名的取法一致。

### 色相侯（色）—— 顾命首辅，掌「身」

- 外貌：身形高大，衣饰华贵，总在整理仪容；年龄感：中年，保养极好，像一尊会呼吸的塑像。
- 语言：爱谈形貌、气色、身子骨，说「这身子是根本，垮了，什么都没了」。
- 生活/爱好：尝遍山珍、试遍华服；爱照铜镜，一日数照。
- 欲望：色身不老，形貌常好。
- 恐惧：衰老、病、身体垮掉。
- 秘密：他比谁都清楚身体是「会坏的东西」，所以加倍地伺候它、怕它。
- 过去：五蕴初成，他是第一个「成形」的，其余四臣都借他这具身体落脚。
- 错误认知：以为「这个身体」就是「我」。
- 核心执着：色身、形相。
- 关系：与受纳侯最亲近（身与受相续）；其余四臣都「住」在他身上。
- 与明心：明心「把身体当自己、为身体焦虑（熬夜、胃疼、怕老）」这一面的化身。
- 首现 / 中期 / 归宿：第一时代 / 学会「听身体，既不拿它当工具，也不拿它当自己」 / 色身不再是被执着的对象。

### 受纳侯（受）—— 掌「受」

- 外貌：脸像晴雨表，衣饰随情绪变；年龄感：青年偏中年。
- 语言：情绪化，一会儿哭一会儿笑，爱说「我难受」「我心里舒坦」。
- 生活/爱好：看戏听曲，专挑能让自己「痛痛快快哭一场或笑一场」的；爱记「今日心情」。
- 欲望：永远要「好受」，不要「难受」。
- 恐惧：苦、痛、难受。
- 秘密：他攒着一本旧账，全是过去没被看见的情绪。
- 过去：一次次情绪被说成「小题大做」「别矫情」，于是更渴望被理解。
- 错误认知：以为「乐受是我，苦受不是我」，只想留乐、拒苦。
- 核心执着：追逐乐受，逃避苦受。
- 关系：与色相侯最亲近（身子舒服了，受才舒服）；与想象侯常拌嘴（想多了，受更乱）。
- 与明心：明心「报喜不报忧、压抑情绪、用『还好』搪塞」这一面的化身。
- 首现 / 中期 / 归宿：第一时代 / 学会「苦受乐受都只是受，来了看见它，不必成为它」 / 情绪不再被压，也不再被放大。

### 想象侯（想）—— 掌「想」

- 外貌：瘦，眼窝深，总在走神，像活在另一个世界里；年龄感：中年。
- 语言：天马行空，一句话能岔到八百里外，爱说「万一」「会不会」。
- 生活/爱好：造梦、画画，把「最坏的结果」和「最好的可能」都画出来；爱在纸上画满迷宫。
- 欲望：把一切「想明白」、想透。
- 恐惧：漏掉某个可能、出错。
- 秘密：他想象的灾难，比真实发生的多一百倍；他靠「想」给自己造了一座逃不出去的城。
- 过去：曾因想太多误过事，也因想得全救过人，于是更信「想」。
- 错误认知：以为「念头＝事实」「我想到的＝真的」。
- 核心执着：思虑、预测、分别。
- 关系：与识海侯一脉相承（想之后是识）；与受纳侯常拌嘴（想多了，受更乱）。
- 与明心：明心「胡思乱想、灾难化、过度思考」这一面的化身。
- 首现 / 中期 / 归宿：第一时代 / 学会「念头来了看见它，不跟着跑」 / 想够了，就停。

### 行愿侯（行）—— 掌「行」

- 外貌：结实，走路带风，总在「做事」；年龄感：中年。
- 语言：爱发誓、爱下决心，说「我一定能」「从明天起」。
- 生活/爱好：给自己定一堆计划，墙上贴满「必须完成」；爱磨刀，准备着，却总没真正下手。
- 欲望：把事情做成，证明自己「有行动力」。
- 恐惧：无力、半途而废。
- 秘密：他立下的愿，十个有九个没做到；他怕的不是「不做」，是「做了也做不成」。
- 过去：一次次热血上头，一次次虎头蛇尾，于是更急着「再发一个大愿」。
- 错误认知：以为「发愿＝做到」「想＝做」。
- 核心执着：行动、造作、折腾。
- 关系：与武将意气相投；是五大臣里最坐不住的一个。
- 与明心：明心「想而不做、做而不成、原地打转却停不下来」这一面的化身。
- 首现 / 中期 / 归宿：第一时代 / 学会「踏实走一小步，不靠发大愿」 / 愿力落在每一步。

### 识海侯（识）—— 掌「识」

- 外貌：极安静，像一面湖，看不清深浅；年龄感：无，似在似不在。
- 语言：极少开口，一开口就是追问「你是谁」「这是不是我」。
- 生活/爱好：守着一片镜湖，看倒影；把「我」和「非我」一点点分开。
- 欲望：要一个「确定的答案」（我是谁）。
- 恐惧：没有答案。
- 秘密：他知道答案，但答案一说出口就「不是了」；他越分别，越找不到「我」。
- 过去：从五蕴初成起，他就负责「了别」（这是好的、那是坏的、这是我、那是他）。
- 错误认知：以为「想清楚我是谁」就能得到「我」。
- 核心执着：追问、分别、认知。
- 关系：与想象侯一脉相承；常被问天童反过来问住。
- 与明心：明心「我是谁」的终极追问者，也是「分别心」的化身。
- 首现 / 中期 / 归宿：第一时代 / 追问到「找心的那个，就是心」 / 沉默，不再需要问。

## 三、念头众生（民间核心，其余详见 08/09 已有，此处补人性维度）

> 以下众生已在 08/09 有心理剖析，本谱只补「外貌 / 语言 / 爱好 / 秘密 / 过去 / 关系」等活人维度。

### 雾先生 · 痴

- 外貌：穿灰袍，整个人像蒙着一层雾，看东西眯着眼；年龄感：中年偏老。
- 语言：慢、笃定，爱说「我看得比你清楚」。
- 生活/爱好：给全城「答疑」，却从没看清过自己脚下。
- 秘密：他其实早就看不清了，只是不敢承认。
- 过去：曾因看不清而受骗，从此坚信「自己最清楚」。
- 关系：与疑川互相不服。
- 与明心：明心「自欺、不肯承认看不清」这一面的化身。
- 首现 / 中期 / 归宿：第一时代 / 承认一直活在雾里 / 雾散之后，原来看得清。

### 夜行客 · 恐惧

- 外貌：瘦削，总裹着黑斗篷，脚步极轻；年龄感：青年。
- 语言：短促、急促，爱说「来不及了」「快走」。
- 生活/爱好：总在夜里赶路，从不在一个地方停留。
- 秘密：他逃的从来不是「鬼」，是「还没发生的坏事」。
- 过去：他见过太多「最坏的结果」，从此只信最坏的那种。
- 关系：与内廷总管（影）有暗中往来。
- 与明心：明心「恐惧、逃避」这一面的化身。
- 首现 / 中期 / 归宿：第一时代 / 第一次留下来 / 发现最坏的结果，大多不会发生。

### 借舟客 · 依赖

- 外貌：文弱，总贴着别人走，像怕自己站不稳；年龄感：青年。
- 语言：迟疑，总要问「你陪我一起去吧」。
- 生活/爱好：总在渡口等船，从不敢独自上船。
- 秘密：他其实会游泳，只是不敢承认「自己可以」。
- 过去：小时候被一个人留在渡口，从此怕独行。
- 关系：和事官最「照顾」也最「累」的人。
- 与明心：明心「不敢独立」这一面的化身。
- 首现 / 中期 / 归宿：情天时代 / 第一次独行 / 发现自己其实能走。

### 回首翁 · 后悔

- 外貌：驼背，总回头看，像丢了东西；年龄感：老。
- 语言：慢，反复提过去，爱说「早知道」「要是当初」。
- 生活/爱好：总去大理寺借旧卷，一遍遍翻「当年」。
- 秘密：他放不下的，不是那件事，是「当时的自己」。
- 过去：曾有一个无法挽回的选择，从此活在过去。
- 关系：与大理寺卿（沈判）有旧交。
- 与明心：明心「悔恨、活在过去」这一面的化身。
- 首现 / 中期 / 归宿：欲海时代 / 第一次抬头看前路 / 过去翻篇，不等于遗忘。

### 赶路人 · 焦虑

- 外貌：行色匆匆，鞋底磨得最薄；年龄感：青年偏中年。
- 语言：快、急，总看天色，爱说「来不及了」「快点」。
- 生活/爱好：永远在赶，却说不清要去哪。
- 秘密：他怕的不是「迟到」，是「一停下来就慌」。
- 过去：从某一刻起，把「忙」当成了「安全」。
- 关系：与钦天监监正（观星人）常擦肩，一个赶路，一个看天。
- 与明心：明心「焦虑、停不下来」这一面的化身。
- 首现 / 中期 / 归宿：第一时代 / 第一次慢下来 / 专注当下，不必赶。

### 万花使 · 欲望

- 外貌：衣着鲜艳，手里总捧着一朵将开未开的花；年龄感：青年。
- 语言：轻快，爱说「下一个更好」。
- 生活/爱好：追逐一切「新鲜」，到手就腻。
- 秘密：他采尽百花，却从没闻过一朵的花香。
- 过去：曾被「渴望」本身推着，停不下来。
- 关系：与江湖众人熟络。
- 与明心：明心「永不满足、追逐下一个」这一面的化身。
- 首现 / 中期 / 归宿：欲海时代 / 看见欲望背后的空洞 / 一朵花，也能好好看。

### 缩影童子 · 自卑

- 外貌：个子小，总低着头，缩在角落；年龄感：孩子。
- 语言：小声、退缩，爱说「我不如他」。
- 生活/爱好：爱躲在大人身后，偷偷看别人。
- 秘密：他其实有一样东西，做得比谁都好，只是从不敢展示。
- 过去：总被拿来「和别的孩子比」。
- 关系：与天衡子、高台侯的阴影里长大。
- 与明心：明心「自卑、总觉得自己不如人」这一面的化身。
- 首现 / 中期 / 归宿：名城时代 / 第一次挺直腰 / 看见自己的价值。

### 青灯 · 善意

- 外貌：温和，手里提一盏灯，不亮却暖；年龄感：青年。
- 语言：少说话，多做；说出来的都是「我陪你」。
- 生活/爱好：夜里给人点灯、引路。
- 秘密：她的善，不是讨好，是一种「我看见了，所以不能不管」。
- 过去：曾因善良被利用，却仍选择善良。
- 关系：与慈舟同路。
- 与明心：明心「善意、但不软弱」这一面的化身。
- 首现 / 中期 / 归宿：第一时代 / 学会有边界的善 / 温柔而坚定。

### 慈舟 · 悲悯

- 外貌：宽厚，像一条能渡人的船；年龄感：中年。
- 语言：平静，能听见别人没说出的话，爱说「我在听」。
- 生活/爱好：在渡口摆渡，把迷路的人送过河。
- 秘密：他见惯苦难，自己也会累，只是从不说。
- 过去：曾渡不了自己最想渡的人。
- 关系：与青灯同路；与问天童交好。
- 与明心：明心「悲悯、见不得人受苦」这一面的化身。
- 首现 / 中期 / 归宿：第一时代 / 学会「帮能帮的，放下帮不了的」 / 渡人先渡己。

### 问天童 · 好奇（初心）

- 外貌：小小一个，眼睛亮得吓人；年龄感：孩子。
- 语言：连续追问「为什么」，问到人哑口。
- 生活/爱好：总在皇城各处跑来跑去，问东问西。
- 秘密：他的「为什么」，是明心早就忘了的「初心」。
- 过去：一直跟在明心身边，明心却记不起他。
- 关系：与明鉴相熟；唤赤炎「赤叔叔」。
- 与明心：明心的「初心 / 好奇」，最终与明心合一。
- 首现 / 中期 / 归宿：第一时代 / 渐隐（明心不再需要外在初心）/ 与明心合一。

### 空山 · 清静

- 外貌：一身素衣，像一座无人打扰的山；年龄感：无，似老似少。
- 语言：极少出现，几乎不说话。
- 生活/爱好：独自坐在心界最深的地方。
- 秘密：他的「静」，不是没声音，是不被声音带走。
- 过去：一直在这里，等人自己安静下来。
- 关系：与宰相遥遥相望。
- 与明心：明心「清静、回归安静」这一面的化身。
- 首现 / 中期 / 归宿：空门时代 / 明心能在闹市也静 / 清静不是地点，是状态。

### 白玉相 · 完美主义

- 外貌：白衣胜雪，一尘不染，连指甲都修得齐整；年龄感：中年。
- 语言：挑剔、严苛，爱说「这还不够好」。
- 生活/爱好：把每样东西摆得横平竖直；爱把一块玉反复摩挲到无瑕。
- 欲望：完美。
- 恐惧：瑕疵——尤其怕自己的瑕疵被发现。
- 秘密：他容不下的，从来不是别人的瑕疵，是自己的不完美。
- 过去：只有「完美」的时候，才被认可过。
- 错误认知：不完美 = 失败。
- 核心执着：完美。
- 关系：与拖延生（同源）同病；与证明郎（证明）相交。
- 与明心：明心「完美主义、自我苛责」这一面的化身。
- 首现 / 中期 / 归宿：名城时代 / 第一次接纳不完美 / 完整比完美重要。

### 称心侯 · 计较心

- 外貌：手里永远拎一杆小秤，秤砣系在腰间；年龄感：中年。
- 语言：爱说「称一称」「不亏吗」，说话带算计。
- 生活/爱好：街头巷尾给人物价——称米、称心、称日子。
- 秘密：他从不称自己，怕称出自己「不值」。
- 过去：早年因被人「估价」太低，从此立志「不被人看轻」。
- 关系：与无厌侯（贪）常有往来，但谁也瞧不起谁。
- 与明心：明心「计较、怕吃亏、怕被看轻」这一面的化身。
- 首现 / 中期 / 归宿：第一时代（卷一后段 52 章起）/ 学会不称 / 心称不出斤两。

### 号序官 · 等待心

- 外貌：坐在厅堂柜台后，手里捏一把号码牌；年龄感：中年偏老。
- 语言：慢条斯理，爱说「下一个」「还没轮到你」。
- 生活/爱好：给所有人排号——看病排号、吃饭排号、进门排号。
- 秘密：他自己的号，从来没叫到过。
- 过去：年轻时排过一次队，错过了一件大事，从此把「秩序」当成全部。
- 关系：与守门官常搭档（一个给号，一个收钱）。
- 与明心：明心「焦虑等结果、怕错过」这一面的化身。
- 首现 / 中期 / 归宿：第一时代（卷一后段 53 章起）/ 听见自己心里的号 / 叫到的没来，等的没叫到。

### 守门官 · 门闩心

- 外貌：穿青灰短打，腰里别一串钥匙；年龄感：壮年。
- 语言：寡言，爱说「门没锁，是里头的门闩」「你那道门不是钥匙锁的」。
- 生活/爱好：守心界各道城门——给出去的人开门，给回来的人留缝。
- 秘密：他自己守的那道门其实锁着，里头的门闩他一直没拉开过。
- 过去：年轻时误锁了一道门，里头的物事全烂了，从此守门时格外小心。

## 七、四相魔君与无明天魔

> 详档见 09_核心反派库。此处仅补「外貌 / 语言 / 关系」等人性维度。

### 我相魔

- 外貌：四条手臂四张脸，每张脸都写着「我最重要」；年龄感：无。
- 语言：不断强调「我」，把一切绕回「我」。
- 生活/爱好：制造「我是特殊的」的幻境。
- 欲望：膨胀、被承认「我」。
- 恐惧：被否定「我」。
- 秘密：他最初出现，是为了保护童年那个弱小的明心。
- 过去：是「我」这个概念最初长出来的样子。
- 错误认知：「我」是世界的中心。
- 核心执着：我相。
- 关系：其余三相魔君的手足。
- 与明心：明心「自我中心」这一面的极致。
- 首现 / 中期 / 归宿：欲海时代 / 被看见后消融 / 转化为护法。

### 人相魔

- 外貌：收藏着无数张「脸」，没有一张是真的；年龄感：无。
- 语言：见谁戴谁的脸，说话从没有自己的口音。
- 生活/爱好：制造「别人眼中的我」。
- 欲望：被所有人喜欢。
- 恐惧：被看穿面具下的空。
- 秘密：他怕的是「摘下面具，没人认识我是谁」。
- 过去：为了讨好不同的人，造出了无数人设。
- 错误认知：别人怎么看我 = 我是谁。
- 核心执着：人相。
- 关系：与千面郎（伪装）同源。
- 与明心：明心「讨好、戴面具」这一面的极致。
- 首现 / 中期 / 归宿：名城时代 / 面具被主动摘下 / 转化为护法。

### 众生相魔

- 外貌：一副悲天悯人的样子，像要扛起全世界；年龄感：无。
- 语言：满口「我要救众生」，把自己架得很高。
- 生活/爱好：制造「背负全世界」的执念。
- 欲望：拯救所有人。
- 恐惧：有人救不了（那证明自己不够好）。
- 秘密：他的「救」，也是一种「证明自己」。
- 过去：见性之后萌生的「责任感」，长偏了。
- 错误认知：我必须救所有人，否则我有罪。
- 核心执着：众生相。
- 关系：与假侠（表演式正义）同源。
- 与明心：明心「以觉悟者自居、说教」这一面的极致。
- 首现 / 中期 / 归宿：第四时代 / 帮能帮的，放下帮不了的 / 转化为护法。

### 寿者相魔

- 外貌：苍白，总想抓住「时间」；年龄感：无，却又老又怕老。
- 语言：反复问「我会不会消失」「你会不会忘了我」。
- 生活/爱好：制造「对死亡、遗忘的恐惧」。
- 欲望：永存、被记住。
- 恐惧：消失、被遗忘。
- 秘密：他怕的不是「死」，是「死了之后，再也没人记得我」。
- 过去：从某一刻起，害怕「我」会没有痕迹地消失。
- 错误认知：被记住 = 存在。
- 核心执着：寿者相。
- 关系：与回首翁（后悔）同源。
- 与明心：明心「怕被遗忘、怕消失」这一面的极致。
- 首现 / 中期 / 归宿：欲海时代 / 明白消失的是身份不是存在 / 转化为护法。

### 无明天魔 · 无明（终极）

- 外貌：没有固定形态，是一片「看不见」；年龄感：无。
- 语言：低声试探，最爱说「所有修行，都是你的欲望」。
- 生活/爱好：制造分别、执着、贪恋、恐惧。
- 欲望：让人「不知道」。
- 恐惧：被看穿（看穿即消融）。
- 秘密：它不是一个「敌人」，是「不知道」本身。
- 过去：它一直都在，只是明心看不见它。
- 错误认知：无（它就是错误认知的根源）。
- 核心执着：遮蔽。
- 关系：与内廷总管（影）暗通，是「潜意识里最黑的部分」。
- 与明心：明心「无明」的终极面对。
- 首现 / 中期 / 归宿：贯穿全书 / 抛出终极试探 / 被彻底看清后自然消融。

## 使用规则

1. 每个众生首先是「人」，其次才是「某类念头」的化身（象征意义正文禁止说破）。
2. 新增众生前，先查本谱 + 08_核心人物库 的差异性核查，确认「心性主题 / 社会身份 / 生活细节」不重复。
3. 众生之间要「有关系」，不是孤立的符号：上下级、亲属、邻里、债主、恩人、仇敌。
4. 与 10_众生命运故事库 配合：本谱是「人」，10 是「这些人会经历的人生困境」，二者交叉使用。
5. 人物中期变化、最终归宿，随创作推进更新（见 03/04/08/09 的对应档案）。
