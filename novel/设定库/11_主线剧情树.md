# 11_主线剧情树

> 明心觉醒之路的主线脉络。主线 = 从「被念头控制」到「无所住而生其心」。
> 每个节点标注：时代、关键事件、明心变化、对应迷失。

---

## 主树干

```
【起点】现实崩塌 → 坠入心界（第一时代·尘中少年）
        │
        ├─ 看见崩乱的心国王城（我是谁？这是哪儿？）
        │
        ├─ 逐域拜访九大势力（生存层：欲望/竞争/愤怒/逃避）
        │        └─ 关键节点①：说出「我看见你了」→ 第一缕清明
        │
【第二时代·欲海初渡】
        ├─ 四相魔君现世（我相/人相/众生相/寿者相）
        ├─ 越反抗越强 → 关键节点②：不认同而非战胜（破执）
        │
【第三时代·情天风暴】
        ├─ 现实分手 + 心界忘川楼
        ├─ 关键节点③：理解一个人 ≠ 占有他（放手）
        │
【第四时代·名城之困】
        ├─ 金榜阁排名 + 现实身份焦虑
        ├─ 关键节点④：身份之外有一个在看的人（事上磨练初启）
        │
【第五时代·念国之乱】
        ├─ 念头纷飞，越分析越乱
        ├─ 关键节点⑤：见性第一瞥——「找心的那个就是心」
        │
【第六时代·识海迷宫】
        ├─ 内在大分裂（五蕴/七情/九势力内乱）
        ├─ 关键节点⑥：各归其位，不令而从（万法归一）
        │
【第七时代·空门无门】
        ├─ 现实 vs 修行的双重考验
        ├─ 关键节点⑦：知行合一——知道并且做到
        │
【第八时代·道境无为】
        ├─ 越控越乱 → 顺势而为
        ├─ 关键节点⑧：返本归真——放下所有身份
        │
【第九时代·无界明心】
        ├─ 无明天魔：「所有修行都是你的欲望」
        ├─ 关键节点⑨：连觉醒的执着也放下（无所住）
        │
【终点】回归现实，普通场景，明心没有像过去那样反应
```

---

## 关键节点详解

| 节点 | 时代 | 事件 | 明心变化 | 对应迷失 |
|------|------|------|----------|----------|
| ① 第一缕清明 | 1 | 说出「我看见你了」 | 从被念头冲走 → 看见念头 | 我想变强（起） |
| ② 破执 | 2 | 不认同而非战胜四相魔君 | 从消灭 → 看见 | 我想变强（落） |
| ③ 放手 | 3 | 情天放手 | 从占有 → 慈悲 | 想让所有人理解我 |
| ④ 事上磨 | 4 | 身份之外有看的人 | 从证明 → 观察 | 想证明自己 |
| ⑤ 见性 | 5 | 找心的就是心 | 从找 → 认出 | 想拯救所有人（起） |
| ⑥ 归一 | 6 | 各归其位 | 从内战 → 共奉一心 | 想拯救所有人（落） |
| ⑦ 知行 | 7 | 知道并且做到 | 从知 → 行 | 想成为觉者（起） |
| ⑧ 返本 | 8 | 顺势、放下身份 | 从控 → 顺 | 想成为觉者（落） |
| ⑨ 无所住 | 9 | 连觉醒也放下 | 从求 → 无求 | 什么都不要了 |

## 主线的三大悬念（CLAUDE.md 第二十九、三十卷）

1. 心界究竟从哪里开始？为什么明心能进入？
2. 自性为什么从不出现？
3. 明心究竟是在进入心界，还是在认识自己？

**终极悬念**：不是「谁是最终反派」，而是「『我』到底是谁？」贯穿全书，直到最后读者不是得到概念答案，而是经历一次自我观察。

---

## 主线推进规则

1. 主线不靠「升级」推进，靠「看见/放下/承担」推进。
2. 每完成一百章检查主线是否推进（见 23_长篇连续性检查规则）。
3. 主线节点之间允许大量生活、支线、众生故事填充，但方向不可偏离（由执着到清明）。
