# 07_心界百官体系

> 心界的官制隐喻：把人心机制映射为官制。这是**底层设计**，正文中禁止频繁解释「这个人物代表什么」，让人物自己活。
> 官职是「图谱」，五蕴大臣和九大势力首领是「任职者」。

## 二、五蕴大臣（色受想行识）

心国王廷的核心，象征明心的身心构成：

| 大臣 | 五蕴 | 象征 | 核心恐惧 | 转变 |
|------|------|------|----------|------|
| 色相大臣 | 色 | 身体与感官 | 被忽视 | 纵欲/压抑 → 倾听身体 |
| 受感大臣 | 受 | 感受与情绪 | 被冷落 | 情绪失控 → 被看见后不再极端 |
| 想象大臣 | 想 | 思维与想象 | 犯错 | 过度思考 → 想够了就停 |
| 行愿大臣 | 行 | 习气与愿力 | 无力 | 狂热发誓 → 接受做不到 |
| 识海大臣 | 识 | 意识与分别 | 无答案 | 追问你是谁 → 沉默微笑 |

## 三、任职者对应关系（整合原则）

1. **五蕴大臣** = 五蕴（色受想行识）的人物化，是心国王廷的「五位大臣」。
2. **九大势力首领** = 各种心理力量的人物化，分布在不同「域」，是明心要逐一理解的「自己」。
3. **百官体系** = 更全面的隐喻总表，揭示每种心理机制在「心界官制」中的位置。

三者关系：**百官图谱（抽象）→ 任职者（具体人物）**。五蕴大臣和九大势力首领都是百官图谱中某些「官职」的具体任职者。

## 三之二、政治体系（顶层四职 + 六部，引自创作宪法_1）

**顶层四职**：
- 皇帝 = 自性（别称本心/真心/本来/性/道/佛性/明/本觉；不坐在皇位上，是世界真正的本体）
- 宰相 = 觉知（观察天下，不直接干涉、不争、不抢、不评判，只是「看见」）
- 文臣 = 理性/知识/分析（逻辑、记忆、学识、经验、规划、判断；聪明但聪明不等于智慧，易犯「用知识解释一切」）
- 武将 = 意志（坚持、行动力、勇气、决断、自律、攻击性；能执行但易执着，相信「努力能解决一切」）

**六部**：
- 吏部 = 身份、名声、评价
- 户部 = 金钱、财富、安全感
- 礼部 = 关系、礼仪、认同
- 兵部 = 竞争、攻击、防御
- 刑部 = 规则、羞耻、惩罚
- 工部 = 行动、创造、执行

> 六部不是简单拟人化，必须拥有欲望、利益、历史、关系、派系、成长、错误。

## 四、使用规则

1. 正文**禁止**出现「这个人物代表XX」的直接解释。
2. 官员称号（谏官、丞相、史官等）在正文中**尽量少用**，它们主要是作者的管理工具。
3. 读者应该通过人物行为自己领悟「他代表什么」。
4. 官职图谱用于保证：每个人物都有唯一、不重叠的心性主题（差异性），避免两个人物代表同一种心理力量。

## 五、差异性检查（防重复）

下列心理力量各只对应一个主要人物，禁止重复拟人：
- 愤怒 → 赤炎（唯一），不可另造「愤怒二号」。
- 贪婪 → 无厌侯（唯一）。
- 傲慢 → 天骄侯（唯一）。
- 怀疑 → 狐疑先生（唯一）。
- 情执 → 红绫夫人（唯一）。
- 逃避 → 梦痴（唯一）。

新增人物前，先查本表，确认其心性主题尚未被占用。
