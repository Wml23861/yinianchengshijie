# 第 28 章 · 行愿之眠 — 创作记录

### 一、创作信息

- 所属：第一卷·入道 > 第一时代·尘中少年
- 时间：现实（接第 27 章明心拨出电话后，第二天下午）
- 地点：现实·公交站、公交车 → 心界·眠龙洞（行愿侯居所 F066）→ 现实·公交车
- 人物：明心、行愿侯（行·意志，重逢，称谓王／您／臣）、抱孩子女人、学生、打盹老头
- 事件：明心坐公交去城西面试地点踩点，出门前把门牌号念了好几遍，站台等车又一遍遍看地址。进心界，眠龙洞正中盘着一条睡龙，是行愿侯这些年立的愿。行愿侯各种叫不醒（喊哑嗓子、擂破鼓、刀背敲头），还发了更大的愿，龙尾动一下又睡。明心也喊「起来」，龙不动。明心发现自己心里也有条龙，戒烟、早起、给母亲打电话，一件一件都睡着。明心点破「想改也是想」「龙醒不醒不在喊，是你走的每一步挣来的」。明心扶正洞口石头，行愿侯缠绳子、捡黑石子（欠户部的账）码到墙根，龙尾动了。回现实，明心在公交车上放下手机，没再一遍遍看地址。
- 主题：想改也是执念（行愿之眠），行动是当下一步，不是发大愿
- 明心状态：困在想改里、想得睡不着 → 明白「想改不了，动手做才改得了」→ 放下「叫醒龙」的执念
- 字数：3000 字（汉字+标点，去标题；汉字 2452）
- 爽点：智爽（睡龙=积年未成的愿；不靠发大愿叫醒，靠当下一步）
- 配比：心界 80% / 现实 20%

### 五、AI 味即时防写（2026-08-22，开发者 A）

1. 转场不套模板：进心界「再一睁眼，站台没了，天也没了」，与第 26/27 章都不同。
2. 落点不是「我跟你一样」重复：第 28 章明心从观察者转成行动示范者（自己扶石头），带行愿侯一起做，推进一层。
3. 不点破象征：不写「龙就是你的愿力」，只写「臣这些年立的愿，攒着攒着就成了这条龙」。
4. 结尾动作收，明心「没再看手机，也没再想龙的事」。
