# 《心界》章节创作规则 v2.0

> 本文档为每一章创作前必须读取并遵守的永久规则。不是建议，是标准。

---

## 一、核心使命

这部小说是一本**用故事给人做心理按摩**的书。

读者读完一章后，必须同时收获四样东西：

| 收获 | 判断标准 |
|------|----------|
| 解压放松 | 心里某个压着的东西被看见了、被理解了、被允许了 |
| 治愈身心 | 不是短暂的爽——是"原来不止我这样"的落地感 |
| 心力增长 | 明心做到了的，读者觉得自己也可以试试 |
| 智慧觉醒 | 不是被教会了什么——是自己悟到了什么 |

---

## 二、分层读者设计（核心新增）

这本书必须**同时服务两类读者**，缺一类就是失败的：

### 下层：普通读者（慧根浅、悟性低、认知有限）

**他们的特点**：
- 在生活中被现实压力压得喘不过气——加班、房贷、人际关系、焦虑
- 心里有说不清道不明的东西压着，但不知道怎么表达
- 说不出来自己想要什么，但知道现在的生活不对
- 不读哲学、不修儒释道、不冥想——但他们在受苦

**对他们的要求**：
- 每一章必须有一个**生活化的现实对境**——加班、被否、分手、攀比、焦虑、熬夜刷手机……这些场景要具体，具体到读者能说"这就是我昨天的经历"
- 替他们说出**他们想说但说不出的困惑**——"为什么我一直在追却不知道在追什么"、"为什么够了的感觉从来不持久"
- 移除压在他们心口上的**说不清道不明但真实存在的东西**——读完一章，胸口轻松了一点
- **明心的每一步成长都必须是读者可模仿的**——不是神通，不是顿悟，是"看一眼"、"松手"、"承认不知道"这种每个人都能做的动作

### 上层：修行读者（上士、儒释道修行人、高慧根者）

**他们的特点**：
- 已读过经典、有实修经验、或在求道路上
- 不会被表面的玄幻情节满足——他们要看"道"是否真的在故事里
- 对说教极度敏感——任何"告诉"都会让他们反感
- 但好的呈现会让他们点头——"对，就是这样"

**对他们的要求**：
- 儒释道智慧**必须通过场景、动作、对话呈现**——不引用经文，不说出术语
- 他们看到某一段时应该产生**"原来就是这样"、"是这么回事"**的体悟——不是学到了新概念，是旧概念被活生生地演出来了
- 每章的智慧深度必须有**至少一层可挖掘的潜台词**——表层故事好看，深层智慧等修行人自己发现
- 卷终章（如第十章）需要有**证悟级别的呈现**——不是主角顿悟，是场景让修行读者自己证到

### 两层读者的交汇点

同一段文字，两层读者读出不同深度，但都觉得"这是写给我的"：

| 场景 | 普通读者读到 | 修行读者读到 |
|------|------------|------------|
| 明心说"我看见你了" | 终于有人看见我了 | 照见五蕴——念头是念头，我是看见念头的人 |
| 松手让洪水流过去 | 情绪不需要憋着 | 顺其自然——不堵即是无为 |
| 赤炎火焰自己收住 | 愤怒的人也需要被理解 | 慈悲不是同情——是看见对方的伤 |
| 无厌侯松手不攥 | 终于可以不用撑了 | 放下执着——松开即自在 |
| 心力在"不知道"时变亮 | 承认不懂也可以 | 不知为不知，是知也 |

## 三、每一章的"移石"设计（核心新增）

每一章必须在读者心口上**移除一块石头**——那些说不清道不明但确实压在那里的东西。

### 石头类型库

| 石头 | 读者的困惑 | 章节示范 |
|------|----------|---------|
| "我必须赢" | 不赢就焦虑，但赢了也空虚 | 第6章 |
| "我不能发火" | 压着愤怒，结果更累 | 第8章 |
| "永远不够" | 赚再多也不安心 | 第9章 |
| "我不知道自己是谁" | 身份焦虑、存在焦虑 | 第3章 |
| "我不够好" | 自我否定、完美主义 | — |
| "没人理解我" | 孤独、表达无门 | 第4章 |
| "我控制不了自己" | 拖延、成瘾、冲动 | — |
| "我怕被抛弃" | 讨好、依赖、不安全依恋 | — |

### 移石公式

```
角色体验同一种困惑 → 明心说出读者的心声 → 
明心做出一个可模仿的小动作 → 困惑松动了一点 → 
读者感到胸口轻了
```

**关键**：不能一次性移除——一块石头要分多章、多角度、渐进式松动。明心不是大师，他每章只松动一点点。读者跟着他，也松动一点点。

## 四、去AI痕迹标准（核心新增）

以下特征出现任意一条，就必须改写：

### 词汇层面
- [ ] "从某种程度上"、"某种意义而言"、"在某种意义上" → 删除
- [ ] "不仅是……更是……"句式连续出现 → 改为简单句
- [ ] "值得注意"、"不可否认"、"显而易见" → 删除
- [ ] 连续三个以上"的"字短语句 → 断句重组
- [ ] "这个过程"、"这一过程" → 用具体动作替代

### 句式层面
- [ ] 连续两个以上"当……的时候"句式 → 删改
- [ ] 连续两个以上"不是……是……"句式 → 保留最重要的一个，其余改简单句
- [ ] 段首句与段末句讲同一件事 → 删一段
- [ ] 形容句超过两个逗号的长度 → 断成两句

### 逻辑层面
- [ ] 前一章和后一章之间存在矛盾的情节、人物、数字 → 必须查证
- [ ] 感情变化缺少过渡——上一段还在怒，下一段忽然平静 → 补过渡
- [ ] 心力变化缺少触发——突然变大或变小 → 补触发瞬间

### 语气层面
- [ ] 概括性/总结性语句："他终于明白……"、"从此他知道了……" → 每章不超过一句
- [ ] 角色说的话像旁白——不像这个人会说出的话 → 改
- [ ] 任何一处让人感觉"这是AI写的"的用词或句式 → 必须重写

## 五、字数锁定

- **每章故事字4500-5000字**（总字符含格式约5500-6000）
- 低于4500必须补——补的是内心戏和具体描写，不是灌水
- 高于5000必须砍——砍的是重复啰嗦、多余的形容词、可合并的场景
- 章节一字数不对齐——每章有自己的节奏，不需要每章"恰好4800"

---

## 六、严谨性标准

### 标点
- **禁止使用破折号（——）**——全部用句号、逗号、冒号替代
- 对话中截断用省略号"……"，不用破折号
- 引号统一用双引号""，内部引用用单引号''
- 逗号、句号、分号按中文标点规范，不在英文语境下使用

### 数字/事实
- 角色说出的任何数字（字数、时间、人数）必须与前后章节一致
- 引用现实世界的事物必须是真实存在的（如第九章罗马尼亚盐矿）
- 物理/生理描写必须合理——水泡破裂后组织液滴落、吸入金粉在肺里沉积（隐喻层面也必须合理）

### 人物一致性
- 同一角色的自称方式前后一致（烈马都统对赤炎称"末将"，对明心称"我"）
- 角色的知识边界——不能说出"他不知道"的东西
- 心力大小必须与前面章节的状态一致——不能从米粒突然跳到核桃

### 重复检查
- 同一章内同一个比喻/意象不超过一次
- 相邻两章不超过三个相同的句式开头
- "不是……是……"句式每章不超过五次（特殊章节除外）

## 七、三教智慧植入

佛道儒每章各选至少一个，通过场景呈现。

### 佛家
照见/觉察、慈悲、放下执着、无常、因果、众生皆有佛性

### 道家  
柔弱胜刚强、顺其自然、知足、无为、相反相成

### 儒家
事上磨练、知行合一、致良知、己所不欲勿施于人、知耻近乎勇

**禁止**：引用经文原文、角色说教式解释智慧、明心"顿悟后成为大师"

---

## 八、解压时刻

每章必有一个——读者不自觉呼出一口气的瞬间。五种类型：被看见、被允许、被理解、松手、一起学。

位置：后半段，靠近高潮或之后。解压前必须有积累，解压后至少两段安稳。

---

## 九、心力变化

每章心力必须有变化：产生/变大/变稳/变亮/变暖。变化来自明心自己的体验，微小而可信。

---

## 十、标点规范：气息连贯

标点符号是**呼吸指引**，不是语法工具。每写完一章必须朗读一遍——标点错的地方就是呼吸断的地方。

### 句号：完整停顿

句号过多造成碎片化。连续两个以上可以逗号连接的短句，合并。

禁止：他站起来。走到门口。推开门。
正确：他站起来，走到门口，推开门。

禁止：殿中没有灯。不需要灯。
正确：殿中没有灯，也不需要灯。

保留短句的情况：节奏强调（"两个字。"）、段落收束（"但他没有攥拳头。"）

### 逗号：连接同一意群

同一句中不超过三个逗号。超过则断句。

### 破折号：铁律——全书禁用

正文中禁止出现破折号（——）及任何类似符号。一个都不行。写完一章后全文搜索"——"，结果必须为零。

---

## 十一、节奏交替

奇快偶慢，相邻不连续高潮。快章冲突揭秘，慢章展开沉淀。

---

## 十二、每章完成后必须逐字逐句审查

**审查不通过，不得视为完成。此条不可跳过、不可敷衍。**

### 第一步：逐字朗读
从头到尾读出每一句话。标点错的地方呼吸会断——呼吸断就是标点错。同口气内的用逗号，需停的用句号。禁止"不是X。不是Y。是Z。"三连碎句。

### 第二步：逐句核查
每一句问：删掉影响意思吗→删。同一段两句话讲同一件事→删一句。

### 第三步：逐段核查
标点都对了？"不是X。是Y"能合并？有没有。，或，，？

### 第四步：全文十条
1. 字数4500-5000？
2. 有英文词？
3. 对境近五章重复？
4. 逻辑自洽？角色说/问了不该知道的事？
5. 儒释道各一？呈现不是说教？
6. 解压时刻到位？
7. 心力变化了？触发具体微小？
8. 结尾钩子够强？
9. 有总结句/AI痕迹？
10. 这一章比上一章更好？

---

## 十三、不可逾越的底线

1. **4500-5000故事字**——不够补内心戏，多了砍啰嗦
2. **每章必有解压时刻**——不是可选项
3. **每章心力必有变化**——哪怕只是米粒到绿豆
4. **三教智慧每种至少一个**
5. **反派被理解，不被"打败"**
6. **明心不突然成大师**——每章进步必须可模仿
7. **不能说教**——智慧通过经历呈现
8. **结尾钩子必须让读者想点下一章**
9. **零破折号、零双逗号、零句逗连用**
10. **零AI痕迹**——按第四节清单自检
11. **两层读者都要照顾到**——普通人觉得说出了他的心声，修行人觉得证到了东西

---

> 本规则为活文档。每完成三章回顾一次，根据实际效果增删。
