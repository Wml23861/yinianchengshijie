# Save the Cat 分层规划指南

用途：把 Save the Cat 从"全书层"升级为"全书 + 分卷 + 章节职责"三层体系。

## 总原则

- **全书层**：完整 15 beats，决定主结构
- **分卷层**：承接全书某一段 beats，或形成卷内迷你弧
- **章节职责层**：只定义本章承担什么节奏职责

不要每章硬套完整 15 beats。

## 一、全书层

全书层必须明确：主母型/副母型、15 beats 落点、各卷分别承担哪些 beats、终局兑现什么承诺。

适合回答：这本书到底是什么故事、为什么读者会持续追更、每卷在大结构里的功能是什么。

### 长篇常用映射

| 全书区段 | 常见卷位 | 说明 |
|---------|----------|------|
| Opening Image ~ Debate | Vol-01 | 建世界、立困境、抛 Catalyst |
| Break Into Two ~ Fun and Games | Vol-02 | 进入新局面，兑现题材承诺 |
| Midpoint ~ Bad Guys Close In | Vol-03 | 局面升级，代价变重 |
| All Is Lost ~ Finale | Vol-04+ | 低谷、顿悟、总决战、结算 |

这只是默认映射，卷数多时要把大区段拆成多卷子弧。

## 二、分卷层

分卷层的任务是把全书节奏拆成可执行的阶段。

每卷至少回答 6 个问题：
1. 在全书里承担什么功能
2. 要兑现什么承诺感
3. 起点状态是什么
4. 升级点或中点反转是什么
5. 结尾要把主角推到什么新状态
6. 结尾留什么钩子给下一卷

### 完整 STC vs 压缩节奏卡

**完整卷内 15 beats**：适用于篇幅长、像独立故事、承担大幅关系变化、核心战役/旅程/真相卷。

**压缩节奏卡**（起点→升级→反转→坠点/胜利→钩子）：适用于过桥卷、过渡卷、篇幅较短的承上启下卷。

## 三、章节职责层

章节层不再套完整 STC。章节的正确问题是：在本卷里负责什么、推进哪个 beat 或承诺感、结束时状态发生什么微变化。

### 可用章节职责标签

| 标签 | 用途 |
|------|------|
| Opening / Setup | 建立当前局面、目标、规则 |
| Catalyst | 让事情真正发生变化 |
| Debate | 让主角犹豫、试探、被迫选择 |
| Break | 主角踏入新局面 |
| Fun and Games | 兑现题材承诺、给读者爽点或新鲜感 |
| B Story | 推进关系线、主题线、搭档线 |
| Midpoint 预热 | 为中点反转做铺垫 |
| Midpoint | 改变局面认知 |
| Pressure | 加码、压缩退路 |
| All Is Lost | 把主角推到底 |
| Dark Night | 低谷后的沉降、重组 |
| Break Into Three | 顿悟、找到新方案 |
| Finale | 执行新方案并证明蜕变 |
| Hook | 章末留下驱动下一章的钩子 |

一个章节 1 个主职责 + 1 个副职责，不超过 2 个。

## 四、章节数多时的切法

不需先定具体章节数。先按"职责段"切，再进入逐章规划。

示例：
```
Vol-02 职责段

第 1 段（卷首）：Break Into Two 后的新局面建立
第 2 段（卷中前段）：Fun and Games，兑现题材承诺
第 3 段（卷中关系推进段）：B Story 加深
第 4 段（卷中关键转折段）：Midpoint 预热和爆发
第 5 段（卷中后段）：Bad Guys Close In
第 6 段（卷末）：卷末反转 + 钩子
```

`novel-discuss` 再去把某一职责段拆成具体事件。全书和分卷规划先回答"这段负责什么"，事件规划阶段再回答"这一事件多少章"。

## 五、补完设定后重排

世界观、势力、规则、角色动机补完后，优先检查：
1. 主母型是否仍然成立
2. 哪些卷的承诺感被改变
3. 哪些 beats 的落点不再自然
4. 哪些章节职责需要挪位

建议重排顺序：先改全书层 → 再改分卷层 → 最后改章节职责层。不要从单章补丁开始修。

## 六、常见错误

### 错误 1：每卷写成同一套模板

表现：每卷都是到新地方、遇新人、打一场、升一级、留钩子。

修正：明确每卷承担的结构功能不同——有的卷负责承诺感，有的卷负责真相，有的卷负责关系裂变。

### 错误 2：每章承担太多职责

表现：一章里既想世界观展示、又爽、又反转、又推进感情、又埋伏笔。

修正：每章只保留 1 个主职责和 1 个副职责。

### 错误 3：把分卷层缺口推给逐章规划

表现：卷没有目标，直接让逐章规划填补。

修正：先补卷目标和卷节奏卡，再做逐章规划。

## 七、推荐工作流

1. `novel-bookplan` 选主母型 / 副母型
2. `novel-bookplan` 建全书节奏蓝图
3. `novel-bookplan` 拆分卷节奏卡
4. `novel-bookplan` 给出某卷的职责段
5. `novel-discuss` 按职责段规划下一事件
6. `novel-sync` 随写作进度更新状态
