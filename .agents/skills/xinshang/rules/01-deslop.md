# 01 · 去 AI 规则（6 Gate + 禁用词 + 7 模式）

> 适配自 `claude-novel-skills` 的 deslop 规则集。
> 本文件只放《心上众生》直接用得上的；完整通用版见 `.claude/skills/claude-novel-skills/rules/`。

---

## 一、6 Gate 门禁（写后自检过一遍）

| Gate | 检测维度 | 一句话规则 |
|------|----------|-----------|
| **A** | 禁用词 | 扫本文件第二节 + `references/checklist.md` 的速查表 |
| **B** | 句式套路 | 「不是 A 而是 B」/「带着…的」/ 连续 3 句以上同结构排比 |
| **C** | 情绪告知 | 「他感到 / 她意识到 / 心头一震」→ 改身体反应、动作 |
| **D** | 节奏均匀 | 连续 5 段长度相近 / 一段超 5 句 / 整章 3 段以上全是短句 |
| **E** | 对话同质 | 所有角色同一语气 / 对话标签密度 >30%（「说道/问道/叹道」堆叠） |
| **F** | 结尾升华 | 「他终于明白了…」「这一刻…」/ 总结 / 升华 / 哲理 / 预告 → 删，停在动作上 |

**A 是硬门槛**（命中即重度 AI）；B/C/D/E/F 是软门槛（按需改）。

## 二、禁用词（三档 + 句式）

### A 档（出现即修，最毒）

- 「不是 A，而是 B」/「不是 A，不是 B，而是 C」：直接写 B
- 「…，带着…」万能状语：拆短句或换动作
- 「他/她知道……」/「他终于明白……」：用行为展示
- 「仿佛 / 犹如 / 宛若……一般」：删或白描
- 「眼中闪过一丝 / 嘴角勾起一抹 / 心中涌起一股」：用身体反应
- 「深吸一口气 / 缓缓 / 轻轻 / 静静 / 不由得 / 情不自禁」：删或换动作

### B 档（一级禁用词，高频或偷懒时处理）

情态：仿佛、犹如、宛若、如同、一丝、一抹、些许、几分、隐约
动作：深吸一口气、缓缓、不禁、微微、轻轻、淡淡
表情：眼中闪过、嘴角勾起、眉头微皱、眉眼低垂、瞳孔微缩
心理：心中一动、心头一震、心下了然、心中暗道、心底泛起、不由得
判断：不容置疑、不容置喙、不易察觉、显而易见、毫无疑问、不可否认
形容：坚定、闪烁着光芒、狡黠、深邃、凛冽、冰冷
过渡：不由自主、情不自禁、自然而然

### C 档（语境敏感，仅高频或偷懒时处理）

突然、好像、瞬间、忽然、这一刻、原来、真正的、缓缓、轻轻、静静

> 出现「**忽然**」仅限物理突然（球忽然砸下来）。其余场景视为心理/时间用 → 删。

## 三、7 种 AI 写作模式（写后逐条扫）

1. **AI 高频词**：不禁、仿佛、映入眼帘、心中暗道、沉声道、嘴角微扬、不由自主、只见、此时此刻、目光如炬
2. **弱化副词泛滥**：每 1000 字「微微/淡淡/缓缓/轻轻」>3 个 = AI 签名
3. **意义膨胀**：意义深远、前所未有、可谓、未来可期 → 写具体后果/对比/动作
4. **万能结论**：未来可期、前途无量、充满希望 → 用未解决的紧张感结尾
5. **论文体开头**：不难看出 / 由此可见 / 事实上 / 综上所述 → 删
6. **书面语连词泛滥**：于是乎 / 与此同时 / 从而 / 因而 / 诚然 → 口语化或删
7. **三连排比癖**：把事情凑成三个以显「完整」→ 砍到只剩最有力的一条

## 四、章末收束硬规则（Gate F 重点）

**章末禁止**：
- 总结性感悟（他终于明白了……）
- 升华式感叹（这一夜，注定无人入眠）
- 哲理式收尾（人生就是这样……）
- 伏笔式预告（他不知道的是，更大的风暴即将来临）

**章末允许**：
- 一个动作（他关上门，没回头）
- 一件物品（床底下那个纸袋还在原位）
- 一句没说出口的话
- 一个新问题
- 一个具体细节（指尖在裤缝上蹭了蹭）
- 安静（他只是站着，巷子没人）

## 五、Show Don't Tell 五对照

| Tell（删） | Show（替换为） |
|-----------|---------------|
| 他是个胆小的人 | 他把检查报告在手里翻来覆去看了三遍，还是不敢打开 |
| 这间酒吧很吵 | 酒保凑到他耳边喊了两次他才听见 |
| 她很富有 | 她随手把一张信用卡丢在桌上 |
| 他很聪明 | 三秒钟他就把文件合上：「第三页，第二行。」 |
| 他很愤怒 | 他把筷子往桌上一拍，碗里的汤溅了出来 |
| 他很紧张 | 他攥紧了手里的纸杯，水洒出来一些 |
| 他很伤心 | 她低头搅着咖啡，搅了很久 |
| 那一夜他很难入睡 | 楼上洗衣机响到后半夜，他就在那声音里睁着眼 |

## 六、对话五级递进（写冲突对话时参考）

同一冲突，从弱到强：

1. 客观陈述：「你把我的东西扔了。」
2. 陈述 + 建议：「你把我的东西扔了，以后能不能先跟我说一声。」
3. 主观指责：「你凭什么动我的东西。」
4. 指责 + 命令：「你算什么东西，也配碰我的东西？滚出去。」
5. 指责 + PUA：「我伺候你吃伺候你穿，你连个东西都放不好。你这辈子也就是这样了。」

**AI 最爱停留在 1-2 级**（温和、解释、客气）。真实的人在压力下会快速爬到 3-4 级。

## 七、系统性去 AI 三遍法（按严重度选）

| AI 味程度 | 策略 |
|----------|------|
| 轻度 | 只做 **Pass 1**（去泛化） |
| 中度 | Pass 1 + **Pass 2**（去书面化） |
| 重度 | 完整三遍 + 重点段落重写 |

**Pass 1 去泛化**：抽象情绪总结句 → 删或换具体动作；假深度句 → 删；空洞结论 → 删；装饰性形容词 → 白描。
**Pass 2 去书面化**：分析性用词（机制/结构/逻辑/体系）→ 日常表达；体制内用语（进一步/深入/推进/落实）→ 删。
**Pass 3 回自然感**：加感官细节、区分角色语气、长短句交错、场景特有记忆点。

> 三遍法不删除情节/设定/关系信息，只改写表达。
> 全文最多 3 轮完整修复；同一段连续 2 轮无变化就停。

## 八、量化分级（客观评分参考）

| 指标 | 轻度 | 中度 | 重度 |
|------|------|------|------|
| 禁用词密度（每千字） | ≤5 | 6-15 | >15 |
| 连续排比数 | ≤2 | 3-4 | ≥5 |
| 心理描写词比例 | ≤10% | 10-25% | >25% |
| 对话标签密度 | ≤30% | 30-50% | >50% |
| 平均段落句数 | ≤3 | 3-5 | >5 |
| 重复描写密度（每千字） | ≤1 | 2-3 | ≥4 |

**最高严重度决定整体级别。**

## 九、白名单机制

项目根目录 `.deslop-whitelist` 中的词不会被标禁用词。
**默认空**。如有例外（如某人物的口头禅），按需添加，不滥用。
