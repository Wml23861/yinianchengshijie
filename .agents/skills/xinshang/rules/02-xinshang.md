# 02 · 项目铁律（《心上众生》专用）

> 通用去 AI 规则见 `rules/01-deslop.md`。
> 本文件放《心上众生》特有的、不能套用通用规则的几条硬约束。

---

## 一、连续句号铁律（最高优先级，硬门槛）

**项目最显眼 AI 签名 = 句号碎片化**。具体规则：

1. **一段句末符 ≤3**（句号 + 问号 + 感叹号 + 省略号加起来）。超过就拆段。
2. **段内不出现「句号后紧跟几个字短句再句号」**：
   - 错：「他停住了。不是王。」→ 对：「他停住了，不是王。」
   - 错：「他就是急。这种急法他熟得很。」→ 对：「他就是急，这种急法他熟得很。」
3. **不能每段都拆成单句短段**（一句话一段贯穿全章是另一极端 AI 味）。长短句搭配。
4. **高频陷阱词**：`X问` `X说` `X没应声` `X应着` `X没再劝` 后面若还接句子，一律改逗号合并。
5. **不写**「句号 + 几字短句 + 句号」拼贴。

> 硬规则自检脚本 `novel/工具/硬规则自检.py` 已内置检测，此项 [X] 即整章不通过，其它项不评分。

---

## 二、字数铁律（硬下限）

- **每章 3000-3300 字**（汉字 + 标点，脚本口径，含标点）
- **目标 3000+**（不要贴 2800 兜底）
- **最低 2800 兜底**（仅当一场景 3000 字写不完整才用）
- **第一遍就写足**（写短了再补是最耗时返工，第 18 章教训）
- **估算**：约 45-55 段，每段 70-90 字（2-3 句），对话短行占行不占字

---

## 三、零破折号 / 零英文 / 零 AI 关键词

**零破折号**：正文中所有 `——` `—` `–` `－` 一律改为逗号 / 句号 / 冒号 / 分号 / 重新组织句子。

**零英文**：正文禁止 PPT / KPI / OKR / deadline / email / App 等英文缩写（已成中文日常的除外）。

**零 AI 关键词**：忽然 / 这一刻 / 仿佛 / 真正的 / 原来 / 缓缓 / 轻轻 / 静静 / 慢慢 / 越 X 越 / 不知何时 / 沉默良久 / 深吸一口气 / 嘴角露出一丝笑容 / 眼神复杂（见 `01-deslop.md` 完整列表）。

---

## 四、对话格式（专治逗号超 3）

**用完整句。X 说，新句。**：
- 对： `"对了。"母亲说，"你爸养了几只鸡，这两天下蛋了。"`
- 错： `"对了，"母亲说，"你爸养了几只鸡，这两天下蛋了"`（逗号堆叠超 3）

**单句逗号 ≤3**（含对话引号内）：一句话到句末为止，逗号最多 3 个，超了就拆句。

**省略号用「……」**：对话没说完、戛然而止、犹豫。禁用破折号代替。

**引号嵌套**：外层「""」全角双引号，内层「''」全角单引号。**禁用半角英文引号 `"` `'`**（硬失败触发）。

## 五、跨章不重复铁律（实战教训：第 16-20 章）

### 1. 现实场景多样化
- **同一现实场景，相邻两章不得重复**。上一章写了出租屋+手机+天花板，这一章必须换。
- 现实线可写：办公室、会议室、工位、菜市场、超市、银行、医院、父母家、咖啡馆、球场、搬家、修车、赶火车、相亲、同学聚会、楼下早餐摊、快递点、健身房、深夜便利店、公园、公交、雨里的公交站。
- 现实线不要每章都「晚上下班回家」。明心也有白天、周末、中午吃饭、通勤以外的时刻。

### 2. 心界人物不每个都当明心镜子
- 16/17/19 章连续用「遇象征人物 → 观察 → 想起自己 → 发现像自己」结构。
- 铁律：**这个结构不能连续两章以上**。心界人物可以有：误会、冲突、拒绝、争吵、对方就是他的人生（跟明心无关）、帮了明心一个跟主题无关的忙、甚至讨厌明心。
- 不要每个象征人物出场都当明心的镜子。众生首先是众生，其次才可能是镜子。

### 3. 意象间隔
- 同一意象近 5 章合计 ≤10 次；一个意象当完某章核心道具后，至少隔 3 章再用。
- 尤其警惕「天亮/天黑」：一章最多 2 次；不得用「天一点点亮起来」过程描写撑字数。

### 4. 心界↔现实过渡方式要换
- 进入/离开心界的过渡方式，相邻两章不得相同。可以：白天走路忽然进入、正在做一件事时切换、被一个声音/气味/触感带进去、章节开头直接已在心界（不写怎么进去的）。
- 不能每章都「躺下 → 往下沉 → 进入心界」。

### 5. 字数靠事件，不靠环境描写和心理活动堆
- 每章 3000 字主要靠剧情（事件 / 对话 / 人物反应）撑，不靠堆砌环境描写和内心独白。
- 如果 3000 字写不满，说明这章事件不够，回去加事件，不是加「他又看了一眼天花板」。

## 六、心界/现实双线铁律

### 1. 配比
- **前 100 章**：心界 85-90% / 现实 10-15%。心界为主，现实负责触发与落地。
- 时代 2-4 可调整，章节卡标注。

### 2. 心界不是单纯副本
- 现实发生的事情 → 可能进入心界。
- 心界发生的变化 → 必须影响现实中的选择。
- **每一次重要心界经历，都应该在现实世界留下痕迹**：
  - 心界里明心学会松手 → 现实里他放下了一次争论
  - 心界里明心看见恐惧 → 现实里他第一次没有逃避一件事
  - 心界里明心发现自己需要认可 → 现实里他第一次没为掌声做选择

### 3. 现实对境库（必须轮换）
- 覆盖：工作 / 家庭 / 婚姻 / 亲子 / 爱情 / 金钱 / 社交 / 学习 / 疾病 / 死亡 / 衰老 / 孤独 / 失败 / 成功 / 消费 / 网络 / 信息过载 / 时间管理 / 拖延 / 成瘾 / 身份焦虑 / 人生选择
- **禁止短期重复**：同一现实对境相邻两章不重样。如连续写工作压力，前一章是会议室，下一章是加班回家，再下一章是同事升职，再下一章是工作失误。

### 4. 经典三线（不可强行塞）
- 儒释道 + 心学 + 禅宗
- 关键处一句原文做钥匙，不多引、不长讲
- 随人物人生自然带出（不是课程表）
- **原文不编造**：无法确认就不加引号，写成人物自己的理解
- 一章 0-1 句金句；连续 5 章可以全无经典，不强求

## 七、人物铁律

### 1. 21 类念头众生 + 顾命五大臣
- 写心界人物前必查登场记录（`36_心界众生谱.md`）。
- 已经登场过的人物一律按重逢写，称谓沿用既定：
  - 五大臣自称「臣」、称明心「王/您」
  - 心界百官/百姓称明心「王」
  - 念头众生各有自报家门方式
- 明心没有失忆设定，认得的都记得。

### 2. 众生是有心路的
- 配角不是工具人：扫地僧和主角，在佛眼里无二无别，笔下亦然。
- 每个角色都要有心路、执着与放下、恐惧与面对。
- 哪怕反派也有自己的过去、习惯、脾气、身体、记忆、朋友、敌人、欲望和恐惧。
- **不点破象征**：「这个人物就是你的愤怒」这种解释太直接，让读者自己发现。

### 3. 反派核心原则（24 字段档案）
- 表层欲望 / 深层恐惧 / 过去创伤 / 错误信念 / 保护机制 / 真正需求 / 最大执着 / 最害怕失去 / 最终必须面对
- 例子：赤炎：表层（力量）→ 深层（害怕失去）→ 错误信念（只有力量才能保护重要的人）→ 保护机制（愤怒）→ 真正需求（允许自己承认害怕）

### 4. 父母是好人、是暖色
- 禁止写父母的不是，禁止家人生病/欠债
- 家庭压力只来自明心自己（报喜不报忧、亏欠、期待）

### 5. 经典不能成为「移动讲义」
- 明心不能每次遇到问题都立刻讲出答案
- 必须经历：不知道 → 误解 → 尝试 → 失败 → 重新看

## 八、章末收束（再次强调）

| 禁止 | 允许 |
|------|------|
| 总结性感悟「他终于明白了…」 | 一个动作（关上门，没回头） |
| 升华式感叹「这一夜，注定…」 | 一件物品（床底那个纸袋还在） |
| 哲理式收尾「人生就是这样…」 | 一句没说出口的话 |
| 伏笔式预告「他不知道的是…」 | 一个新问题 |
| 三短句递进升华 | 一个具体细节 |
| 低级钩子「更大的风暴即将来临」 | 安静（他只是站着，巷子没人） |

## 九、AI 味专项七项（自检加分项）

每章额外打分（任一 ≥7 必改）：

1. **模板化**（0-10）：结构是否机械化（开头冲突→对话→经典→悟道→金句→钩子）
2. **总结感**（0-10）：是否替读者/人物总结
3. **说教感**（0-10）：是否作者腔
4. **金句密度**（0-10）：是否过密（一章 >2 句金句）
5. **句式重复**（0-10）：同构句是否连用
6. **人物机械感**（0-10）：是否所有人都像作者说话
7. **经典硬塞感**（0-10）：经典是否与当下人物经历强相关
