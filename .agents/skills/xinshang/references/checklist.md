## 四、禁用词速查（命中即改）

### A 档（出现即修，最毒）
- 不是 A，而是 B / 不是 A，不是 B，而是 C
- …，带着…（万能状语）
- 他/她知道… / 他终于明白…
- 仿佛 / 犹如 / 宛若…一般
- 眼中闪过一丝 / 嘴角勾起一抹 / 心中涌起一股
- 深吸一口气 / 缓缓 / 轻轻 / 静静 / 不由得 / 情不自禁

### B 档（高频偷懒时处理）
- 情态：仿佛、犹如、宛若、如同、一丝、一抹、些许、几分、隐约
- 动作：深吸一口气、缓缓、不禁、微微、轻轻、淡淡
- 表情：眼中闪过、嘴角勾起、眉头微皱、眉眼低垂、瞳孔微缩
- 心理：心中一动、心头一震、心下了然、心中暗道、心底泛起、不由得
- 判断：不容置疑、不容置喙、不易察觉、显而易见、毫无疑问、不可否认
- 形容：坚定、闪烁着光芒、狡黠、深邃、凛冽、冰冷
- 过渡：不由自主、情不自禁、自然而然

### C 档（语境敏感）
- 突然、好像、瞬间、忽然、这一刻、原来、真正的、缓缓、轻轻、静静

**「忽然」**仅限物理突然（球忽然砸下来）。其余场景视为心理/时间用 → 删。

### 项目专用硬禁用
- 破折号 —— — – －（全数 → 逗号/句号/冒号/分号/重写）
- 英文缩写 PPT/KPI/OKR/deadline/email/App（已成中文日常的除外）
- AI 关键词：见 A 档

## 五、章末收束硬规则（Gate F 重点）

**章末禁止**：
- 总结性感悟（他终于明白了……）
- 升华式感叹（这一夜，注定无人入眠）
- 哲理式收尾（人生就是这样……）
- 伏笔式预告（他不知道的是，更大的风暴即将来临）
- 三短句递进升华
- 低级钩子（更大的风暴即将来临）

**章末允许**：
- 一个动作（他关上门，没回头）
- 一件物品（床底下那个纸袋还在原位）
- 一句没说出口的话
- 一个新问题
- 一个具体细节（指尖在裤缝上蹭了蹭）
- 安静（他只是站着，巷子没人）
