# 对比优化规则

## 核心哲学

**不靠死板的评分标准，而是通过与优秀作品的对比来提升质量。**

- 将生成内容与 `[skill]/references/` 目录下的优秀小说进行对比
- 从结构、内容、技法等多个维度找出差距
- 针对性优化，使输出达到参考作品的水平

## 参考小说位置

`[skill]/references/` 目录下存放用户认可的参考小说文件（`.txt` 或 `.md` 格式）。也可将参考信息保存在 `设定/参考小说_[小说名].md`。

## 对比维度

### 七维度全面对比

| 维度 | 对比内容 | 优化方向 |
|------|----------|----------|
| **结构设计** | 叙事结构、章节安排、伏笔设置、节奏控制 | 对齐参考作品的结构水平 |
| **内容描写** | 场景描写、感官细节、氛围营造、情感渲染 | 达到参考作品的描写细腻度 |
| **人物塑造** | 角色设计、对话写作、行为刻画、性格展现 | 参考作品的人物立体感 |
| **写作技法** | 钩子设置、悬念控制、情感节奏、高潮设计 | 学习参考作品的技法运用 |
| **节奏控制** | 快慢交替、张弛有度、章节节奏、情绪节奏 | 匹配参考作品的节奏感 |
| **对话质量** | 口语化程度、潜台词、人设化、信息效率 | 参考作品的对话水准 |
| **情感渲染** | 情感浓度、渲染手法、读者共情、情绪波动 | 达到参考作品的情感强度 |

### 分阶段对比重点

| 阶段 | 对比重点 |
|------|----------|
| 灵感 | 核心设定吸引力、角色设计反差魅力、情节展开可能性 |
| 大纲 | 整体结构设计、章节节奏安排、伏笔埋设与回收、高潮节点设置、人物成长弧线 |
| 正文 | 场景描写细腻度、对话自然度和信息量、情感渲染浓度、节奏控制精准度 |

## 极端化原则

**好小说不是各维度都高分，而是某个维度做到极致。**

优化时优先增强内容的自然优势维度，而非平均用力：

| 核心体验 | 极端化标准 |
|----------|-----------|
| 暧昧感 | 让读者脸红心跳，反复回味 |
| 诱惑力 | 让读者血脉贲张，欲罢不能 |
| 悲伤感 | 让读者泪流不止，久久不能释怀 |
| 笑点密度 | 让读者笑出声来，停不下来 |
| 悬念感 | 让读者猜不到结局，欲罢不能 |
| 热血感 | 让读者热血沸腾，握紧拳头 |
| 甜蜜度 | 让读者甜到牙疼，嘴角上扬 |
| 治愈感 | 让读者感到温暖，内心平静 |

## 去耦合化评估

对比时检查：
1. **角色维度多样性**：同一角色在不同场景是否展现了不同的情绪×行为×语言组合？
2. **情节元素独立性**：事件类型、事件风格、场景氛围是否独立选择？
3. **交叉组合新鲜感**：角色特点与情节元素的组合是否给读者带来意外？

## 达标标准

以参考作品为基准：
- 达到参考作品的核心水平 → 达标
- 超过参考作品 → 优秀
- 未达到参考作品 → 继续优化

如果无参考作品，使用默认标准：
- 结构完整、逻辑自洽
- 描写细腻、有画面感
- 对话自然、有人设感
- 节奏合理、有起伏感
- 情感到位、有共鸣感
