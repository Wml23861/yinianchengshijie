# 小说创作项目
<!-- skill-version: 10.0.0 -->

## 使用 Skill

本项目使用 `/novel` skill 进行创作。所有写作规则、技法、去AI味规则由 skill 提供。

**入口**：调用 `/novel` skill，进入小说创作系统。

---

## 目录结构

```
项目根目录/
├── 灵感/          → 灵感最终版
├── 设定/          → 创作设定 + 世界观 + 参考小说
├── 大纲/          → 全书大纲
│   └── 章节大纲/  → 章节大纲 + 世界线系统 + 角色剧情
├── 正文/          → 各章 txt 文件（纯正文）
│   └── [小说名]/
└── 追踪/          → 情节追踪 + 角色追踪 + 上下文摘要 + 写作反馈
```

## 关键文件

| 文件 | 用途 |
|------|------|
| `追踪/上下文摘要.md` | 恢复上下文（伏笔、关系、当前场景） |
| `追踪/情节追踪.md` | 情节去耦合组合记录 |
| `追踪/角色追踪.md` | 角色去耦合塑造记录 |
| `大纲/角色系统_[小说名].md` | 角色当前状态、关系网络 |
| `大纲/章节大纲/世界线系统_[小说名].md` | 时间线、事件、伏笔状态 |

## 工具和规则

所有工具和规则由 `/novel` skill 自动加载，位于 skill 安装目录（`~/.claude/skills/claude-novel-skills-main/`）：

- **技法库**：`[skill]/tools/techniques/`（角色塑造、情节构造、正文写作、反面教材）
- **去耦合组件**：`[skill]/tools/decoupled/`（角色特点分类、情节元素分类）
- **规则集**：`[skill]/rules/`（输出、优化、去AI味、检查、禁用词）
- **参考资料**：`[skill]/references/`

> `[skill]/` 前缀 = skill 安装目录，无前缀 = 项目根目录。
