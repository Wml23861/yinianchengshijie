# /写一章 → 写一章正文

A 写正文的命令。**前置条件：必须先有 48 骨架**（用 /设计一章 生成），无骨架不准动笔。
**写前必读** `novel/设定库/写作流程/52_对话与标点格式手册.md`（**2026-09-01 硬关化**）—— 漏调 = 51 章事故重演。

---

## 一、4 步流程

### 第 1 步：读骨架（2 分钟）

读 `novel/创作记录/第N章_标题_骨架.md`。骨架不存在 → 提示用户先敲 `/设计一章 第N章`。

### 第 2 步：写正文（30-40 分钟）

按 48 骨架的 4 填空 + 设计说明写正文。

**格式硬关（**2026-09-01 硬关化**）**—— 边写边查，不要等脚本兜底：
- 对话每句独立成段（前后空行隔开）—— P0
- 对话全部用全角 `""`，无半角 `"`、无 `「」` —— P0
- 段首不能 `。`（句号）—— P0
- 段中不要 `。+主语` 碎片化（用 `，` `；` `：` 承接）—— P0
- `"X说"` 不连用 3+ 次 —— P0
- 一段对话 8+ 句：至少 2 处非"说"动词 / 动作打断 / 停顿打断 / 答非所问
- 详细规则见 `52_对话与标点格式手册.md` §1-§6

**每段前问 3 问**（CLAUDE.md 卷二）：
1. 此刻是谁/在哪/因为想要什么/做了什么？
2. 这一段是"事件"还是"道理"？（事件继续；道理删掉或挪到对话里）
3. 删掉"作者解释"后，剩下的内容是否还成立？

**写完每段必查**：
- 不写"忽然""这一刻""人生就是这样""原来……""真正的……"
- 不连续 2+ 个同构句
- 不用"深吸一口气""沉默良久""嘴角微微上扬"
- 不用空洞大词（深邃/古老/震撼/灵魂/宿命）

### 第 3 步：跑硬规则脚本（2 分钟）

```bash
python novel/工具/硬规则自检.py <章文件>
```

任何 `[X]` 必改到 `[OK]`。**连续句号 `[X]` 即整章不过。**

Windows bash 找不到 Python：
```bash
export PATH="/usr/bin:/bin:/f/Program Files (x86)/python:$PATH"; cd "e:/心界/yinianchengshijie" && python novel/工具/硬规则自检.py <章文件>
```

### 第 4 步：删哲理自检（5 分钟）

把以下段落**整段删掉**：
- "人生就是这样""原来……""真正的……""其实……"
- 总结性心理活动（"这一刻他终于明白……"）
- 金句/排比/三个"不是 X 是 Y"
- 经典原文引用（除非角色真的在念经）
- "作者借人物讲哲理"的段落

自检：
```
[ ] 剩 ≥ 60% 字数
[ ] 有人物欲望在驱动
[ ] 有具体动作在推进
[ ] 有至少一个事实变化
[ ] 主角还在"做事"，不是"想事"
[ ] 至少一个配角有自己的私事
```

剩不到 60% → 重写对应段落。
