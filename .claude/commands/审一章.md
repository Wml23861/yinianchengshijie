## 四、5 大硬关（审核CLAUDE.md 卷二）

### 硬关 ①：删哲理测试（P0 / 一票否决）

把以下段落整段删掉：
- "人生就是这样""原来……""真正的……""其实……"
- 总结性心理活动（"这一刻他终于明白……"）
- 金句/排比/三个"不是 X 是 Y"
- 经典原文引用（除非角色真的在念经）
- "作者借人物讲哲理"的段落

剩 ≥ 60% 字数 / 仍有人物欲望在驱动 / 有具体动作在推进 / 有事实变化 / 主角还在做事 / 至少一个配角有私事
**任一不达 → P0**

### 硬关 ②：人物生活测试（P0）

对每个出场人物问 4 问：
1. 有自己的私事？
2. 有具体的生活细节？
3. 有与象征意义无关的个人爱好？
4. 在这章里犯过错？（误解/犹豫/嘴硬/答非所问）

任一人物 4 问都"否" → P0

### 硬关 ③：AI 痕迹扫描（P0/P1）

- A. 硬规则脚本结果（必查）— [X] 即 P0
- B. 模板句扫（grep 一次，看 3+ 同类 → P1）
- C. 同构句扫（连续 3+ 同结构 → P1）
- D. 连续句号（`。。` `句号碎片化` → P0）
- E. 空洞大词（深邃/古老/震撼/灵魂/宿命，单章 2+ → P1）
- F. 经典原文核验（凭记忆编/出处错/拼接 → P0）
- **G. 52 手册格式扫描（**2026-09-01 硬关化**）** —— 见 `52_对话与标点格式手册.md`：
  - 对话未独立成段（一行 3+ 对 `""`） → P0
  - 段首是 `。` → P0
  - 段中 `。+主语` 碎片化（连续 2 段都以主语开头且段尾是 `。`） → P1
  - `"X说"` 一段内 4+ 次 → P1
  - 半角引号 / `「」` 方头括号 → P0
  - 一段对话 8+ 句无动作/停顿/非"说"动词打断 → P1

### 硬关 ④：现实 ↔ 心界映照测试（P1）

- 1. 本章现实线有具体场景？（不是全是"他躺在床上"）
- 2. 心界发生的事在现实留痕迹？
- 3. 现实发生的事对应心界？
- 4. 现实场景与最近 3 章是否重样？

任一不达 → P1

### 硬关 ⑤：二十章反重复矩阵（P1）

对照 49_二十章反重复矩阵.md 5 张表：
- 表 1 现实场景：相邻两章重样 → P1
- 表 2 心界人物落点：连续 2 章"遇→像自己" → P1
- 表 3 关键意象：近 5 章合计 > 10 次 → P1
- 表 4 开头形式：20 章内同一种 > 3 次 → P1
- 表 5 触发结构：进出心界过渡重样 → P1

5 项至少换 3 项。本章必须与最近 5 章至少有 3 项不同。
