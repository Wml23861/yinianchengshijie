## 四、执行流程（4 步）

### 第 1 步：自动跑 /设计一章

按 /设计一章 命令的 4 步生成骨架（4 填空 + 5 张表差异 + 200-400 字设计说明）。
存到 `novel/创作记录/第N章_标题_骨架.md`。

### 第 2 步：写正文

按骨架 4 填空写正文。每段前问 3 问（CLAUDE.md 卷二）。

### 第 3 步：跑硬规则脚本

```bash
python novel/工具/硬规则自检.py <章文件>
```

任何 `[X]` 必改到 `[OK]`。**连续句号 `[X]` 即整章不过。**

### 第 4 步：删哲理自检 + 滚动复审前两章

删哲理自检（剩 ≥ 60%）。

滚动复审前两章（CLAUDE.md 雷区清单 25）：
- 衔接重复（当前章开头与前章结尾是否逐句重复）
- 状态连续（时间/地点/身体/位置）
- 前文遗留（前两章埋的伏笔/钩子是否遗漏）

## 五、跨章不重复铁律（必过）

- 现实场景：相邻两章不重样
- 心界人物：不当连续 2 章镜子
- 意象：近 5 章合计 ≤10 次
- 过渡：相邻两章不重样
- 一章「天亮/天黑」最多 2 次
