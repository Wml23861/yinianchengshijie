# /写六章 → xinshang Skill 写六章

本命令是 **xinshang Skill** 的薄壳（写六章单会话闭环）。与 `/写一章` `/审一章` `/继续下一章` **互斥、不共用闸门**。

---

## 一、调 Skill 工作流

按 `workflows/write-six.md` 执行：

1. **加载 Skill** 入口：`.claude/skills/xinshang/SKILL.md`
2. **加载铁律**：`rules/01-deslop.md` + `rules/02-xinshang.md` + `rules/03-management.md`
3. **加载速查**：`references/checklist.md` + `references/templates.md` + `references/script.md`
4. **执行流程**：workflows/write-six.md 十一节（触发 / 连写六章 / 脚本自检 / 落正文 / 子代理复审 / 返修 / 复审 / 闭环 / 到顶未通过 / 纪律 / 与其他命令关系）

---

## 二、边界

- 一次性写 **6 章**（`$ARGUMENTS` 可覆盖，见第三节）
- 六章全部写完并自检通过，才交审核
- 审核**必须**跑（与 `/写一章` 不同，`/写六章` 是自动复审）
- 循环到六章全部零 P0/P1，且 P2/P3 都有处置
- **创作记录/、审核记录/ 一律不写**（项目永久废弃）；全流程通知输出在对话 + 47 顶部进度行
- 项目里只落两样：**六章正文** + 47 顶部一行进度
- git 绝不自主提交

---

## 三、确定本批章号

读 `$ARGUMENTS`：

- `43-48` 形式 → 按区间写
- `43` 形式 → 从 43 起连写 6 章
- `4` 这种小数字（≤20 且当前正文已超过它）→ 视为章数，从正文最大章号 +1 起连写这么多章
- 空 → 扫 `novel/正文/01_第一卷_入道/01_第一时代_尘中少年/` 取最大章号，+1 起连写 6 章

确定后，先把「本批 = 第 X 至第 Y 章」在对话里报出来，再动笔。

## 五、阶段一：创作（按 workflows/write-six.md 第二节）

每章：
1. 查登场记录（grep 前文 + 36_心界众生谱.md）
2. 设计章节（CLAUDE.md 第七十二条 12 字段）
3. 写正文（3000-3300 字，一章一个事件单元）
4. 跑脚本（任何 `[X]` 当场修到 `[OK]`，不许攒到最后）
5. 八轮自查 + 43 维度 + 44 第二节七张平滑脸

**批内横向自查（六章连写独有）**：
- 现实线场景：相邻两章不得重复
- 心界人物落点：不得连续两章以上都是「遇象征人物→观察→想起自己→发现像自己」
- 意象：近五章合计 ≤10 次；核心道具隔 3 章再用
- 进出心界过渡：六章不得雷同
- 章节结尾形式：六章不得雷同
- 字数不得靠环境描写和心理独白堆，靠事件撑

---

## 六、阶段二：独立审核（子代理，干净上下文）

用 `general-purpose` 子代理（`run_in_background: false`）。提示词模板见 `workflows/write-six.md` 第五节完整版。

**子代理按 审核CLAUDE.md 14 轮 + 48 规则审**：
- 跑硬规则脚本（必跑）
- 14 轮审查
- 逐条带证据（40 项清单）
- 批内 + 跨章节重复专项
- 结论只有「通过」或「不通过（N 处 P0 + M 处 P1）」

**复审轮起新子代理**（不复用），提示词追加上一轮 P0/P1 清单 + 逐条核验要求。

---

## 七、阶段三：返修

- **P0/P1 全改，一条不留**
- P2/P3：能改就改；确实不该改的，逐条写明理由
- 每章改完重跑脚本到 `[OK]`
- 改完动过正文，整章从头逐句重审

---

## 八、轮次上限

- **轮次上限 4 轮**（初审 + 3 次复审）
- 到上限仍有 P0/P1：**停下来，如实报告剩余问题和卡住原因，交给用户判断，不许自己宣布通过**
- workflow/write-six.md 第九节列出未通过时回复格式

---

## 九、47 顶部更新（**只改一行**）

- 创作中：「## 当前：/写六章 进度 N/6（第 N 章《xxx》已脚本自检 [OK]）」
- 待复审：「## 当前：/写六章 六章已写完，等独立子代理复审（轮次 1/4）」
- 返修中：「## 当前：/写六章 第 M 轮返修完，等独立子代理复审（M/4）」
- 终审通过：「## 当前：/写六章 六章已通过（轮次 X/4）」

**别的不动。**

---

## 十、终审通过时

1. 47 顶部更新如上
2. 对话输出：
   ```
   【终审通过 · 第 X-Y 章】
   总轮次 N 轮；逐章：章号 | 标题 | 字数 | 最终脚本结果
   累计修掉：P0 N 条 / P1 N 条 / P2 N 条 / P3 N 条
   本批剩余风险与后续建议：逐条（没有就写「无」）
   ```
3. 不提交 git

---

## 十一、纪律

- 零破折号、零英文、零半角标点、引号全角成对、字数 3000-3300（2800 兜底）
- 金句 0-1 句、每章不顿悟、不替读者/人物/作者悟
- 创作者不得自评通过；审核者不得改正文；两者不得在同一轮里互相让步
- 不奉承、不客套、不说「应该没问题」
- 不擅改核心设定，不确定的记待确认
