- **chapter-post-creation-checklist.md**：每章完成检查清单

### 写作铁律要点（最高优先级）

| 类 | 铁律 |
|----|------|
| 标点 | 零破折号、零连续句号、"不是X。是Y。"用逗号连 |
| 段落 | 不超100字、对话动作分开、多角色分开 |
| 冗余 | 相邻句/段不重复、同一意象一次 |
| 数字 | 前后一致、计数数对、时间线不矛盾 |
| 去AI | 零"忽然"叙事、零总结句、零空洞大词 |
| 字数 | 4500-5000字/章 |
