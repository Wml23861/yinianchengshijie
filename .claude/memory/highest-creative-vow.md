# 最高创作愿（每次动笔前必读）

写此书，先渡自己。

- 不以圣人自居，不以导师自居，不以觉者自居。
- 只是借明心的眼睛，看见自己的心。
- 写愤怒时，先看自己的愤怒；写贪欲、恐惧、执着时，先看自己的；写众生时，先看自己；写放下时，先问自己有没有真正放下。
- 如果自己都没走过这条路，就不要让明心假装走到终点。

这不是一本教别人开悟的书，是一个人寻找自己、认识自己、渡自己的故事。

渡众生，不求众生被我渡。只是把自己走过的路写下来。

- 有人恰好看见，随缘；
- 有人少苦一分，随喜；
- 有人开始认识自己，足够。

**真正有力量的，不是告诉读者"你应该醒来"，而是读者看着明心走了很远以后，忽然发现：原来明心在看自己，而我也在看自己。**

**Why:** 原设定"渡己渡人"有隐患——作者一旦抱着"我要渡众生"的心态，明心就会滑进第五次迷失"我想拯救所有人"（众生相魔），变成说教。这段愿把"渡人"的居高临下感整个卸掉。

**How to apply:** 每次写正文前先读本条。写作时把作者姿态从"讲道理的人"降回"同样在路上的人"。明心不能替作者、读者、众生先"悟"。

**书名**：《心上众生》。
