# 创作常见错误清单（第 1-5 章踩过的雷）

> 每次动笔前快速过一遍，逐条对照，避免重犯。

## 一、动笔时（写作过程）

1. **字数不足**：第一遍常只写 1000 字左右（精炼过度）。→ 第一遍就写足 2000 字（约 28-32 段，每段 70-90 字）。
2. **段落太长**：一段塞多件事，超 100 字（最严重 262 字）。→ 一段一件事（60-90 字）。
3. **内容重复**：扩充时塞重复（灰蒙蒙空地×2、你在看什么×2、梧桐叶沙沙×2）。→ 扩充后检查有无重复意象/描述。
4. **精确数字**：像 AI（三千六百五十天、九百多种可能）。→ 用「十年」「三十来岁」等自然说法，不精确到个位数。

## 二、语言 / AI 痕迹

5. **连续句号**：叙述硬断（手。掌心的伤口还在。、救火。没有一个人。）。→ 用程序扫「句号+无标点短句+句号」，改逗号连接。
6. **点破感受**：心里松了、心里安静了一点。→ 用动作/细节（呼出一口气、松开手指），不直接说感受（宪法第四十七条）。
7. **「忽然」叙事**：他忽然很怕、他忽然觉得。→ 零「忽然」（除真实物理突然）。
8. **「这一刻」模板句**。→ 删。
9. **「不是X。是Y」碎句**。→ 逗号连接。
10. **连续同构句**（看见…看见…看见、看着…看着…看着）。→ 变句式。

## 三、逻辑 / 连贯性

11. **人物关系矛盾**（母亲问「有没有对象」、父亲「一个人住」）。→ 动笔前读相关人物设定，尤其现实人物（父母、周薇、张总）。
12. **人物状态没随章节推进**（第 5 章还「腿软」）。→ 每章开头对照前一章的身体状态、位置、时间。
13. **数字前后不一致**（九年 vs 十年）。→ 数字统一，先对设定库（如「十年」= F003）。
14. **表述不当**（「在现实里」，明心不知自己在不在现实）。→ 注意明心的认知边界。

## 四、工程 / 记录

15. **字数统计错误**（grep/tr 不可靠，曾把 2000 误报成 6500）。→ 用 Python 精确统计。
16. **日期写「本次」**。→ 写实际日期 YYYY-MM-DD。
17. **章节名「上下」**。→ 每章唯一名。
18. **复审不彻底**（说「检查完了」却还漏）。→ 用程序全量扫描（连续句号、数字、重复），不靠眼睛零星看。

**核心教训**：别挤牙膏（用户提一句改一句），要主动、全面、一次性查干净。
