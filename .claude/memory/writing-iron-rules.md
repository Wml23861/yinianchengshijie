# 正文写作铁律（不可违反）

创作或修改任何正文时，以下规则是**铁律**，违反任何一条都必须立即修正。

## 一、标点符号（零容忍）

1. **零破折号**：全文禁止 `——`。需要转折用逗号、句号、冒号。
2. **零连续句号（叙述硬断）**：同一段落内，连贯叙述被句号硬断成「X。Y。」碎句（如「手。掌心的伤口还在。」「救火。没有一个人。」），必须改逗号连接。但「有节奏的短句」（内心独白「这是哪儿。」、震惊停顿「十年。」「是火。」）可保留，不算碎句硬断。
3. **"不是X。是Y。"** → 必须写成"不是X，是Y。"（逗号连接）
4. **"不是X。不是Y。是Z。"** → 三连碎句，必须用逗号连成"不是X，不是Y，是Z。"
5. **逗号不超三**：同一句话里逗号不超过三个，超过就断句。
6. **省略号**：对话截断用 `……`，不用破折号。
7. **引号**：外层双引号 `""`，内层单引号 `''`，不能混用、不能遗漏右引号。

## 二、段落（符合阅读习惯）

1. **段落不超100字**：单段超过100字必须拆分。这是硬性上限，不是建议。
2. **一个意思一段**：一段只讲一件事，讲完就换段。
3. **对话与动作分开**：一段对话，一段动作/描写，不要混在一大段里。
4. **多角色分开**：多个角色各自的动作/对话，每人独立成段，不挤在一段。
5. **空行分段**：段落之间用空行隔开，视觉上透气。

## 三、冗余重复（零容忍）

1. **相邻句不重复**：同一段里两句话讲同一件事，删一句。
2. **相邻段不重复**：段首和段末讲同一件事，删一段。
3. **同一意象不重复**：同一个比喻/意象，一章只出现一次。
4. **"不是……是……"句式**：每章不超过五次（特殊章节除外）。
5. **无废话形容词**：连续三个以上"的"字短语，必须断句重组。

## 四、数字与事实（必须严谨）

1. 角色说出的任何数字（字数、时间、人数、年龄）必须前后章节一致。
2. "五个字""六个字"这类计数，必须数对。
3. 时间线不能矛盾（如：不能既"十年前带金手去王城"又"十年前刚挖第一桶金"）。

## 五、去AI痕迹

1. **零"忽然"叙事**：禁止"忽然想起/觉得/懂了/发现"引入感悟或回忆。用场景因果链、触发物、动作替代。每章最多一处，且仅限真实物理突然性。
2. **零总结句**："他终于明白""这一刻他懂了"——每章不超过一句。
3. **零连续"当……的时候"**：连续两个以上必须删改。
4. **零空洞大词**："深邃""古老""某种不可名状"——用具体有质感的词替代。

## 六、字数

- 每章 2800-3300 字（最低 2800 字）。
- 低于 2800 字补具体描写和剧情，不是灌水。
- 高于 3300 字砍重复啰嗦、多余形容词、可合并场景。

## 七、每次修改后必须全章审查

只要动了正文——哪怕改一个字、一个标点——必须从头到尾重新审查：

1. 搜 `——`，必须为零
2. 搜"不是.*。是"、"不是.*。不是"，必须为零
3. 搜"忽然"，每章不超过一处
4. 逐段检查：段落是否过长、是否有连续句号、是否有冗余重复
5. 朗读一遍，呼吸断的地方就是标点错

**此铁律高于一切。违反任何一条，该章视为未完成。**
