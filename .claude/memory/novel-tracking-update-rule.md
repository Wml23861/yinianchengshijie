每次创作完新章节后，必须更新以下文件：

## 必须更新的文件

1. **README.md** — 更新：
   - 总进度（如 "18/50（36%），下一章：第19章"）
   - 对应章节的行：核心、解压、智慧、经文出处、读者获得、生活应用、状态 ✅

2. **生活对境库.md** — 在"对境使用追踪总表"中添加新行：
   - 章节号、对境编号、领域

3. **创作宪法.md / 章节创作规则.md** — 如果新章节产生了需要记录的新规则或模式，更新

## 更新原则

- 更新不是可选的，是创作流程的最后一步
- 准确的追踪数据让下次创作能更好地选对境、选经文、保持一致性
- README 中的章节信息是未来回顾全书结构的唯一索引

**Why:** 不更新追踪文件会导致对境重复、经文碰撞、进度模糊，影响后续创作质量。

**How to apply:** 每完成一章创作后，立刻更新 README.md 的进度和章节行、生活对境库.md 的追踪表。
