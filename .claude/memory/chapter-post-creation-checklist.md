《心界》小说项目：每完成一章创作（或对已有章节进行修改），必须同步更新以下记录文件：

1. `novel/进度面板.md` — 进度条百分比、下一章信息
2. `novel/正文/01_第一卷_入道/README.md` — 卷进度章数和百分比
3. `novel/正文/01_第一卷_入道/01_第一部_五蕴初醒/README.md` — 章数+1，填写本章表格行（核心/解压/智慧/经文出处/读者获得/生活应用）
4. `novel/生活对境库.md` — 新对境入库 + 追踪表更新
5. `novel/人物档案.md` — 新人/新名字/重要转变（如铁壁的转变、阿简的名字）
6. `novel/时间线.md` — 重大事件（如适用）

**Why:** 不更新记录，下次创作时无法快速进入状态，会产生前后矛盾。多个文件中的数字必须跨文件一致。

**How to apply:** 每次创作完成后按检查清单逐项确认。所有文件中的数字（章数、百分比）必须跨文件一致。
