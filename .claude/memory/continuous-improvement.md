## 持续完善原则

《我的心里住着一个世界》目标是流传千古的经典。大纲、规划、规则都不是冻结的——每一章写完后，新产生的认知应该反哺到规划文件中。

### 每次创作后必回顾

1. **README.md 章节规划**：新章标题、核心、解压、智慧填入；规划章标题是否还合理，需要调整随时改
2. **千万字超长篇大纲.md**：实际完成与规划对照，更新进度、修正方向
3. **章节创作规则.md / 创作宪法.md**：如果新章产生了更好的写法或发现了新问题，更新规则
4. **人物档案.md**：新人物出场、旧人物转变，立刻记录

### 规划是活的

- 章标题规划不是铁律——写到那里时如果有了更好的想法，改标题、调顺序、合并拆分都可以
- 大纲的章节数分配是估计值——实际写作中根据节奏调整
- 每次大段完成（如10章）做一次系统性回顾

**Why:** 固步自封的规划会变成枷锁。流传千古的作品不是一次规划出来的，是一步一步走出来的。每一步都在修正上一步的偏差。

**How to apply:** [[novel-tracking-update-rule]] 和 [[chapter-post-creation-checklist]] 已覆盖创作后更新，本规则追加一条：每10章做一次深度回顾，每完成一个大段重读规划文件。
