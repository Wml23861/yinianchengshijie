# 每章创作与审查记录流程

千万字不能靠模型记忆，必须靠文档记录。每章严格执行：

## 创作前（先读，不靠记忆）

1. 读 [[highest-creative-vow]]（最高创作愿）+ writing-iron-rules（铁律）+ 设定库 43_人类化写作规则（人类化写作核心，写前必读）。
2. 读前一章正文（知道上一章写到哪、结尾钩子是什么）。
3. 读 24_章节索引系统（前一章登记：人物、事件、伏笔、对境）。
4. 读 30_章节问题记录（之前出现过什么问题，避免重犯）。
5. 读 39_章节卡（本章规划）+ 18_生活对境库（对境别重复）+ 13_伏笔库。
6. 读本章涉及人物的设定（36 众生谱 / 08 / 09），尤其**现实人物**（父母、周薇、张总）。

## 写完后（审查 → 记录，不是可选）

1. **解压时刻检查**：每章必须有「解压时刻」——跟情节有关、让人放松、含蓄带智慧的一个片刻（明心停下呼吸、看火、听风等），不能通篇紧张。见宪法第四十五条。
2. **审查（滚动复审，8 项）**：AI痕迹 → 逻辑 → 语言 → 标点符号 → 段落 → 排版 → 伏笔 → 衔接（顺序执行，逐项过）。
   - 每次写完，除了审查**当前章**，还要往前**复审前两章**（同样 8 项）。
   - 这样每章至少被审 3 次：创作时一次 + 后面两章各复审一次，问题不遗漏，章节之间连贯性有保障。
   - 【已固化】此规则已明文写入设定库 22_章节质量审查规则.md「一之附：滚动复审」与 23_长篇连续性检查规则.md，以正文为准，本 memory 仅作指针。
3. **在对话里输出完整创作报告**（用户不翻文档就能知道做了什么），固定格式：
   - 【当前章 · 主要做了什么】：内容概要、字数、明心变化、伏笔（埋/回收）、解压时刻
   - 【当前章 · 审查结果】：AI痕迹 / 逻辑 / 语言 / 标点符号 / 段落 / 排版 / 伏笔 / 衔接 逐项 ✅/❌
   - 【当前章 · AI痕迹专项】：破折号、英文、「不是X。是Y」碎句、「忽然/突然」叙事、「这一刻/终于明白/仿佛/原来/真正的/所谓」模板句、连续同构句、点破感受，逐项列结果，并列出「发现并修改的问题」
   - 【前两章复审】：各列一段复审结果（AI痕迹/逻辑/语言/标点符号/段落/排版/伏笔/衔接 逐项 ✅/❌，以及复审发现的问题和修改），复审也要输出到对话
4. **记录到文档**：
   - 42_章节创作记录：详细登记本章（创作信息/伏笔对境/审查结果/问题修改/下一章衔接）。
   - 24_章节索引系统：简表索引（一行一章，章号/标题/时代/核心课题）。
   - 30_章节问题记录：登记审查发现的问题 + 修改动作。
   - 18_生活对境库：对境追踪。
   - 40_进度面板：进度 + 下一章。
   - 13_伏笔库 / 33_已回收伏笔：埋设/回收伏笔。
5. **写完一章停止**，不自动写下一章。

## 关键教训（已记录，勿重犯）

- 字数必须用 **Python 精确统计**（grep/tr 都不可靠），每章 2800-3300 字（最低 2800 字）。
- 写正文前必须对照人物设定，尤其现实人物关系（曾出现「有没有对象」「一个人住老家」两处逻辑矛盾）。
- 章节名唯一，不用「上/下」命名。
- 段落不超 100 字，一段一件事（约 60-90 字），别一段塞多件事、别重复同一内容。
- 解压时刻不点破感受（不写「心里松了」），用动作/细节让读者自己感受。
- 记录日期写实际日期（YYYY-MM-DD），不写「本次」「今天」。
- 时间/年龄/数量等数字，除非剧情需要精确，否则用模糊自然说法（「十年」「三十来岁」），不要精确到个位数（「三千六百五十天」像 AI 写的）。

**Why:** 不记录，千万字到后面会不知道前面写了什么；记录审查错误，才能避免重复、快速解决。

**How to apply:** 每章按「先读 → 写 → 审查 → 记录 → 停」五步走，缺一不可。
