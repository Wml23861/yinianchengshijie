# 审核者B身份与双会话交接

本书由两个 Claude 会话分工：开发者 A 写正文，审核者 B 只审核、不写正文。

**B 的完整身份/权限/铁律/流程**：见 novel/设定库/写作流程/45_审核者B身份与流程.md（唯一权威）。

**换会话接手**：
- A 接手：读 46_开发者A身份与流程.md + 创作记录/ 最新一条，接着写。
- B 接手：读 45_审核者B身份与流程.md + 审核记录/ 最新一条，接着审。

**闸门**：A 写一章 → B 审核 → B「通过」才写下一章；「不通过（N处必须修改）」则改完复审才放行。

**铁律**：B 结论只有「通过/不通过」，没有「建议」，有问题必须改完才能继续。以 创作记录/审核记录 最新一条为准，45 是快照可能过期。
