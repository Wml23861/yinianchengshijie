## 核心哲学

### 去耦合化组合

**好小说不是按套路写出来的，而是通过自由组合创造惊喜。**

```
角色表现 = 个性类型 × 情绪状态 × 行为动作 × 语言风格
章节内容 = 事件类型 × 事件风格 × 场景氛围 × 角色特点
```

- 角色特点和情节元素是独立维度，可自由组合
- 同一角色在不同场景展现不同面——高冷×害羞=可爱，高冷×愤怒=压迫感
- 组合越丰富，角色越立体、情节越不单调

### 核心体验极端化

**每个内容都要声明核心体验类型，并将其推到极致：**

| 核心体验 | 极端化标准 | 关键技法 |
|----------|-----------|---------|
| 暧昧感 | 让读者脸红心跳，反复回味 | 感官分层法+克制留白法+渐进式隐喻法 |
| 诱惑力 | 让读者血脉贲张，欲罢不能 | 感官分层法+环境烘托法+微反应刻画法 |
| 悲伤感 | 让读者泪流不止 | 重复递进情绪法+以死换情法+环境烘托法 |
| 笑点密度 | 让读者笑出声来 | 内心独白式幽默+对比式幽默+破折号旁白法 |
| 悬念感 | 让读者猜不到结局 | 信息差驱动法+钩子设置技巧+嵌套式叙事框架 |
| 热血感 | 让读者热血沸腾 | 高潮场景设计+重复递进情绪法 |
| 甜蜜度 | 让读者甜到牙疼 | 感官叠加法+微反应刻画法+环境烘托法 |
| 治愈感 | 让读者感到温暖 | 场景构建+感官叠加法+生活细节法 |

### 对比优化

**不靠死板评分标准，通过与优秀作品的对比提升质量。**

从结构设计、内容描写、人物塑造、写作技法、节奏控制、对话质量、情感渲染七个维度对比，找出差距并针对性优化。

## 核心创作技法

### 场景设计

场景 = 同一时间 + 同一地点 + 同一组人物的连续叙事单元。

**场景类型**：

| 类型 | 功能 |
|------|------|
| 对话场景 | 推进关系、揭示信息 |
| 动作场景 | 推进情节、制造紧张 |
| 描写场景 | 营造氛围、建立世界 |
| 回忆场景 | 补充背景、制造对比 |
| 过渡场景 | 连接主场景、调节节奏 |
| 转折场景 | 改变方向、制造悬念 |

**场景切换技巧**：

| 技巧 | 说明 |
|------|------|
| 硬切 | 直接切换时间/地点，干净利落 |
| 情绪衔接 | 用上场景的情绪过渡到下场景 |
| 意象过渡 | 用共同意象（雨、声音、气味）连接 |
| 时间跳跃 | 明确时间跨度后进入新场景 |
| 空间并置 | 同一时间不同空间，蒙太奇效果 |

**每章建议2-5个场景，类型多样，避免单场景拖沓。**

### 章节衔接

**章节之间必须有衔接，不能各自独立。**

| 结尾技巧 | 效果 |
|----------|------|
| 悬念式 | "门开了，站在门口的人让她愣住了。" |
| 情感式 | "她终于哭了出来，三年来第一次。" |
| 转折式 | "原来，他一直都知道。" |
| 留白式 | "她转身离开，再也没有回头。" |
| 钩子式 | "明天的会议上，一切都将改变。" |
| 问题式 | "这一次，她还会选择相信他吗？" |

| 开头技巧 | 功能 |
|----------|------|
| 承接式 | 延续上章情绪/场景 |
| 跳跃式 | 时间/空间跳跃 |
| 对比式 | 与上章形成反差 |
| 悬念式 | 延续上章悬念 |
| 新场景式 | 全新环境 |
| 内心式 | 角色心理 |

**过渡技巧**：时间过渡、空间过渡、情绪过渡、视角过渡、因果过渡、意象过渡。

### 章节标题设计

**好的标题 = 钩子 + 悬念 + 情感**

| 类型 | 示例 |
|------|------|
| 情感独白型 | "我什么都不剩下了"、"这一次，我不会再放手" |
| 悬念提问型 | "谁在背后操控这一切？"、"这个秘密还能藏多久？" |
| 数字引爆型 | "总分——555分！"、"三天" |
| 反差对比型 | "婚礼当天，新娘逃了"、"敌人变成了朋友" |
| 意象隐喻型 | "雨夜的告别"、"破晓时分" |
| 金句标志型 | "这一刀，我记了三年"、"你欠我一个道歉" |

### 故事弧

**故事弧在自然叙事节点结束，不在整数章结束。**

| 故事弧类型 | 建议章数 |
|------------|----------|
| 短弧（小冲突） | 3-7章 |
| 中弧（阶段性冲突） | 8-15章 |
| 长弧（重大冲突） | 16-30章 |
| 超长弧（世界观级） | 30-50章 |

结束标准：冲突解决、关系转变、世界观揭示、成长蜕变、情感高潮——任意自然节点。

### 节奏控制

- 长短句结合，一段2-4句
- 短句制造紧张（用于打斗、冲突、关键转折）
- 长句营造氛围（用于描写、情感、回忆）
- 不要一句话一段，不要连续5句以上同长度句子

## 去AI味（Gate A-F）

| Gate | 维度 | 要点 |
|------|------|------|
| A | 禁用词 | 扫描 banned-words.md 中的禁用词和句式 |
| B | 句式套路 | "不是A而是B"、万能状语、连续排比 |
| C | 情绪告知 | "他感到/她意识到" → 用身体反应展示 |
| D | 节奏均匀 | 排比、长句、段落长度过于一致 |
| E | 对话同质 | 所有角色同一语气、对话标签过多 |
| F | 结尾升华 | "他终于明白了……"式总结收尾 |

三遍修复法：Pass 1 去泛化 → Pass 2 去书面化 → Pass 3 回自然感。

## 学习模式

分析优秀小说，产出技法库和去耦合组件的扩展：

1. 从12个维度全面分析（角色特点、塑造手法、情节构造、钩子技巧、对话写作等）
2. 归类输出到 `[skill]/tools/extensions/techniques/` 和 `[skill]/tools/extensions/decoupled/`
3. 案例驱动，每个技巧点必须有原文案例支撑
