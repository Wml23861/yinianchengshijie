# 输出规则

## 文件系统

```
项目根目录/
├── CLAUDE.md                          # 静态指引文件（教 Claude 使用 skill）
├── 灵感/
│   └── 灵感_[小说名]_最终版.md
├── 大纲/
│   ├── 大纲_[小说名]_最终版.md        # 全书大纲
│   ├── 角色系统_[小说名].md           # 角色档案
│   └── 章节大纲/
│       ├── 章节大纲_[小说名]_最终版.md
│       ├── 世界线系统_[小说名].md
│       └── 角色剧情_[小说名].md
├── 正文/[小说名]/
│   ├── 第001章_[章节名].txt
│   └── ...
├── 设定/
│   ├── world_[小说名].md              # 世界观
│   ├── 创作设定_[小说名].md           # 创作偏好
│   └── 参考小说_[小说名].md           # 参考作品信息
└── 追踪/
    ├── 上下文摘要.md                   # 进度与衔接上下文
    ├── 写作反馈.md                     # 检查反馈
    ├── 情节追踪.md                     # 去耦合组合记录
    └── 角色追踪.md                     # 去耦合塑造记录
```

| 内容类型 | 格式 | 说明 |
|----------|------|------|
| 创作设定 | `.md` | 创作方向、风格、篇幅等用户选择 |
| 灵感 | `.md` | 只输出最终版 |
| 大纲 | `.md` | 最终版 + 角色系统 |
| 章节大纲 | `.md` | 最终版 + 世界线系统 + 角色剧情 |
| 正文 | `.txt` | 纯正文，不含评价、优化、注释 |
| 角色系统 | `.md` | 角色档案 |
| 世界线系统 | `.md` | 世界线进程追踪 |
| 设定 | `.md` | 世界观文档 |

## 模板

### 创作设定

```markdown
# 创作设定 — [小说名]

## 基本信息
- 题材类型：[都市言情/古代言情/玄幻修仙/悬疑推理/科幻末世/校园青春/历史架空]
- 创作风格：[甜宠/虐恋/热血/悬疑/治愈/搞笑/其他]
- 计划篇幅：[短篇1-5万/中篇5-20万/长篇20-50万/超长篇50万+]
- 每章字数：[2000/3000/4000/5000+]
- 计划章数：[根据篇幅和每章字数计算]

## 核心体验
- 主要体验：[暧昧/悲伤/搞笑/热血/悬念/甜蜜/治愈/诱惑]
- 极端化方向：[具体标准]

## 补充说明
[用户的特定要求]
```

### 角色系统

```markdown
# 角色系统 — [小说名]

## [角色名]

**核心特点**：[3词定义，如：高冷/外冷内热/护短]

**当前状态**：
- 身份：[当前身份]
- 能力：[当前能力水平]
- 情感状态：[对谁/什么感觉]

**关系网络**：
- [角色B]：[关系描述] → [变化趋势]

**成长弧线**：
- 起点：[初始状态]
- 转折1：[第X章，变化]
- 当前：[弧线位置]

**故事线进展**：
- [第X章]：[关键事件]
```

|------|----------|------|----------|
