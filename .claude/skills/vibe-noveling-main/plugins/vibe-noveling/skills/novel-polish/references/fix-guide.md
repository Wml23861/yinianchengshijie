# AI 味修复指南

本文件仅覆盖**工具无法自动检测**的 AI 味模式。工具能检测的（破折号、纠偏句式、虚假拔高、翻译腔、情感标签等）由工具报告，不在此重复。

## 对话失真

角色对话过于客气、理性或功能性，像在开会。

### 修复策略

用随机字符串（≥16 字符）片段选择策略，确保同类问题不同位置用不同改法：

- **策略 A**：插入打断、反问或攻击性短句
- **策略 B**：把设定解释改成行动后果展示
- **策略 C**：给角色加非理性反应（偏执、赌气、装傻、故意误解）
- **策略 D**：删掉整个回合，用动作替代信息传递

整句重写，不做局部换词。

## 无功能细节

声音、微动作、小物件等细节不承担叙事功能。

### 判断标准

- 声音描写反复出现但不是关键信息
- 嘴角上扬、手指敲击等微动作在偷渡情绪
- 删掉后对剧情推进、压力变化、关系判断无影响

### 修复策略

- **策略 A**：删除，联系前后句调整衔接
- **策略 B**：改成角色态度判断
- **策略 C**：改成直接结果
- **策略 D**：改成对话或行动

整句重写，不做局部换词。
