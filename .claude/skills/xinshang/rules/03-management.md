| 数据库 | 路径 | 维护方 | 作用 |
|--------|------|--------|------|
| 章节卡 | `novel/设定库/剧情规划/39_前100章章节卡.md` | A | 每章 8 字段卡（章号/标题/现实线/心界线/爽点/经典/明心状态/钩子/配比） |

## 二、章节卡 8 字段（每章一张）

```
章号 · 标题
├─ 现实线：现实中发生什么（地点/人物/事件/情绪）
├─ 心界线：心界里发生什么（地点/人物/事件/情绪）
├─ 本章爽点：智爽（看破式）/ 暖爽（被看见）or 悬念 / 冲突
├─ 本章经典：哪部经典 / 哪句原文 / 人物为什么在此刻想起
├─ 明心状态 A→B：起始 → 结束（一两个字，如「强撑 → 更累」「茫然 → 被戳中」）
├─ 钩子：章末吸引读者继续的东西（一个动作/物品/问题/反常/安静）
└─ 配比：现实% / 心界%（前 100 章默认 10/90 或 0/100）
```

**强制规则（第 51 章起）**：
- 不预先设计多张章节卡。每写完一章追加下一张。
- 写六章就是六章全部写完，再追加六张。**绝不一次性设计多张**，避免重复与脱节。
- 第 1-50 章已填齐 8 字段卡，从第 51 章起空白等写时填。

**章节名唯一**：不用「上/下/之一/之二」。

**伏笔类型**：小（场景细节）/ 中（人物关系）/ 大（世界观）/ 长期（跨时代）/ 哲学（终极问题）

**伏笔必须公平**：回收时读者回头看「原来早就出现了」，不是「作者临时编的」。

**禁止为反转而反转**：反转必须改变理解/关系/读者对过去的认识/未来选择。

## 五、上下文摘要（A↔B 交接必读）

> 见 `47_中间人转发话术.md` 顶部。

**结构：进度行 + 状态详情节**。

### 5.1 进度行（每次只改一行）

```
## 当前：正等 A 写第 N 章（第 N-1 章《xxx》已通过）
```

A 写完改成「正等 B 审第 N 章」。
B 通过改成「正等 A 写第 N+1 章」。
B 不通过：章号不变，改成「正等 A 改第 N 章」，并**覆盖**「给 A 的修改提示词」节。

### 5.2 状态详情节（替代创作记录 + 审核记录）

A 写完 → 47 顶部追加：

```
### A 第 N 章写完状态详情
- 标题 / 字数 / 脚本 [OK]
- 12 字段设计：[目的/人物/冲突/欲望/障碍/情绪/场景/动作/智慧/对境/结尾/伏笔]
- 修复记录：[自查问题 → 改法 → 复查]
- 跨章衔接：[与前两章的衔接点、状态连续]
- 登记数据库更新：章节卡 39 / 时间线 16 / 伏笔 13 / 人物库 08 36
```

B 审完 → 47 顶部追加：

```
### B 第 N 章审完状态详情（第 X 轮）
- 脚本：[OK]/[X 及修复]
- 14 轮结果：每轮一行
- P0/P1 清单：[章号-行号-原文-违反条款-建议改法]
- 跨章重复：[与前 5 章对照结果]
- 经典检查：[出处/准确性/待确认]
- 元叙事检查：[无 / 有（行 X）]
- B 备注：[其他提示、铺垫、伏笔提醒]
```

**A 改完**：把「A 第 N 章改完」节追加到 47 顶部（说明改了哪几处、跑脚本结果）。

**A 写到新章 / B 审到新章**：旧的「状态详情」节保留在 47 文件里（不删，作为历史追溯），最新一节在最上面。

### 5.3 进度行（精简样例）

```

**第 51 章写作提醒**：
- 字数 3000+（第 50 章 3042）
- 「请柬」不再作核心道具（第 49/50 连续两章核心道具，已停用）
- 开头勿用「巷子尽头」结构（第 48/49/50 连用，已登记）

> 本节以 `硬规则自检.py` 全量扫描结果为准，不是记忆快照。

### A 第 51 章写完状态详情
[详细 12 字段设计 / 修复 / 衔接]
```

## 八、写作流程（10 步闭环）

1. **读资料**（上面清单 1-12）
2. **设计章节**（本章目的/人物/冲突/欲望/障碍/情绪变化/关键场景/智慧触点/结尾状态）
3. **写正文**（第一遍就写足 3000 字，一章一个事件单元）
4. **自查自审**（跑脚本 + 八轮审查 + 43 维度）
5. **更新 47 顶部**（「A 第 N 章写完状态详情」节：字数 / 脚本状态 / 12 字段设计 / 问题与修复 / 跨章衔接）
6. **同步章节卡**（第 51 章起强制：在 39 对应幕末尾追加下一章的 8 字段卡）
7. **更新 47 顶部**为「正等 B 审第 N 章」
8. **交 B 审核（可选）**
9. **若 B 改**：按 N 处提示词改 → 跑脚本 → 改完回复「改完了」
10. **若 B 通过**：更新 47 顶部为「正等 A 写第 N+1 章」

## 九、章节完成质量标准（自评）

每章完成按 100 分自评：

| 维度 | 分值 | 标准 |
|------|------|------|
| 故事性 | 20 | 一章一个事件单元，事件完整 |
| 人物真实性 | 20 | 人物有独立欲望、说错话、犯错、不完美 |
| 语言自然度 | 15 | 无模板、无金句过密、无作者腔 |
| 情绪力量 | 10 | 情绪用动作展示，不直接命名 |
| 思想深度 | 10 | 智爽/暖爽落地，不说教 |
| 连续性 | 10 | 与前文衔接，无矛盾 |
| 原创性 | 5 | 不重复前章结构/意象/过渡 |
| 读者吸引力 | 5 | 钩子有效（不低级） |
| 排版标点 | 5 | 零破折号、零英文、引号成对 |

**85+ 合格；75-84 需修改；<75 不得入库**。
