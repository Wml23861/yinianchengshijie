## 一、章节卡 8 字段（每章一张，存 39_前100章章节卡.md）

```
第 N 章 · 标题

├─ 现实线：现实中发生什么
│  [地点 / 人物 / 事件 / 情绪]
│
├─ 心界线：心界里发生什么
│  [地点 / 人物 / 事件 / 情绪]
│
├─ 本章爽点：智爽（看破式）/ 暖爽（被看见）or 悬念 / 冲突
│
├─ 本章经典：哪部经典 / 哪句原文 / 人物为什么在此刻想起
│
├─ 明心状态 A→B：起始 → 结束
│  [一两个字，如「强撑 → 更累」「茫然 → 被戳中」]
│
├─ 钩子：章末吸引读者继续的东西
│  [一个动作 / 物品 / 问题 / 反常 / 安静 / 一句没说出口的话]
│
└─ 配比：现实% / 心界%
   [前 100 章默认 10/90 或 0/100，时代 2-4 可调]
```

**强制规则**：
- 第 1-50 章已填齐 8 字段卡
- 第 51 章起空白等写时填，**不预先设计多张卡**
- 写六章就是六章全部写完，再追加六张。**绝不一次性设计多张**
- 章节名唯一：不用「上/下/之一/之二」

**伏笔类型**：小（场景细节）/ 中（人物关系）/ 大（世界观）/ 长期（跨时代）/ 哲学（终极问题）

**伏笔必须公平**：回收时读者回头看「原来早就出现了」，不是「作者临时编的」。

**禁止为反转而反转**：反转必须改变理解/关系/读者对过去的认识/未来选择。
