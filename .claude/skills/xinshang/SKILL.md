# xinshang · 《心上众生》创作 Skill

本 Skill 把通用「去 AI 写作规则」与「中文长篇管理结构」适配到《心上众生》的双线结构、心界设定、念头众生、儒释道经典三线，是写正文（A）、审正文（B）、中间转发、AI 痕迹防护的统一入口。

**不替代** 项目宪法（`CLAUDE.md`、`审核CLAUDE.md`），而是把它们压缩成可被 Skill 加载的最小可用单元。

## 核心铁律（不可妥协，五条起步）

1. **连续句号铁律（最高优先级）**：一句完整意思不拆成碎片短句；段落句末符 ≤3；不出现「句号 + 几字短句 + 句号」的 AI 签名。脚本硬拦截。
2. **字数硬下限**：每章 3000+ 字（汉字 + 标点，目标 3000，最低 2800 兜底）。脚本硬拦截。
3. **零破折号、零英文、零 AI 关键词**（忽然 / 这一刻 / 仿佛 / 真正的 / 原来 / 缓缓 / 轻轻 / 静静）。脚本硬拦截。
4. **金句稀缺**：一章 0-1 句金句；不是每章都有悟道；不替人物/读者/作者悟。
5. **跨章不重复**：相邻两章不重复现实场景、不重复心界过渡方式、不重复核心道具；意象近 5 章合计 ≤10 次。

完整铁律见 `rules/02-xinshang.md` 与 `references/checklist.md`。

## 触发方式

| 命令 | 调用方 | 工作流 |
|------|--------|--------|
| `/写一章 [章号]` | 开发者 A | `workflows/write-chapter.md` |
| `/审一章` | 审核者 B | `workflows/review-chapter.md` |
| `/写六章 章节范围` | A + 独立子代理 | `workflows/write-six.md` |
| `/继续下一章` | 开发者 A | `workflows/continue-next.md` |
| 中间转发 | 中间人 | `workflows/mediate-AB.md` |

> A 写下一章不强制等 B 审（`/写一章` 直接写）。B 审是**可选**闸门。
> `/写六章` 是单会话一人分饰两职的闭环，写完交独立子代理复审到零 P0/P1。

## 工作模式（A 写 / B 审 / 中间转）

> **重要**：本项目**不**写 `novel/创作记录/` `novel/审核记录/` 两个目录。所有 A 的章节设计、B 的审查结论、跨章衔接、修复记录，**统一写到 `47_中间人转发话术.md` 顶部的「状态详情」节**。这样新会话接手时只读 47 顶部一个文件就够了，不用扫两个目录。

| 模式 | 输入 | 输出 | 文件 |
|------|------|------|------|
| A 写 | 章号 + 上下文摘要 | `novel/正文/.../N_第N章_标题.md` + 47 顶部更新 | `workflows/write-chapter.md` |
| A 续 | 上一章 + 状态 | 下一章正文 + 47 顶部更新 | `workflows/continue-next.md` |
| B 审 | 章号 | 47 顶部更新（结论 + 提示词） | `workflows/review-chapter.md` |
| 中间 | A/B 任意更新 | 47 顶部一行 | `workflows/mediate-AB.md` |

## 项目特色（本 Skill 与通用 Skill 的区别）

| 通用 Skill | xinshang（本 Skill） |
|-----------|----------------------|
| 单线叙事 | **双线（心界 85-90% / 现实 10-15%，写满 100 章后调整）** |
| 通用爽点 | **智爽（看破）+ 暖爽（被看见）**，不写打脸/无敌/秒杀 |
| 通用反派 | **21 类念头众生**（贪/嗔/痴/慢/疑/恐惧…），反派首先是人，其次才是象征 |
| 通用过渡 | **心界↔现实过渡**相邻两章不重样 |
| 通用章末 | **不升华、不预告、不三短句递进**，停在动作上 |
| 通用经典 | **儒释道三线**，原文不编造，无法确认就不加引号 |
| 通用字数 | **3000+ 硬下限**（不是 2000-3000 弹性） |
| 通用反查 | **14 轮审查 + 48 规则**（项目审核宪法），不是 6 Gate 通用 |

## 不做的事（本 Skill 边界）

- **不写 `novel/创作记录/` 目录**（设计/修复/衔接写到 47 顶部「状态详情」节）
- **不写 `novel/审核记录/` 目录**（14 轮结果/提示词写到 47 顶部「状态详情」节）
- **不自主 git 提交**（用户明确说「提交」才 commit/push）
- **不替用户/人物/作者悟**
- **不擅自修改核心设定**（不确定查文件，记待确认）
- **不写「骗检测器」的糙文**（CLAUDE.md 第三十七卷禁止）
- **不替用户奉承**，直接改问题
