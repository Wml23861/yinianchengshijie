**关键自问**：
- 明心此刻想要什么？独立于主题（想吃饭、想回家、想躲开某个人）
- 移的是哪一块石头？（CLAUDE.md 第三十六条）
- 现实对境用哪一个？（不能与上章重样）
- 心界↔现实过渡方式？（不能与上章同构）
- 有没有「没用的话/动作」？必须有

## 四、写正文

**一遍过自检**：

1. 字数 2900-3000（约 45-55 段，每段 70-90 字）
2. 单句逗号 ≤3；段落句末符 ≤3；禁碎片短句
3. 对话格式：`"完整句。"X说，"新句。"`（避中缀逗号堆叠）
4. 零禁用词：忽然 / 这一刻 / 仿佛 / 真正的 / 原来 / 缓缓 / 轻轻 / 静静（忽然仅限物理突然）
5. 零破折号、零英文、全角引号
6. 金句 0-1 句
7. 章末不升华：停在动作/物品/没说出口的话/具体细节/安静
8. 不替人物悟、不替读者总结
9. 众生有心路，配角也有自己的事
10. 写每段前问"这句是不是顺到没毛边？"

**章节元数据混入正文禁止**：不含「第 X 章」「上一章」「本章主题」「作者的话」「读者」「剧情」「小说」。
