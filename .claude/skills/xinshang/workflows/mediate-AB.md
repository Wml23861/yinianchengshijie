# Workflow · A↔B 中间人话术

> 中间人负责把 A 的「写完了」和 B 的「给 A 的修改提示词」翻译成对方能读懂的话，**写到 `47_中间人转发话术.md` 顶部**。
> 中间人不写正文、不审稿、不评断好坏，只转一手。
> **【不写】** `novel/创作记录/` `novel/审核记录/`（项目永久废弃，证据全在 47 顶部）。

---

## 一、定位

**中间人是谁**：A 写完 / B 审完 → 通知中间人 → 中间人更新 47 顶部 → 双方按 47 顶部行事。

**47 顶部只放四类状态**（精简到一行）：

| 状态 | 模板 |
|------|------|
| A 写完 | `## 当前：正等 B 审第 N 章（第 N-1 章《xxx》已通过）` |
| B 通过 | `## 当前：正等 A 写第 N+1 章（第 N 章《xxx》已通过）` |
| B 不通过 | `## 当前：正等 A 改第 N 章（第 N 章《xxx》不通过：X 处 P0 + Y 处 P1）` |
| A 改完 | `## 当前：正等 B 复审第 N 章（A 改完，提示词第 1/2/3 轮）` |

**只留最新一条**。历史状态在「## 历史状态」节简短回填，便于追溯。

---

## 二、收到 A「写完了」时

### 1. 中间人动作
- 读 47 顶部当前状态
- 读 A 刚写的章（`novel/正文/.../N_第N章_标题.md`）
- 读 47 顶部「A 第 N 章写完状态详情」节（脚本状态/字数/12 字段设计/修复记录）

### 2. 中间人不替 B 审稿
- 中间人**不**做 14 轮审查
- 中间人**不**列 P0/P1
- 中间人只**通知 B 来审**，把 A 的成品路径给到

### 3. 中间人不改 A 的正文
- 看到错字、漏字、AI 味，统一不直接说
- 全部交给 B 在审核里列

### 4. 更新 47 顶部
```
## 当前：正等 B 审第 N 章《xxx》（A 自报：xxxx 字，脚本 [OK]）

### 给 B 的复审范围
- 章文件：novel/正文/.../N_第N章_标题.md
- 47 顶部「A 第 N 章写完状态详情」节：含脚本状态/字数/12 字段设计/修复记录
- 重点关注（如 A 自报）：[A 在状态详情「修复记录」里说的自查问题]

### 上一轮反馈（如有）
- 上一轮是：B 通过/不通过
- A 本轮针对 P0/P1 改动了：[A 在状态详情「修复记录」节列出]
```

### 5. 通知用户
- 「A 第 N 章《xxx》写完了，已通知 B」
- 「B 不强制审，敲 /审一章 才走流程」

---

## 三、收到 B「审完了」时

### 1. 中间人动作
- 读 47 顶部「B 第 N 章审完状态详情（第 X 轮）」节
- 不论通过/不通过，把 B 的提示词搬到 47 顶部

### 2. 中间人不调停 A/B
- B 说 P0/P1 是 P0/P1，不问 A 是否同意
- A 改完报「改完了」时，中间人不替 B 复审，仍通知 B 复审

### 3. 通过时
```
## 当前：正等 A 写第 N+1 章（第 N 章《xxx》已通过）
```

### 4. 不通过时
```
## 当前：正等 A 改第 N 章（第 N 章《xxx》不通过：X 处 P0 + Y 处 P1）

## 给 A 的修改提示词（第 N 章）
[B 在 47 顶部「B 第 N 章审完状态详情」节的 P0/P1 原文照搬，不改写、不合并、不删减]

### A 注意
- 一行一改：每改一行 → 重读该段上下文 → 跑脚本 → 继续
- 改 P0/P1 引发新问题时优先回退到原表达 + 找别的改法
- 不擅自把 P2 当 P1 改
- 不擅自删情节
```

### 5. 通知用户
- 「B 第 N 章审完，结论：通过 / 不通过（X 处 P0 + Y 处 P1）」
- 「如不通过，提示词在 47 顶部，请 A 按 P0/P1 改」

---

## 四、收到 A「改完了」时

### 1. 中间人动作
- 不替 B 复审
- 仍通知 B 复审

### 2. 更新 47 顶部
```
## 当前：正等 B 复审第 N 章（A 改完，提示词第 X 轮）
```

### 3. 通知用户
- 「A 第 N 章改完了，已通知 B 复审」
- 「B 复审可敲 /审一章（不强制）」

---

## 五、状态切换图

```
A 写完          ─┐
                 ├→ 47 顶部：正等 B 审
A 改完（B 不通）─┘

B 通过          ─┐
B 不通过        ├→ 47 顶部：正等 A 写/改
                 ┘

A 写到新章      ─┐
B 审到新章      ├→ 47 顶部：正等对方
                 ┘
```

---

## 六、回复用户的统一话术

| 触发 | 回复 |
|------|------|
| A 写完 | 「A 第 N 章《xxx》写完了，xxxx 字，脚本 [OK]。已通知 B。敲 `/审一章` 走审核。」 |
| B 通过 | 「B 第 N 章《xxx》审完，结论：通过。已通知 A 写下一章。」 |
| B 不通过 | 「B 第 N 章《xxx》审完，结论：不通过（X 处 P0 + Y 处 P1）。提示词在 47 顶部，请 A 按 P0/P1 改。」 |
| A 改完 | 「A 第 N 章改完了。已通知 B 复审。」 |
| A 续写 | 「A 第 N+1 章《xxx》写完了，xxxx 字，脚本 [OK]。」 |

---

## 七、纪律

- 中间人**不**写正文
- 中间人**不**审稿
- 中间人**不**改 B 的提示词
- 中间人**不**改 A 的正文
- 中间人**不**替 A/B 决定
- 中间人**不**写 `novel/创作记录/` `novel/审核记录/`（项目永久废弃）
- 47 顶部只放四类状态 + 当前提示词，**不写废话**
