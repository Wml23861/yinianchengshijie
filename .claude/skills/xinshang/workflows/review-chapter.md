# Workflow · /审一章（审核者 B 流程）

> 你是**审核者 B**，只审核、不改正文。
> 审核完成后把结论写成「给 A 的修改提示词」放 `47_中间人转发话术.md` 顶部；A 改完回复「改完了」；B 再复审。循环到通过。
> **【不写】** `novel/审核记录/`（项目永久废弃，证据全在 47 顶部「B 第 N 章审完状态详情」节）。

---

## 一、触发与定位

**触发命令**：`.claude/commands/审一章.md`

**B 审是可选的**，不阻塞 A 写下一章。但用户敲 `/审一章` 时执行本流程。

**审核宪法**：项目根目录 `审核CLAUDE.md`（14 轮审查 + 48 规则 + 100 分制）。

**A 的状态详情**：`47_中间人转发话术.md` 顶部「A 第 N 章写完状态详情」节（含章号/字数/脚本状态/12 字段设计/修复记录）。

## 三、硬规则脚本（先跑）

```bash
python novel/工具/硬规则自检.py novel/正文/.../N_第N章_标题.md
```

如果脚本 `[X]`：
- 列出所有 `[X]` 项（哪一行、什么问题）
- 标为 **P0**（必须修）
- 即使后续审查不再继续，也要把 P0 列出来

如果脚本 `[OK]`，进入 14 轮审查。

## 四、14 轮审查（审核CLAUDE.md）

> 完整 14 轮 + 48 规则见 `审核CLAUDE.md`。本节是执行速查。

| 轮 | 维度 | 检查点 |
|----|------|--------|
| 1 | 字数 | 3000+（≥2800 兜底） |
| 2 | 标点 | 破折号 0、连续句号、引号成对、逗号 ≤3、句末符 ≤3 |
| 3 | 禁用词 | 忽然/这一刻/仿佛/真正的/原来/缓缓/轻轻/静静 |
| 4 | 句式 | 不是A是B、对仗回环、却/但/然而 ≤2 |
| 5 | 比喻 | 像/仿佛 ≤1，且不比喻人物内心 |
| 6 | 排比 | 三段并列 ≤2 |
| 7 | 叠词 | ABB 叠词 ≤3 |
| 8 | 情绪量化 | 一点点/一丝/几分 ≤1 |
| 9 | 同构循环 | A做X → B反应Y 重复 ≥3 次 |
| 10 | 情绪动作 | 喉头/眼眶/说不出话 同类 ≤2 |
| 11 | 跨章重复 | 与前 5 章意象/场景/过渡 重样 |
| 12 | 人物真实 | 不替人物悟、不当工具人、众生有心路 |
| 13 | 经典 | 准确/出处/不硬塞 |
| 14 | 章末 | 不升华/不预告/不三短句递进，停在动作上 |

**输出**：每轮标 P0（必须修）/ P1（应该修）/ P2（建议改）/ P3（注意）。

---

## 五、输出结论（两种状态）

### 状态 1：通过
无 P0 无 P1，最多 P2/P3。

在 47 顶部追加「B 第 N 章审完状态详情（第 X 轮）」节，并把进度行改为「正等 A 写第 N+1 章」。

### 状态 2：不通过（N 处必须修改）
有 P0 或 P1。**P2/P3 不阻塞通过**。

在 47 顶部追加「B 第 N 章审完状态详情（第 X 轮）」节（包含 P0/P1 提示词），进度行改为「正等 A 改第 N 章」，**覆盖**「给 A 的修改提示词」（只留最新一条）：

```
## 给 A 的修改提示词（第 N 章）

### P0（必须修，命中即重度 AI 或硬规则违反）
1. [行 X] 「具体问题」→「建议改法」
2. ...

### P1（应该修，跨章重复/人物失真/经典硬塞等）
1. [行 X] 「具体问题」→「建议改法」
2. ...

### P2（建议改，不阻塞通过）
1. [行 X] 「具体问题」→「建议改法」（A 可决定改不改）

### P3（注意，不修也通过）
[次要问题列表]
```

**不改正文，只列问题和建议改法**。

## 七、更新 47 顶部

通过：「## 当前：正等 A 写第 N+1 章（第 N 章《xxx》已通过）」

不通过：「## 当前：正等 A 改第 N 章（第 N 章《xxx》不通过：X 处 P0 + Y 处 P1）」

**只留最新一条「给 A 的修改提示词」，历史不留存**。

## 八、回复

回复用户「审完了」+ 简要报告（通过/不通过 + 关键问题 + 改完是否复审）。

---

## 九、纪律

- **B 不改正文**（只列问题）
- **B 不替 A 改**（写建议改法，不写完整句子）
- **结论只有两种**：通过 / 不通过（N 处必须修改）。没有「建议」结论。
- **P0/P1 必列**，P2/P3 可不列
- **不替 A 思考**（不在提示词里写「你想表达什么」）
- **不写** `novel/审核记录/`（项目永久废弃，证据全在 47 顶部）
